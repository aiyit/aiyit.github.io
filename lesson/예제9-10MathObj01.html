예제 9-10: JavaScript Math 객체 메서드1 분석 보고서

본 문서는 JavaScript 수학 내장 객체(Math)가 제공하는 주요 삼각함수, 절대값, 세제곱근, 올림 등의 메서드(abs, acos, acosh, asin, asinh, atan, atan2, cbrt, ceil)의 동작 원리와 활용법을 분석한 내용입니다.

1. HTML 전체 소스코드

<!DOCTYPE html>
<html>
<head>  <title>예제9-10Math 메소드1</title> </head>
<body>
<h3>Math 객체 메소드1</h3>
<p>abs(x) : <b id="ca"></b></p>
<p>acos(x) : <b id="cca"></b></p>
<p>acosh(x) : <b id="cnct"></b></p>
<p>asin(x) : <b id="ido"></b></p>
<p>asinh(x): <b id="vlf"></b></p>
<p>atan(x): <b id="fxd"></b></p>
<p>atan2(x) : <b id="prc"></b></p>
<p>cbrt(x) : <b id="exp"></b></p>
<p>ceil(x) : <b id="str"></b></p>
<script>
	var x = 1, y = 3;
	document.getElementById("ca").innerHTML = Math.abs(x);
	document.getElementById("cca").innerHTML = Math.acos(x);
	document.getElementById("cnct").innerHTML = Math.acosh(x);
	document.getElementById("ido").innerHTML = Math.asin(x); 
	document.getElementById("vlf").innerHTML = Math.asinh(x);
	document.getElementById("fxd").innerHTML = Math.atan(x);
	document.getElementById("prc").innerHTML = Math.atan2(x,y);
	document.getElementById("exp").innerHTML = Math.cbrt(x);
	document.getElementById("str").innerHTML = Math.ceil(x);  
</script>
</body>
</html>

2. HTML 구조 및 DOM 요소 설명

  • <h3>: 화면 대표 제목(Math 객체 메소드1)을 정의합니다.
  • <p> 및 <b id="..."> 태그: 각 Math 메서드의 연산 결과를 동적으로 바인딩하여 출력하기 위한 DOM 구역입니다. ca, cca, exp 등의 고유 ID가 부여되어 있습니다.

3. JavaScript Math 주요 메서드 상세 분석 (기준 변수: x = 1, y = 3)

메서드명 사용 예시 동작 설명 및 의미
Math.abs() Math.abs(1) 숫자의 절대값을 반환합니다. ➔ 1
Math.acos() Math.acos(1) 아크코사인(역코사인) 값을 라디안 단위로 반환합니다. ($\arccos(1) = 0$) ➔ 0
Math.acosh() Math.acosh(1) 역쌍곡코사인 값을 반환합니다. ($\operatorname{arcosh}(1) = 0$) ➔ 0
Math.asin() Math.asin(1) 아크사인(역사인) 값을 반환합니다. ($\arcsin(1) = \pi/2$) ➔ 1.5707963267948966 (약 $\pi/2$)
Math.asinh() Math.asinh(1) 역쌍곡사인 값을 반환합니다. ➔ 0.881373587019543
Math.atan() Math.atan(1) 아크탄젠트 값을 반환합니다. ($\arctan(1) = \pi/4$) ➔ 0.7853981633974483 (약 $\pi/4$)
Math.atan2() Math.atan2(1, 3) 주어진 인수(y, x)의 아크탄젠트 값을 반환합니다. ➔ 0.3217505543966422
Math.cbrt() Math.cbrt(1) 숫자의 세제곱근(cube root)을 반환합니다. ($\sqrt[3]{1} = 1$) ➔ 1
Math.ceil() Math.ceil(1) 소수점이 있는 경우 크거나 같은 정수 중 가장 작은 수를 반환(올림)합니다. ➔ 1
