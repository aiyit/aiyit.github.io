예제 10-7 & 10-8: 사용자 입력 및 마우스 이벤트 핸들러 통합 분석 문서

본 문서는 폼 요소의 값 변경을 감지하는 `onchange` 이벤트와 마우스 포인터의 진입·이탈을 감지하는 `onmouseover`/`onmouseout` 이벤트의 동작 원리와 문자열·스타일 제어 기법을 설명합니다.

1. 이벤트 핸들러 개념 및 통합 개요

웹 인터페이스에서 사용자의 입력값 검증과 시각적 피드백은 사용자 경험(UX)을 결정하는 핵심 요소입니다.

💡 핵심 포인트:
  • onchange: 입력 필드의 값이 바뀌고 포커스가 벗어날 때(또는 엔터 입력 시) 발생하여 유효성 검사 및 데이터 가공에 사용됩니다.
  • onmouseover / onmouseout: 마우스 커서가 특정 영역에 올라가거나 벗어날 때 발생하여 동적인 UI 효과를 제공합니다.

2. 병합된 HTML 원본 코드

<!DOCTYPE html>
<html>
<head>
  <link rel="stylesheet" href="style.css">
  <meta charset="utf-8">
  <title>예제 10-7 & 10-8 통합 예제</title>
  <script>
    // 예제 10-7: 입력값 대문자 변환 및 글자 수 검사
    function changeText() {
      var x = document.getElementById("txt").value;
      document.getElementById("txt").value = x.toUpperCase();  // 대문자로 변환
      var y = x.length;  // 입력된 문자의 길이 계산

      if (y < 10) {
        alert(y + "자 입력됨. 10자 이상 입력하세요!");
      } else {
        alert("올바른 입력입니다.");
      }
    }

    // 예제 10-8: 마우스 오버/아웃에 따른 스타일 및 텍스트 변경
    function mouseOver() {
      var target = document.getElementById("mouse");
      target.innerHTML = "onMouseOut()";
      target.style.border = "2px solid blue";
    }

    function mouseOut() {
      var target = document.getElementById("mouse");
      target.innerHTML = "onMouseOver()";
      target.style.border = "2px solid red";
    }
  </script>
</head>
<body id="main">
  <!-- Part 1: onchange -->
  <h3 style="text-align:center;">onchange() 이벤트 예제</h3>
  <h3>소문자로 입력한 후, 엔터를 누르거나 포커스를 이동해 보세요.</h3>
  <input type="text" id="txt" size="20" onchange="changeText();">

  <hr style="margin: 30px 0;">

  <!-- Part 2: onmouseover / onmouseout -->
  <h3>마우스를 올려놓으세요</h3>
  <h3 id="mouse" style="text-align:center; border:2px solid red;"
        onmouseover="mouseOver()" onmouseout="mouseOut()">
    onMouseOver()
  </h3>
</body>
</html>

3. 주요 함수 및 메서드 상세 분석

이벤트 / 메서드 관련 코드 동작 설명 및 특징
onchange 이벤트 onchange="changeText();" 입력 필드의 값이 변경된 후, 사용자가 포커스를 다른 곳으로 이동하거나 엔터(Enter) 키를 누를 때 트리거되어 함수를 실행합니다.
toUpperCase() x.toUpperCase() 입력받은 문자열의 모든 영문 소문자를 대문자로 변환하여 다시 입력창에 반영합니다.
length 속성 var y = x.length; 문자열의 총 글자 수를 숫자로 반환하여 조건문(10자 이상 여부) 검사에 활용합니다.
onmouseover / onmouseout onmouseover="..." onmouseout="..." 마우스 커서가 해당 요소 영역 안으로 들어올 때(Over)와 밖으로 빠져나갈 때(Out) 각각 다른 동작을 수행하여 직관적인 인터랙션을 구현합니다.
스타일 동적 변경 target.style.border = "..." 요소의 테두리 색상이나 모양을 스크립트로 실시간으로 갱신하여 시각적 변화를 줍니다.

핵심 정리

    입력값 제어 (`onchange`): 폼 데이터 완성 시점에 값을 가공(대문자 변환)하고 유효성을 검증(길이 체크) 마우스 반응 (`onmouseover`/`onmouseout`): 포인터 위치에 따라 콘텐츠와 스타일을 동적으로 토글 통합 인터랙션: 사용자 입력과 시각적 피드백을 웹 페이지에 구현하는 대표적인 DOM 이벤트 모델

학습 포인트: 폼 입력 제어 이벤트와 마우스 포인터 인터랙션 이벤트를 결합하여 다양한 사용자 행동 패턴에 대응하는 웹 스크립트 작성법을 익힙니다.
