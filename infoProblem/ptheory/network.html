1. 네트워크 기본 개념

1-1. 컴퓨터 네트워크란?

컴퓨터 네트워크(Computer Network)는 두 대 이상의 컴퓨터나 정보기기가 통신 매체로 연결되어 데이터와 자원을 주고받는 시스템입니다.

1-2. 네트워크 구성 방식

클라이언트-서버(Client-Server)

서버가 서비스를 제공하고 클라이언트가 요청합니다. 계정과 데이터를 중앙에서 관리하기 쉽습니다.

피어 투 피어(Peer-to-Peer, P2P)

각 컴퓨터가 상황에 따라 서비스 제공자와 이용자 역할을 함께 수행합니다.

1-3. 네트워크 토폴로지(Topology)

형태구조와 특징
성형(Star)중앙 허브·스위치에 연결. 관리가 쉽지만 중앙 장치 장애 영향이 큼.
버스형(Bus)공통 전송 회선을 여러 장치가 공유.
링형(Ring)장치가 고리 형태로 연결.
망형(Mesh)여러 경로로 연결되어 신뢰성이 높지만 구축 비용이 큼.
트리형(Tree)계층적으로 분기되는 구조로 확장에 유리.
시험 포인트 LAN·MAN·WAN은 연결 범위로 구분하고, 토폴로지는 장치의 물리적 또는 논리적 연결 형태를 의미합니다.

3. IP 주소와 서브넷

3-1. IPv4 주소

IP(Internet Protocol) 주소는 네트워크에서 장치를 식별하고 패킷을 목적지로 전달하는 논리 주소입니다. IPv4는 32비트이며 8비트씩 네 부분으로 나누어 10진수로 표시합니다.

3-2. 네트워크 주소와 호스트 주소

IP 주소는 서브넷 마스크 또는 프리픽스 길이를 기준으로 네트워크 부분과 호스트 부분으로 나뉩니다.

비유 네트워크 주소는 아파트 단지, 호스트 주소는 단지 안의 개별 세대에 비유할 수 있습니다.

예: 192.168.10.25/24 → 마스크 255.255.255.0, 네트워크 주소 192.168.10.0, 브로드캐스트 주소 192.168.10.255, 일반적인 사용 가능 호스트 수 254개.

3-3. 서브넷 마스크와 CIDR

서브넷 마스크(Subnet Mask)는 IP 주소에서 네트워크 부분과 호스트 부분을 구분하는 32비트 값입니다. CIDR(Classless Inter-Domain Routing)은 네트워크 비트 수를 /24처럼 표시합니다.

3-4. /26 계산 예제

192.168.10.0/24를 /26으로 나누면 호스트 비트는 6개, 주소 수는 64개, 일반 사용 가능 호스트 수는 62개입니다. 네 번째 옥텟의 블록 크기는 256−192=64입니다.

5. 라우팅·네트워크 운영·보안

5-1. 라우팅(Routing)

라우팅은 라우터가 목적지 IP 네트워크까지 패킷을 전달할 경로를 결정하는 과정입니다. 라우팅 테이블에는 목적지 네트워크, 다음 홉, 출력 인터페이스 등이 기록될 수 있습니다.

방식·프로토콜특징
정적 라우팅관리자가 경로를 직접 설정. 단순하지만 변경 시 수동 관리 필요.
동적 라우팅라우팅 프로토콜로 경로 정보를 교환하고 네트워크 변화에 대응.
RIP거리 벡터 방식, 홉 수를 기준으로 경로 선택. 최대 15홉.
OSPF링크 상태 방식, 비용(cost)을 기준으로 경로 계산.
BGP자율 시스템(AS) 사이에서 경로 정보를 교환하는 경로 벡터 방식.

5-2. NAT와 DHCP

NAT(Network Address Translation)

IP 주소 정보를 다른 주소로 변환합니다. 사설 IP를 공인 IP로 변환해 내부 장치가 외부 네트워크와 통신하도록 구성할 수 있습니다.

DHCP(Dynamic Host Configuration Protocol)

IP 주소, 서브넷 마스크, 기본 게이트웨이, DNS 서버 등의 네트워크 설정을 자동 제공합니다.
