Gemini 좌측 설정 메뉴 완벽 활용법

Gemini 인터페이스 드롭다운 메뉴 팝업의 총 12가지 메뉴 항목별 기능 개요, 기본 활용 방법, 그리고 대화창에 바로 적용 가능한 실제 예시활용 문구를 모았습니다.

1. 개인화 & 주요 기능 메뉴

활동

히스토리 관리

과거 대화 기록, 프롬프트 입력 내역, 검색 활동을 조회하거나 필요 시 기록을 삭제 및 보관 관리합니다.

기본 활용법: 이전 대화 내용을 다시 찾아보거나 보안을 위해 특정 대화 기록을 삭제할 때 사용합니다.
실제 예시활용 문구

"지난주에 작성했던 '인공지능 교육과정 시나리오' 대화 내용을 찾아서 주요 요약본을 보여줘."

개인 인텔리전스

사용자 역할 지정

사용자의 직업, 호칭, 전문 분야 및 preferred 답변 스타일을 미리 등록하여 모든 대화에 자동 적용합니다.

기본 활용법: 매번 본인 소개를 반복할 필요 없이 원하는 형태의 답변을 고정하도록 커스텀 컨텍스트를 지정합니다.
실제 예시활용 문구

"나는 대학에서 AI를 가르치는 박교수야. 답변할 때 '박교수님'으로 불러주고, 예시는 대학 수업 실습에 바로 적용 가능한 수준으로 작성해 줘."

Gemini로 메모리 가져오기

지식 동기화

외부 프로젝트 파일, 가이드라인 문서, 기존 기억 데이터를 Gemini 장기 메모리로 일괄 학습시킵니다.

기본 활용법: 표준 템플릿 문서나 특정 학기 평가 기준을 메모리로 통합해 지속 인지시킵니다.
실제 예시활용 문구

"지난 학기 제출받은 '학생 프로젝트 제출 양식' 문서를 메모리로 등록하고, 앞으로 질문 시 이 기준을 적용해 줘."

사용량 한도

쿼리/토큰 트래킹

일일/월간 토큰 소모 수치, 프롬프트 요청 가능 횟수 및 고급 모델 이용 한도 상태를 체크합니다.

기본 활용법: 고성능 모델이나 생성형 AI 호출 잔여량을 미리 확인하여 효율적으로 할당합니다.
실제 예시활용 문구

"오늘 생성형 AI 이미지 및 코드 생성 잔여 횟수와 토큰 사용량을 확인해 줘."

예약된 작업

반복 자동화

주기적으로 자동 수행할 반복 프롬프트, 브리핑 보고서 생성 태스크를 등록하고 관리합니다.

기본 활용법: 정기 트렌드 분석 리포트 수신이나 주간 교육 자료 요약을 자동 생성하도록 예약합니다.
실제 예시활용 문구

"매주 월요일 오전 9시에 '최신 AI 기술 동향 및 교육 적용 사례'를 요약해서 리포트로 생성해 줘."

스킬

도구 연동

Python 코드 스크립트 실행, 실시간 웹 검색, 데이터 시각화 도구 등의 기능을 켜고 끕니다.

기본 활용법: 코딩 실행 환경이나 그래프 시각화 엔진 스킬을 호출해 복잡한 데이터를 처리합니다.
실제 예시활용 문구

"Python 스킬을 사용해서 업로드한 CSV 데이터셋의 결측치를 처리하고 산점도 그래프로 시각화해 줘."

2. 커스텀 에이전트 & 앱 환경 메뉴

Gems

맞춤형 에이전트

특정 목적(튜터, 카피라이터, 데이터 분석관 등)으로 사전에 설계된 커스텀 AI 에이전트를 호출합니다.

기본 활용법: 미리 구성한 전문가 챗봇 페르소나를 즉시 대화 상대로 지정할 수 있습니다.
실제 예시활용 문구

"'AICE 시험 대비 엑셀/AI 튜터 Gem'을 불러와서 초보자 맞춤형 예제 문제를 3개 출제해 줘."

내 공개 링크

공유 URL 관리

외부 공유를 위해 발급한 대화 세션 URL을 한눈에 조회하거나 보안을 위해 삭제/비공개 처리합니다.

기본 활용법: 팀원이나 학생들에게 공유된 스레드 주소를 종합 제어합니다.
실제 예시활용 문구

"'Three.js 전기설비 시뮬레이션 코드' 대화의 공개 공유 링크를 생성하거나 기존 공유 링크를 해제해 줘."

테마

UI 스킨

화면 인터페이스를 라이트 모드, 다크 모드, 또는 시스템 기본 설정에 맞추어 스위칭합니다.

기본 활용법: 야간 및 어두운 환경에서 가독성을 높이고 눈의 피로를 최소화합니다.
실제 예시활용 문구

"눈의 피로도를 낮추기 위해 화면 모드를 '다크 테마'로 전환해 줘."

구독 보기

요금제 관리

현재 이용중인 Gemini 구독 등급(Advanced 등) 및 차기 결제일, 결제 수단을 관리합니다.

기본 활용법: 플랜 요금제의 최신 모델 이용 권한을 확인하고 플랜을 갱신합니다.
실제 예시활용 문구

"현재 요금제의 결제 주기 및 1.5 Pro/2.0 Pro 모델 접근 권한 상태를 확인해 줘."

Gemini Notebook

지식 워크스페이스

연구 문서, 논문 정리, 대화 스레드를 노트 형태로 구성하여 체계적으로 종합 분석하는 공간입니다.

기본 활용법: 프로젝트 단위로 노트 폴더를 구성하여 AI 교정 및 종합 정리를 진행합니다.
실제 예시활용 문구

"'VR/XR 몰입형 학습 연구' 노트를 생성하고 관련 자료와 대화 요약을 한곳에 모아 관리해 줘."

의견 보내기 & 도움말

피드백 및 매뉴얼

기능 개선 제안이나 오류 사항을 구글 팀에 바로 제출하거나 사용법 매뉴얼 도움말을 탐색합니다.

기본 활용법: 한국어 번역 미흡이나 소스코드 인덴트 오류 시 즉시 리포트합니다.
실제 예시활용 문구

"코드 생성 중 발생한 한국어 주석 출력 오류를 개발팀에 피드백으로 전송해 줘."
