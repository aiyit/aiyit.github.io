예제 9-7: JavaScript Number 객체 속성 분석 보고서

본 문서는 JavaScript 숫자(Number) 객체가 제공하는 주요 정적 속성(MAX_VALUE, MIN_VALUE, POSITIVE_INFINITY, NEGATIVE_INFINITY)의 개념과 표현 범위를 분석한 내용입니다.

1. HTML 전체 소스코드

<!DOCTYPE html>  HTML5 문서 형식을 선언합니다. 
<html>  HTML 문서 시작 
<head>  문서 기본 정보 영역 시작 
    <title>예제9-7Number 속성</title>  브라우저 탭에 표시할 제목 
</head>  head 영역 끝 
<body>  화면에 표시할 내용 시작 

<h3>Number 속성</h3>  Number 속성을 소개하는 제목 

<p>MAX_VALUE : <b id="ca"></b></p>  MAX_VALUE 값을 출력할 위치를 만듭니다. 
<p>MIN_VALUE : <b id="cca"></b></p>  MIN_VALUE 값을 출력할 위치를 만듭니다. 
<p>POSITIVE_INFINITY : <b id="cnct"></b></p>  양의 무한대 값을 출력할 위치를 만듭니다. 
<p>NEGATIVE_INFINITY : <b id="ido"></b></p>  음의 무한대 값을 출력할 위치를 만듭니다. 

<script>  JavaScript 코드 시작 

    document.getElementById("ca").innerHTML = Number.MAX_VALUE;  id가 ca인 요소에 가장 큰 양의 숫자를 출력합니다. 
    document.getElementById("cca").innerHTML = Number.MIN_VALUE;  id가 cca인 요소에 0에 가장 가까운 양의 숫자를 출력합니다. 
    document.getElementById("cnct").innerHTML = Number.POSITIVE_INFINITY;  id가 cnct인 요소에 양의 무한대를 출력합니다. 
    document.getElementById("ido").innerHTML = Number.NEGATIVE_INFINITY;  id가 ido인 요소에 음의 무한대를 출력합니다. 

</script>  JavaScript 코드 끝 
</body>  body 영역 끝 
</html>  HTML 문서 끝 


<!DOCTYPE html>  두 번째 HTML 예제의 시작을 나타내는 HTML5 선언 
<html>  두 번째 HTML 문서 시작 
<head>  두 번째 문서의 기본 정보 영역 시작 
    <title>예제9-8Number 메소드</title>  두 번째 예제의 브라우저 제목 
</head>  head 영역 끝 
<body>  화면에 표시할 내용 시작 

<h3>Number 메소드</h3>  Number 메소드를 소개하는 제목 

<p>isFinite : <b id="ca"></b></p>  isFinite() 실행 결과를 표시할 위치 
<p>isInteger : <b id="cca"></b></p>  isInteger() 실행 결과를 표시할 위치 
<p>isNaN : <b id="cnct"></b></p>  isNaN() 실행 결과를 표시할 위치 
<p>toExponential : <b id="ido"></b></p>  toExponential() 실행 결과를 표시할 위치 
<p>toFixed : <b id="fxd"></b></p>  toFixed() 실행 결과를 표시할 위치 
<p>toPrecision : <b id="prc"></b></p>  toPrecision() 실행 결과를 표시할 위치 
<p>toString : <b id="str"></b></p>  toString() 실행 결과를 표시할 위치 
<p>valueOf : <b id="vlf"></b></p>  valueOf() 실행 결과를 표시할 위치 

<script>  JavaScript 코드 시작 

    var num = 1234.567;  숫자 1234.567을 num 변수에 저장합니다. 

    document.getElementById("ca").innerHTML = Number.isFinite(num);  num이 유한한 숫자인지 검사하여 true 또는 false를 출력합니다. 
    document.getElementById("cca").innerHTML = Number.isInteger(num);  num이 정수인지 검사합니다. 
    document.getElementById("cnct").innerHTML = Number.isNaN(num);  num이 숫자가 아닌 값인지 검사합니다. 
    document.getElementById("ido").innerHTML = num.toExponential(num);  num을 지수 표기법으로 문자열 변환합니다. 
    document.getElementById("fxd").innerHTML = num.toFixed(1);  소수점 아래 한 자리까지 표시합니다. 
    document.getElementById("prc").innerHTML = num.toPrecision(4);  전체 유효 숫자를 네 자리로 표시합니다. 
    document.getElementById("str").innerHTML = num.toString(num);  숫자를 문자열로 변환합니다. 
    document.getElementById("vlf").innerHTML = num.valueOf(num);  Number 객체의 기본 숫자값을 반환합니다. 

</script>  JavaScript 코드 끝 
</body>  body 영역 끝 
</html>  HTML 문서 끝
소스코드 표시 영역 끝

2. HTML 구조 및 DOM 요소 설명

  • <h3>: 화면 대표 제목(Number 속성)을 정의합니다.
  • <p> 및 <b id="..."> 태그: Number 객체의 속성 값을 동적으로 바인딩하여 출력하기 위한 DOM 구역입니다. ca, cca, cnct, ido 등의 고유 ID가 부여되어 있습니다.

3. JavaScript Number 주요 속성 상세 분석

속성명 사용 표현 동작 설명 및 의미
Number.MAX_VALUE Number.MAX_VALUE JavaScript에서 표현할 수 있는 가장 큰 양의 숫자를 나타냅니다. (약 1.79E+308) 이 값을 초과하면 무한대(Infinity)로 처리됩니다.
Number.MIN_VALUE Number.MIN_VALUE JavaScript에서 표현할 수 있는 0에 가장 가까운 양의 숫자를 나타냅니다. (약 5E-324) 0은 아니지만 0에 근접한 가장 작은 양수입니다.
Number.POSITIVE_INFINITY Number.POSITIVE_INFINITY 양의 무한대(Infinity)를 나타내는 특수한 상숫값입니다. 오버플로우 발생 시 반환됩니다.
Number.NEGATIVE_INFINITY Number.NEGATIVE_INFINITY 음의 무한대(-Infinity)를 나타내는 특수한 상숫값입니다.
메서드명 사용 예시 동작 설명 및 결과 (기준 값: 1234.567)
Number.isFinite() Number.isFinite(num) 값이 유한수인지 검사합니다. ➔ true
Number.isInteger() Number.isInteger(num) 값이 정수인지 검사합니다. (소수점이 있으므로 거짓) ➔ false
Number.isNaN() Number.isNaN(num) 값이 NaN(Not-a-Number)인지 검사합니다. ➔ false
num.toExponential() num.toExponential() 숫자를 지수 표기법으로 변환합니다. ➔ 1.234567e+3
num.toFixed(digits) num.toFixed(1) 소수점 이하 자릿수를 지정하여 반올림된 문자열로 반환합니다. ➔ 1234.6
num.toPrecision(digits) num.toPrecision(4) 전체 유효숫자 개수를 지정하여 반환합니다. ➔ 1235
num.toString() num.toString() 숫자를 문자열로 변환합니다. ➔ 1234.567
num.valueOf() num.valueOf() Number 객체의 원시 숫자 값을 반환합니다. ➔ 1234.567
