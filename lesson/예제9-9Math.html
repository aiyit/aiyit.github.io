예제 9-9: JavaScript Math 객체 속성 분석 보고서

본 문서는 JavaScript 수학 내장 객체(Math)가 제공하는 주요 상수 속성(E, LN2, LN10, LOG2E, LOG10E, PI, SQRT1_2, SQRT2)의 개념과 활용법을 분석한 내용입니다.

1. HTML 전체 소스코드

1. HTML 전체 소스코드

<!DOCTYPE html>  HTML5 문서 형식을 선언합니다. 
<html>  HTML 문서의 시작입니다. 
<head>  문서의 기본 정보를 작성하는 영역입니다. 
    <title>예제 9-9Math 속성</title>  브라우저 탭에 표시할 문서 제목입니다. 
</head>  head 영역 끝 
<body>  화면에 표시할 내용을 작성하는 영역입니다. 

<h3>Math 객체 속성</h3>  Math 객체의 속성을 소개하는 제목입니다. 

<p>Euler's 상수(E) : <b id="ca"></b></p>  오일러 상수 E의 값을 출력할 위치입니다. 
<p>자연로그2 LN2 : <b id="cca"></b></p>  자연로그 2의 값을 출력할 위치입니다. 
<p>자연로그10 LN10 : <b id="cnct"></b></p>  자연로그 10의 값을 출력할 위치입니다. 
<p>2진로그E(LOG2E) : <b id="ido"></b></p>  log₂E 값을 출력할 위치입니다. 
<p>10진로그E(LOG10E): <b id="fxd"></b></p>  log₁₀E 값을 출력할 위치입니다. 
<p>PI : <b id="prc"></b></p>  원주율 파이(π) 값을 출력할 위치입니다. 
<p>SQRT1_2 : <b id="str"></b></p>  1을 2로 나눈 값의 제곱근을 출력할 위치입니다. 
<p>SQRT2 : <b id="vlf"></b></p>  2의 제곱근 값을 출력할 위치입니다. 

<script>  JavaScript 코드를 작성하는 영역의 시작입니다. 

    document.getElementById("ca").innerHTML = Math.E;  id가 ca인 요소에 오일러 상수 약 2.71828을 출력합니다. 
    document.getElementById("cca").innerHTML = Math.LN2;  id가 cca인 요소에 자연로그 2의 값 약 0.69315를 출력합니다. 
    document.getElementById("cnct").innerHTML = Math.LN10;  id가 cnct인 요소에 자연로그 10의 값 약 2.30259를 출력합니다. 
    document.getElementById("ido").innerHTML = Math.LOG2E;  id가 ido인 요소에 E의 밑이 2인 로그값 약 1.4427을 출력합니다. 
    document.getElementById("fxd").innerHTML = Math.LOG10E;  id가 fxd인 요소에 E의 밑이 10인 로그값 약 0.4343을 출력합니다. 
    document.getElementById("prc").innerHTML = Math.PI;  id가 prc인 요소에 원주율 약 3.14159를 출력합니다. 
    document.getElementById("str").innerHTML = Math.SQRT1_2;  id가 str인 요소에 1/√2의 값 약 0.7071을 출력합니다. 
    document.getElementById("vlf").innerHTML = Math.SQRT2;  id가 vlf인 요소에 √2의 값 약 1.4142를 출력합니다. 

</script>  JavaScript 코드 영역 끝 
</body>  body 영역 끝 
</html>  HTML 문서 끝
</script> </body> </html>

2. HTML 구조 및 DOM 요소 설명

  • <h3>: 화면 대표 제목(Math 객체 속성)을 정의합니다.
  • <p> 및 <b id="..."> 태그: Math 속성 값을 동적으로 바인딩하여 출력하기 위한 DOM 구역입니다. ca, cca, prc 등의 고유 ID가 부여되어 있습니다.

3. JavaScript Math 주요 속성 상세 분석

속성명 사용 표현 동작 설명 및 의미
오일러 상수 Math.E 자연로그의 밑(Euler's constant)인 약 2.718 값을 반환합니다.
자연로그 2 Math.LN2 2의 자연로그 값(약 0.693)을 반환합니다.
자연로그 10 Math.LN10 10의 자연로그 값(약 2.302)을 반환합니다.
2진 로그 E Math.LOG2E 밑이 2인 오일러 상수의 로그 값(약 1.442)을 반환합니다.
10진 로그 E Math.LOG10E 밑이 10인 오일러 상수의 로그 값(약 0.434)을 반환합니다.
원주율 (PI) Math.PI 원주율 파이 값인 약 3.14159...를 반환합니다.
1/2의 제곱근 Math.SQRT1_2 1/2의 제곱근(또는 1을 2의 제곱근으로 나눈 값, 약 0.707)을 반환합니다.
2의 제곱근 Math.SQRT2 2의 제곱근 값(약 1.414)을 반환합니다.

3. JavaScript Math 주요 메서드 상세 분석 (기준 변수: x = 1, y = 3)

메서드명 사용 예시 동작 설명 및 의미
Math.abs() Math.abs(1) 숫자의 절대값을 반환합니다. ➔ 1
Math.acos() Math.acos(1) 아크코사인(역코사인) 값을 라디안 단위로 반환합니다. ($\arccos(1) = 0$) ➔ 0
Math.acosh() Math.acosh(1) 역쌍곡코사인 값을 반환합니다. ($\operatorname{arcosh}(1) = 0$) ➔ 0
Math.asin() Math.asin(1) 아크사인(역사인) 값을 반환합니다. ($\arcsin(1) = \pi/2$) ➔ 1.5707963267948966 (약 $\pi/2$)
Math.asinh() Math.asinh(1) 역쌍곡사인 값을 반환합니다. ➔ 0.881373587019543
Math.atan() Math.atan(1) 아크탄젠트 값을 반환합니다. ($\arctan(1) = \pi/4$) ➔ 0.7853981633974483 (약 $\pi/4$)
Math.atan2() Math.atan2(1, 3) 주어진 인수(y, x)의 아크탄젠트 값을 반환합니다. ➔ 0.3217505543966422
Math.cbrt() Math.cbrt(1) 숫자의 세제곱근(cube root)을 반환합니다. ($\sqrt[3]{1} = 1$) ➔ 1
Math.ceil() Math.ceil(1) 소수점이 있는 경우 크거나 같은 정수 중 가장 작은 수를 반환(올림)합니다. ➔ 1

3. JavaScript Math 주요 메서드 상세 분석 (기준 변수: x = 1.00, y = 3)

메서드명 사용 예시 동작 설명 및 의미
Math.cos() Math.cos(1) 주어진 각도(라디안)의 코사인 값을 반환합니다. ➔ 0.5403023058681398
Math.cosh() Math.cosh(1) 쌍곡코사인 값을 반환합니다. ➔ 1.5430806348152437
Math.exp() Math.exp(1) 오일러 상수 $e$의 거듭제곱($e^1$) 값을 반환합니다. ➔ 2.718281828459045
Math.floor() Math.floor(1) 인수로 전달된 숫자와 같거나 작은 정수 중 가장 큰 수(내림)를 반환합니다. ➔ 1
Math.log() Math.log(1) 자연로그 값($\ln(1)$)을 반환합니다. ➔ 0
Math.max() Math.max(1, 3, 0.3, 12) 전달된 인수들 중 가장 큰 값을 반환합니다. ➔ 12
Math.min() Math.min(1, 3, 0.3, 12) 전달된 인수들 중 가장 작은 값을 반환합니다. ➔ 0.3
Math.pow() Math.pow(1, 3) 베이스 숫자의 지정된 거듭제곱 값($1^3$)을 반환합니다. ➔ 1
Math.random() Math.random() 0 이상 1 미만의 무작위 난수(Pseudo-random number)를 반환합니다. ➔ (실행 시마다 무작위 소수 반환, 예: 0.812...)

3. JavaScript Math 주요 메서드 상세 분석 (기준 변수: x = 1.234)

메서드명 사용 예시 동작 설명 및 의미
Math.round() Math.round(1.234) 소수점 이하 첫째 자리에서 반올림하여 가장 가까운 정수를 반환합니다. ➔ 1
Math.sin() Math.sin(1.234) 주어진 각도(라디안)의 사인 값을 반환합니다. ➔ 0.942488801931616
Math.sinh() Math.sinh(1.234) 쌍곡사인(Hyperbolic Sine) 값을 반환합니다. ➔ 1.5654395346894052
Math.sqrt() Math.sqrt(1.234) 숫자의 양의 제곱근(Square Root)을 반환합니다. ($\sqrt{1.234}$) ➔ 1.1108555263624835
Math.tan() Math.tan(1.234) 주어진 각도(라디안)의 탄젠트 값을 반환합니다. ➔ 2.915011707577517
Math.tanh() Math.tanh(1.234) 쌍곡탄젠트 값을 반환합니다. ➔ 0.8433983693437295
Math.trunc() Math.trunc(1.234) 숫자의 소수점 이하를 버리고 정수 부분만 반환합니다. ➔ 1
