JavaScript 예제 9-1: 객체의 개념과 코드 설명

이 문서는 제공된 프로그램을 그대로 제시하고, 프로그램에 사용된 객체, 속성, 메서드, this, 반복문의 의미를 설명합니다.

참고: 이 예제는 제목에 ‘객체 생성자’라고 되어 있지만, 실제 코드는 new를 사용하는 생성자 함수 방식이 아니라 객체 리터럴 방식으로 객체를 만듭니다.

1. 제공된 HTML 전체 코드

아래는 질문에 제공된 원본 코드입니다. 프로그램의 동작을 바꾸지 않았습니다.

<!DOCTYPE html>
<html>
<head>
<title>예제9-1객체 생성자</title>

    <script>
       var human ={ name: "Park", age:40, sex:"female", speed:20,    //속성
              walk : function(){ this.speed = 5;},      //걷기 메소드
              run : function(){ this.speed +=3;},        //달리기 메소드
        };
    do {
    document.write("이름:"+human.name+ " 달리기:" + human.speed + "<br />");
        human.run();

    </script>

2. 객체란 무엇인가요?

객체(Object)는 관련된 데이터와 기능을 하나로 묶어 놓은 것입니다. 이 예제에서는 사람의 정보와 행동을 human이라는 객체 하나에 모았습니다.

var human = {
    name: "Park",
    age: 40,
    sex: "female",
    speed: 20,
    walk: function(){ this.speed = 5; },
    run: function(){ this.speed += 3; }
};
구분코드의미
속성(Property)name: "Park"이름 데이터
속성(Property)age: 40나이 데이터
속성(Property)sex: "female"성별 데이터
속성(Property)speed: 20현재 속도 데이터
메서드(Method)walk: function(){...}객체가 수행하는 걷기 기능
메서드(Method)run: function(){...}객체가 수행하는 달리기 기능

3. 메서드와 this의 의미

human.run()은 human 객체의 run 메서드를 실행합니다.

run: function(){ this.speed += 3; }

여기서 this.speed는 현재 메서드를 호출한 human 객체의 speed 속성을 가리킵니다. 따라서 실행할 때마다 속도에 3을 더합니다.

human.walk()은 다음 코드를 실행합니다.

walk: function(){ this.speed = 5; }

이 메서드는 속도를 3씩 더하는 것이 아니라, 속도 값을 5로 다시 설정합니다.

4. do...while 반복문은 어떻게 실행되나요?

do...while은 먼저 중괄호 안의 명령을 한 번 실행한 다음, 조건을 검사합니다. 이 코드에서는 현재 속도를 출력하고, 속도를 3 증가시킨 뒤, human.speed < 35인지 검사합니다.

순서출력되는 속도run() 실행 후 속도반복 조건 검사
1202323 < 35 → 참
2232626 < 35 → 참
3262929 < 35 → 참
4293232 < 35 → 참
5323535 < 35 → 거짓, 반복 종료
속도 35는 반복 조건을 검사할 때 만들어지지만, 다음 반복이 시작되지 않으므로 ‘달리기’ 출력에는 나타나지 않습니다.

5. 프로그램의 최종 출력

반복문이 끝난 뒤 human.walk()가 실행되어 속도가 5로 바뀝니다. 마지막 출력은 이 값을 보여 줍니다.

이름:Park 달리기:20 이름:Park 달리기:23 이름:Park 달리기:26 이름:Park 달리기:29 이름:Park 달리기:32 이름:Park 걷기:5

6. 실행 순서 한눈에 보기

  1. human 객체를 만들고 속성 및 메서드를 정의합니다.
  2. 현재 이름과 속도를 출력합니다.
  3. human.run()으로 속도를 3 증가시킵니다.
  4. 속도가 35보다 작은 동안 반복합니다.
  5. 반복이 끝나면 human.walk()으로 속도를 5로 설정합니다.
  6. 이름과 걷기 속도 5를 마지막으로 출력합니다.

핵심 순서: 출력(20) → 증가(23) → 출력(23) → 증가(26) → 출력(26) → 증가(29) → 출력(29) → 증가(32) → 출력(32) → 증가(35) → 조건 거짓 → 걷기 속도 5 → 마지막 출력

핵심 정리

  • 객체: 데이터와 기능을 하나로 묶은 것
  • 속성: 객체가 가진 데이터(name, age, speed 등)
  • 메서드: 객체가 수행하는 기능(run(), walk())
  • this: 이 호출 문맥에서 메서드를 실행하는 human 객체를 가리킴
  • do...while: 명령을 먼저 실행한 후 조건을 검사하는 반복문

학습 포인트: 이 코드는 객체의 속성 값을 메서드로 변경하고, 반복문으로 그 변화를 관찰하는 예제입니다.
