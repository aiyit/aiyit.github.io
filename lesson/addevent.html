addEventListener(),
이벤트를 연결하는 표준 방법

클릭, 키 입력, 마우스 이동처럼 사용자가 하는 동작을 이벤트라고 한다. addEventListener()는 "이 요소에서 이 이벤트가 일어나면 이 함수를 실행해 줘"라고 등록하는 메서드이다.

요소.addEventListener("이벤트 종류", 실행할 함수, 옵션) btn.addEventListener("click", function () { ... })

1. 이벤트를 연결하는 세 가지 방법

<!-- ① HTML 속성 -->
<button onclick="hello()">클릭</button>

// ② DOM 속성
btn.onclick = function () { ... };

// ③ addEventListener
btn.addEventListener("click", function () { ... });
방법같은 이벤트에 여러 개 등록평가
① HTML 속성불가능 (하나만)HTML과 코드가 섞여 관리가 어렵다
② DOM 속성불가능 (나중 것이 앞의 것을 덮어씀)간단하지만 한 개만 쓸 때 적합
③ addEventListener가능 (모두 실행됨)권장하는 표준 방식
핵심 차이는 "덮어쓰기"와 "누적"이다. 아래 실습에서 직접 확인해 보자.

실습 1. 덮어쓰기 vs 누적

두 버튼을 차례로 눌러 보자.
a.onclick = function () { log("A 실행"); };
a.onclick = function () { log("B 실행"); };   // A를 덮어쓴다 → B만 실행

b.addEventListener("click", function () { log("A 실행"); });
b.addEventListener("click", function () { log("B 실행"); }); // A, B 모두 실행

2. 이벤트 객체(event)

함수에는 이벤트에 대한 정보가 담긴 이벤트 객체가 자동으로 전달된다. 보통 매개변수 이름을 e 또는 event로 쓴다.

속성의미
e.type이벤트 종류 ("click", "keydown" 등)
e.target이벤트가 실제로 일어난 요소
e.currentTarget리스너를 등록한 요소
e.clientX, e.clientY마우스 좌표(마우스 이벤트)
e.key누른 키 이름(키보드 이벤트)
e.preventDefault()브라우저의 기본 동작을 막는다

실습 2. 마우스 좌표와 키 입력

이 상자 위에서 마우스를 움직이거나 클릭해 보자
이벤트 정보가 여기에 표시된다.
pad.addEventListener("mousemove", function (e) {
  console.log(e.type, e.clientX, e.clientY);
});
input.addEventListener("keydown", function (e) {
  console.log("누른 키:", e.key);
});

3. 리스너 제거: removeEventListener()

등록한 리스너를 없애려면 removeEventListener()에 같은 이벤트 종류와 같은 함수를 넘긴다. 그래서 제거할 함수는 이름을 붙여 따로 만들어 둔다.

function say() { console.log("눌렀다"); }

btn.addEventListener("click", say);
btn.removeEventListener("click", say);   // 제거 성공

btn.addEventListener("click", function () { ... });
btn.removeEventListener("click", function () { ... }); // 제거 실패! 다른 함수이다
이름 없는 함수는 매번 새로 만들어지는 서로 다른 함수라서 제거할 수 없다.

실습 3. 등록·제거와 once 옵션

먼저 "대상 버튼"을 눌러 아무 일도 없는 것을 확인하자.
btn.addEventListener("click", say, { once: true });  // 한 번 실행 후 자동 제거

4. 이벤트 버블링

안쪽 요소에서 일어난 이벤트는 바깥쪽 부모 요소로 올라가며 전달된다. 이를 버블링이라 한다. 아래 안쪽 파란 상자를 눌러 보자.

바깥 (div 1)
가운데 (div 2)
안쪽 (여기를 클릭)
안쪽 상자를 클릭해 보자.
inner.addEventListener("click", function (e) {
  e.stopPropagation();   // 부모로 전달되지 않게 막는다
});
버블링 덕분에 부모 하나에만 리스너를 달아 많은 자식의 클릭을 처리할 수 있다. (이벤트 위임)

5. 자주 쓰는 이벤트

종류이벤트발생 시점
마우스click, dblclick, mouseover, mouseout, mousemove클릭, 더블클릭, 올림, 벗어남, 이동
키보드keydown, keyup키를 누름, 뗌
입력 양식input, change, submit, focus, blur입력 중, 값 확정, 제출, 포커스 얻음/잃음
문서·창DOMContentLoaded, load, resize, scroll문서 준비, 로딩 완료, 크기 변경, 스크롤
이벤트 종류 이름에는 on을 붙이지 않는다. addEventListener("click", ...)이 맞고 "onclick"은 틀리다.

6. 확인 문제

1. 같은 버튼에 click 함수를 두 개 등록하면 둘 다 실행되는 방식은?

addEventListener()이다. onclick 속성은 마지막에 대입한 함수만 남는다.

2. addEventListener("onclick", f)가 동작하지 않는 이유는?

이벤트 종류에는 on을 붙이지 않는다. "click"이라고 써야 한다.

3. 어떤 키를 눌렀는지 알려면 어떤 속성을 쓰는가?

keydown 이벤트의 e.key

4. removeEventListener()가 동작하려면 무엇이 같아야 하는가?

이벤트 종류와 함수가 같아야 한다. 그래서 제거할 함수는 이름 있는 함수로 만든다.

5. 안쪽 요소 클릭이 바깥 요소 리스너까지 실행되는 현상과 막는 방법은?

버블링이라 하고, e.stopPropagation()으로 막는다.
