Navigator 객체 기초 개념 및 속성 분석 문서

본 문서는 사용자의 웹 브라우저 종류, 버전, 운영체제(OS) 및 네트워크 연결 상태 등의 클라이언트 환경 정보를 조회할 수 있는 `navigator` 객체의 기초 개념과 주요 속성들을 상세히 설명합니다.

1. Navigator 객체란 무엇인가요? (기초 개념)

`navigator` 객체는 브라우저를 실행하고 있는 사용자(클라이언트)의 단말기 및 웹 브라우저에 대한 종합적인 정보를 담고 있는 자바스크립트의 내장 객체입니다.

💡 핵심 역할: 서버는 클라이언트의 정확한 브라우저 환경을 알기 어렵기 때문에, 자바스크립트의 navigator 객체를 통해 사용자의 기기 운영체제나 네트워크 상태(온라인 여부)를 파악하고 그에 맞는 맞춤형 콘텐츠나 예외 처리를 제공할 수 있습니다.

2. 제공된 HTML 원본 코드

<!DOCTYPE html>
<html>
<head>
<meta charset="utf-8">
<title>navigator 객체</title>
<link rel="stylesheet" href="style.css">   
</head>
<body>
<h3>navigator 객체</h3>
<p>navigator appCodeName: <b id="wh"></b>입니다.</p>
<p>navigator appName: <b id="awh"></b>입니다.</p>
<p>navigator appVersion: <b id="cd"></b>입니다.</p>
<p>navigator cookieEnabled: <b id="pd"></b>입니다.</p>
<p>navigator onLine: <b id="prt"></b>입니다.</p>
<p>navigator platform: <b id="pltf"></b>입니다.</p>
<p>navigator userAgent: <b id="userA"></b>입니다.</p>
<button type="button" onclick="lct()">navigator 정보 보기</button>
<script>
    function lct() {
         var appCodeName = navigator.appCodeName;
         var appVersion = navigator.appVersion; 
         var appName = navigator.appName;
         var cookieEnabled = navigator.cookieEnabled;
         var onLine = navigator.onLine;
         var platform = navigator.platform;
         var userAgent = navigator.userAgent;
          
        document.getElementById("wh").textContent = appCodeName;
        document.getElementById("awh").textContent = appName;
        document.getElementById("cd").textContent = appVersion;
        document.getElementById("pd").textContent = cookieEnabled;
        document.getElementById("prt").textContent = onLine;
        document.getElementById("pltf").textContent = platform;
        document.getElementById("userA").textContent = userAgent;
    }
</script>
</body>
</html>

3. Navigator 주요 속성 상세 분석

속성명 반환 예시 (브라우저 환경에 따라 다름) 설명 및 특징
appCodeName "Mozilla" 브라우저의 코드 이름을 반환합니다. (대부분의 모던 브라우저는 호환성을 위해 "Mozilla"로 고정되어 반환됨)
appName "Netscape" 브라우저의 공식 이름을 반환합니다. (크롬, 사파리 등도 레거시 호환을 위해 "Netscape"를 반환하는 경우가 많음)
appVersion 버전 및 엔진 상세 정보 문자열 브라우저의 상세 버전 정보를 반환합니다.
cookieEnabled true 또는 false 사용자의 브라우저에서 쿠키 사용이 허용(활성화)되어 있는지 부울리언 값으로 반환합니다.
onLine true 또는 false 현재 사용자의 기기가 인터넷에 연결(온라인)되어 있는지 여부를 반환합니다.
platform "Win32", "MacIntel" 등 브라우저가 실행되고 있는 사용자의 운영체제(OS) 플랫폼 환경을 반환합니다.
userAgent 브라우저 전체 식별 문자열 브라우저 종류, 버전, OS 정보가 모두 포함된 종합 문자열로, 브라우저 세부 식별에 가장 많이 사용됩니다.

핵심 정리

    클라이언트 환경 파악: 사용자의 브라우저와 기기 상태를 코드로 진단하는 도구 활용성: 쿠키 지원 여부 확인(cookieEnabled)이나 네트워크 상태 체크(onLine) 등에 유용 주의점: 일부 속성(`appName`, `appCodeName` 등)은 과거 웹 표준 호환성 문제로 인해 모든 브라우저에서 고유한 값을 주지 않고 통일된 값을 반환하므로, 상세 식별에는 주로 `userAgent`나 기능 감지 기법을 함께 활용함

학습 포인트: `navigator` 객체를 통해 클라이언트의 브라우저 및 시스템 환경 정보를 안전하게 조회하는 방법을 익힙니다.
