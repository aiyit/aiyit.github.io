3. 리스트(List)

리스트는 여러 데이터를 하나의 변수에 순서대로 저장하는 Python 자료형입니다. 인덱스는 0부터 시작하며, 값을 변경하거나 추가·삭제할 수 있습니다.

리스트 실습 1. 생성·조회·수정

Python 코드 · 리스트 기본 조작
scores = [85, 90, 78, 95]

print("첫 번째 점수:", scores[0])
print("세 번째 점수:", scores[2])

scores[1] = 100
print("수정된 리스트:", scores)
실행 결과
첫 번째 점수: 85
세 번째 점수: 78
수정된 리스트: [85, 100, 78, 95]

리스트 실습 2. 추가·삭제·반복

Python 코드 · 리스트 관리
fruits = ["사과", "바나나", "포도"]

fruits.append("딸기")       # 마지막에 추가
fruits.remove("바나나")    # 값으로 삭제

for fruit in fruits:
    print(fruit)

print("항목 수:", len(fruits))
실행 결과

포도
딸기
항목 수: 3
기억하기: append()는 끝에 추가, insert()는 지정 위치에 삽입, remove()는 값을 기준으로 삭제, pop()은 항목을 꺼내며 삭제합니다.

리스트와 배열 구분: Python list는 서로 다른 자료형도 함께 저장할 수 있는 유연한 컨테이너입니다. array.array는 지정한 한 종류의 기본 자료형 값을 저장합니다. NumPy 배열은 과학·수치 계산에 널리 사용됩니다.

5. 스택(Stack)

스택은 후입선출(LIFO: Last In, First Out) 방식입니다. 가장 나중에 넣은 데이터가 가장 먼저 나옵니다.

스택 실습 1. 리스트로 push와 pop

Python 코드 · 스택 기본 연산
stack = []

# push: 데이터 추가
stack.append("책 A")
stack.append("책 B")
stack.append("책 C")
print("현재 스택:", stack)

# pop: 마지막 데이터 꺼내기
item = stack.pop()
print("꺼낸 데이터:", item)
print("남은 스택:", stack)
실행 결과

꺼낸 데이터: 책 C
남은 스택: ['책 A', '책 B']

스택 실습 2. 괄호 짝 검사

Python 코드 · 괄호 검사 알고리즘
def check_brackets(expression):
    stack = []

    for char in expression:
        if char == "(":
            stack.append(char)
        elif char == ")":
            if not stack:
                return False
            stack.pop()

    return len(stack) == 0

print(check_brackets("(A+B)"))
print(check_brackets("((A+B)"))
print(check_brackets("(A+B))"))
실행 결과
True
False
False
활용: 실행 취소(Undo), 웹 브라우저 뒤로 가기 기록, 함수 호출 관리, 괄호 검사 등에 사용됩니다.

6. 큐(Queue)

큐는 선입선출(FIFO: First In, First Out) 방식입니다. 먼저 들어온 데이터가 먼저 나갑니다.

은행 창구 대기 줄
출구
손님 A
손님 B
손님 C
손님 D
입구

A가 먼저 들어왔으므로 가장 먼저 서비스를 받습니다.

연산의미Python deque
enqueue뒤쪽에 데이터 추가append()
dequeue앞쪽에서 데이터 제거popleft()
front맨 앞 데이터 확인queue[0]

큐 실습 1. deque로 대기열 구현

Python 코드 · 큐의 삽입과 삭제
from collections import deque

queue = deque()

# enqueue: 뒤에 추가
queue.append("학생 A")
queue.append("학생 B")
queue.append("학생 C")
print("대기열:", list(queue))

# dequeue: 앞에서 제거
person = queue.popleft()
print("서비스 대상:", person)
print("남은 대기열:", list(queue))
실행 결과
대기열: ['학생 A', '학생 B', '학생 C']
서비스 대상: 학생 A
남은 대기열: ['학생 B', '학생 C']

큐 실습 2. 프린터 작업 대기열

Python 코드 · 작업을 순서대로 처리
from collections import deque

print_queue = deque(["보고서.pdf", "과제.docx", "사진.png"])

while print_queue:
    job = print_queue.popleft()
    print("인쇄 중:", job)

print("모든 인쇄 작업 완료")
실행 결과
인쇄 중: 보고서.pdf
인쇄 중: 과제.docx
인쇄 중: 사진.png
모든 인쇄 작업 완료
주의: 리스트의 pop(0)을 반복하면 앞 요소들을 이동시켜야 해 데이터가 많을 때 비효율적일 수 있습니다. 큐에는 collections.deque의 popleft()를 사용하는 것이 일반적입니다.
