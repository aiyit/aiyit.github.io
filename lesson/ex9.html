객체(Object)와 생성자 함수

처음 배우는 학생도 이해할 수 있도록, 객체를 만드는 이유부터 this, new까지 단계별로 살펴봅니다.

1. 객체란 무엇인가요?

객체는 하나의 대상에 관한 정보와 기능을 한데 묶어 놓은 것입니다.

예를 들어 학생 한 명에게는 이름과 학과 같은 정보가 있고, 자기소개를 하는 기능도 있을 수 있습니다. JavaScript에서는 정보는 속성(property), 기능은 메서드(method)라고 부릅니다.

학생 객체
이름: 민수
학과: AI소프트웨어과
학년: 1
→
객체의 기능
자기소개하기()
학년 표시하기()
const student = {
  name: "민수",             // 속성: 학생의 이름
  department: "AI소프트웨어과",
  grade: 1,
  introduce: function() {  // 메서드: 객체의 기능
    return "안녕하세요. 저는 " + this.name + "입니다.";
  }
};

console.log(student.name);       // 민수
console.log(student.introduce()); // 안녕하세요. 저는 민수입니다.
기억할 점: student.name은 이름이라는 속성의 값이고, student.introduce()는 메서드를 실행하는 표현입니다. 메서드를 실행할 때는 괄호 ()가 필요합니다.

2. 객체를 여러 개 만들려면?

학생 객체를 한 명만 만든다면 위와 같이 작성해도 됩니다. 하지만 학생이 30명이라면 객체 코드를 30번 반복해야 할까요?

생성자 함수(Constructor Function)는 같은 형태의 객체를 반복해서 만들 수 있도록 설계한 함수입니다. 쉽게 말해 객체를 찍어내는 설계도입니다.

생성자 함수
학생 객체의 설계도
→
new Student(...)
학생 객체 1
→
new Student(...)
학생 객체 2
function Student(name, department, grade) {
  this.name = name;
  this.department = department;
  this.grade = grade;
}

const student1 = new Student("민수", "AI소프트웨어과", 1);
const student2 = new Student("지영", "AI소프트웨어과", 2);

console.log(student1.name); // 민수
console.log(student2.name); // 지영
코드쉬운 의미
function Student(...)학생 객체를 만드는 설계도(생성자 함수)를 정의합니다.
name, department, grade객체마다 달라질 정보를 전달받는 매개변수입니다.
this.name = name새로 만들어지는 객체의 name 속성에 전달받은 이름을 저장합니다.
new Student(...)설계도를 사용해 새로운 학생 객체를 만듭니다.
student1, student2각각 별도의 객체를 가리키는 변수입니다.
명명 규칙: 생성자 함수 이름은 관례적으로 첫 글자를 대문자로 씁니다. Student처럼 작성하면 일반 함수와 구분하기 쉽습니다. JavaScript가 대문자를 강제하는 것은 아니지만 널리 쓰이는 약속입니다.

3. 가장 헷갈리는 this 이해하기

this는 이 코드에서 새로 만들어지는 객체를 가리킵니다. this.name = name을 두 부분으로 나누어 보세요.

this.name = name;
// 왼쪽 this.name : 객체 안에 저장할 속성
// 오른쪽 name    : 함수가 전달받은 매개변수 값

예를 들어 new Student("민수", "AI소프트웨어과", 1)을 실행하면, 매개변수 name에는 "민수"가 들어오고 새 객체의 name 속성에 저장됩니다.

왼쪽연결오른쪽
this.name← 값을 저장name (전달받은 "민수")
this.grade← 값을 저장grade (전달받은 1)
비유: 택배 상자에 붙이는 이름표가 this.name이고, 택배 신청서에서 받아온 이름이 name입니다. 신청서의 이름을 해당 상자의 이름표에 적는 과정입니다.

4. 직접 실행해 보기

이름과 학년을 바꾸고 버튼을 눌러 보세요. 아래 예제는 생성자 함수를 이용해 두 학생 객체를 만든 뒤, 각 객체의 속성을 읽어 출력합니다.

버튼을 누르면 결과가 여기에 표시됩니다.
function Student(name, grade) {
  this.name = name;
  this.grade = grade;
}
const student1 = new Student("민수", 1);
const student2 = new Student("지영", 2);

구분객체 리터럴생성자 함수
작성 예const s = {name:"민수"};const s = new Student("민수");
적합한 상황형태가 다른 객체 또는 소수의 객체같은 구조의 객체를 여러 개 생성할 때
장점짧고 직관적반복 코드를 줄이고 구조를 통일

현대 JavaScript에서는 클래스(class) 문법도 자주 사용합니다. 다만 생성자 함수의 원리를 먼저 이해하면 this와 객체 생성 과정을 배우는 데 도움이 됩니다.

class Student {
  constructor(name, grade) {
    this.name = name;
    this.grade = grade;
  }
}
const student1 = new Student("민수", 1);

7. 핵심 정리

  • 객체: 관련된 데이터와 기능을 묶은 것
  • 속성: 객체가 가진 정보. 예: student.name
  • 메서드: 객체에 연결된 함수. 예: student.introduce()
  • 생성자 함수: 비슷한 구조의 객체를 반복해서 만드는 함수
  • this: 생성자 함수에서 새로 만들어지는 객체를 가리킴
  • new: 생성자 함수를 이용해 새 객체를 생성
한 문장으로 기억하기: 생성자 함수는 설계도이고, new는 그 설계도로 새 객체를 만들며, this는 만들어지는 객체의 속성을 설정할 때 사용합니다.
