1. NumPy와 시각화 도구의 관계

NumPy는 수치 계산과 배열 처리가 주된 역할이고, 그래프를 직접 그리는 기능은 약합니다. 그래서 NumPy가 계산한 데이터를 시각화 라이브러리에 넘겨주는 구조로 사용합니다.

1단계데이터 생성·수집학생 점수, 센서 온도, 매출
➜
2단계NumPy 처리평균, 합계, 최댓값, 조건 검색
➜
3단계시각화 도구Matplotlib, Seaborn, Plotly
➜
4단계결과 해석추세, 분포, 차이, 이상값

쉬운 비유: 요리사와 화가

🧮 NumPy계산 담당재료를 손질하고 계산한다
➜
📊 숫자 데이터전달평균 81.0, 점수 배열 …
➜
🎨 Matplotlib그림 담당받은 숫자로 그래프를 그린다

예) 학생 점수 100개가 있을 때 NumPy로 평균과 최고점을 계산하고, Matplotlib으로 점수 분포를 그래프로 표현합니다.

3. 대표적인 그래프 5가지

같은 숫자 배열도 어떤 그래프를 쓰느냐에 따라 전달하는 정보가 달라집니다. 아래 그림은 이 강의에서 직접 그리게 될 결과입니다.

그래프용도예시NumPy 기능그리기 함수
선 그래프 (Line)시간에 따른 변화시간별 온도 변화np.arange(), 배열 연산plt.plot()
막대그래프 (Bar)항목 간 크기 비교학생별 시험 점수np.array(), np.max()plt.bar()
히스토그램 (Histogram)값이 어느 구간에 얼마나 분포하는지한 학급의 성적 분포np.mean(), np.std()plt.hist()
산점도 (Scatter)두 변수 사이의 관계공부 시간과 시험 점수배열 간 연산, 조건 검색plt.scatter()
히트맵 (Heatmap)숫자 크기를 색으로 표현학생별·과목별 점수 비교2차원 배열, reshape()sns.heatmap()
질문: "학생 5명의 점수 비교"와 "한 학급 100명의 점수 분포"에는 각각 어떤 그래프가 맞을까요?
정답 보기5명 비교 → 막대그래프(항목별 크기 비교), 100명 분포 → 히스토그램(구간별 개수). 데이터가 적고 이름이 있으면 막대, 데이터가 많고 "몰림"을 보고 싶으면 히스토그램입니다.

4. 실습 전에: 그래프 코드 읽는 법

Matplotlib 코드는 대부분 아래 4단계로 되어 있습니다. 코드가 길어 보여도 이 순서만 기억하면 쉽게 읽을 수 있습니다.

① 데이터 준비np.array(...)그릴 숫자를 만든다
➜
② 그리기plt.bar() / plt.plot()그래프 종류를 고른다
➜
③ 꾸미기plt.xlabel() · title() · legend()제목과 이름을 붙인다
➜
④ 보여주기plt.show()화면에 출력한다
처음 보는 표현쉬운 설명

import matplotlib.pyplot as plt그래프 도구를 불러와 plt라는 짧은 이름으로 쓴다 (plt = 그림판)
# 글자주석. 컴퓨터는 무시하고 사람이 읽는 설명이다
label="Score"이름표 붙이기. 범례(legend)에 이 이름이 나온다
linestyle="--"선 모양 지정. "--"는 점선
plt.xlabel("A"); plt.ylabel("B")세미콜론(;)은 한 줄에 명령 두 개를 쓸 때 사용

5. 실습 1 — 학생 점수 막대그래프와 평균선

목표: 배열 생성 → 평균 계산 → 막대그래프 → 평균선 표시까지 한 흐름으로 실행합니다.
import numpy as np                 # 숫자 계산 도구 NumPy를 np라는 짧은 이름으로 불러온다
import matplotlib.pyplot as plt    # 그래프 도구 Matplotlib(pyplot)을 plt라는 이름으로 불러온다

# 1. 학생 점수 배열 생성
scores = np.array([70, 85, 90, 65, 95])   # 학생 5명의 점수를 NumPy 배열로 만든다

# 2. NumPy로 평균 계산
average = np.mean(scores)                 # 점수 5개의 평균을 구한다 → 81.0

# 3. 막대그래프 작성
students = np.arange(1, 6)                # 학생 번호 [1 2 3 4 5] (x축에 쓸 값)
plt.bar(students, scores, label="Score")  # x축=학생 번호, 막대 높이=점수, 범례 이름="Score"
plt.axhline(average, linestyle="--", label="Average")  # 평균 높이에 가로 점선(--)을 긋는다

# 4. 그래프 꾸미기
plt.xlabel("Student Number")              # x축 제목
plt.ylabel("Score")                       # y축 제목
plt.title("Student Score Visualization")  # 그래프 전체 제목
plt.xticks(students)                      # x축 눈금을 1~5 정수로만 표시
plt.legend()                              # 범례(Score, Average 설명 상자) 표시
plt.grid(axis="y", alpha=0.3)             # 가로 눈금선을 연하게(투명도 0.3) 표시

# 5. 그래프 출력
plt.show()                                # 완성된 그래프를 화면에 보여 준다
print("평균 점수:", average)              # 계산한 평균을 글자로도 확인한다

실행 결과 (그림 속 번호는 코드와 연결됩니다)

번호코드그림에서의 역할
①plt.title()그래프 맨 위 제목
②plt.ylabel()세로축 이름(점수)
③plt.xlabel()가로축 이름(학생 번호)
④plt.bar()학생별 점수를 막대로 표시
⑤plt.axhline()평균(81.0)을 나타내는 가로 점선
⑥plt.legend()막대=Score, 점선=Average 설명 상자
⑦plt.grid()읽기 쉽게 깔아 둔 연한 눈금선
평균 점수: 81.0
코드역할
np.array()점수 데이터를 배열로 생성
np.mean()평균 계산 (결과: 81.0)
plt.bar()학생별 점수를 막대로 표시
plt.axhline()평균을 나타내는 수평 점선
plt.show()그래프 화면 출력
학생 질문: ① 점수를 하나 추가하면 어떤 줄을 고쳐야 할까요? ② 평균 미만인 막대만 다른 색으로 칠하려면?(힌트: scores < average)
정답 보기① scores 배열에 값을 추가하고, 학생 번호도 늘려야 하므로 np.arange(1, 6)을 np.arange(1, 7)로 바꿉니다(끝값 미포함).
# 평균 미만 막대만 다른 색으로 칠하기
colors = np.where(scores < average, "tomato", "steelblue")   # 조건이 참이면 tomato, 거짓이면 steelblue
plt.bar(students, scores, color=colors)                      # color에 막대별 색 목록을 넘긴다

6. 실습 2 — 그래프 종류별 따라 하기

목표: 같은 방식으로 선 그래프, 히스토그램, 산점도, 히트맵을 직접 그려 봅니다. 한글 폰트 문제를 피하기 위해 라벨은 영어로 작성했습니다.

① 선 그래프 — 시간별 온도

import numpy as np
import matplotlib.pyplot as plt

hours = np.arange(0, 24)                          # 0시~23시: [0 1 2 ... 23]
temp = 15 + 8 * np.sin((hours - 9) * np.pi / 12)  # 사인 곡선으로 하루 온도를 만든다(평균 15도, ±8도, 15시경 최고)
plt.plot(hours, temp, marker="o")                 # 선 그래프를 그리고 각 점에 동그라미(o)를 표시한다
plt.xlabel("Hour"); plt.ylabel("Temperature")     # 축 제목(;로 한 줄에 명령 두 개)
plt.title("Hourly Temperature")                   # 그래프 제목
plt.show()                                        # 화면에 출력

② 히스토그램 — 점수 분포

import numpy as np
import matplotlib.pyplot as plt

np.random.seed(0)                                         # 난수 시작값 고정 → 실행할 때마다 같은 그래프
scores = np.random.normal(70, 10, 100).clip(0, 100)       # 평균 70, 표준편차 10인 점수 100개 생성, 0~100 밖은 잘라낸다
plt.hist(scores, bins=10, edgecolor="black")              # 점수를 10개 구간(bins)으로 나눠 개수를 막대로 표시, 테두리 검정
plt.axvline(scores.mean(), linestyle="--", label="Mean")  # 평균 위치에 세로 점선을 긋는다
plt.xlabel("Score"); plt.ylabel("Students")               # 축 제목
plt.legend(); plt.show()                                  # 범례 표시 후 출력
print("평균:", scores.mean().round(1), "표준편차:", scores.std().round(1))  # 평균과 퍼진 정도 확인

③ 산점도 — 공부 시간과 점수

import numpy as np
import matplotlib.pyplot as plt

np.random.seed(1)                                       # 난수 고정
hours = np.random.uniform(0, 10, 50)                    # 공부 시간 50개: 0~10 사이 무작위 값
score = 40 + 5 * hours + np.random.normal(0, 5, 50)     # 점수 = 기본 40점 + 1시간당 5점 + 오차(들쭉날쭉함)
plt.scatter(hours, score)                               # x=공부 시간, y=점수 위치에 점을 하나씩 찍는다
plt.xlabel("Study Hours"); plt.ylabel("Score")          # 축 제목
plt.title("Study Hours vs Score")                       # 그래프 제목
plt.show()                                              # 화면에 출력
print("상관계수:", np.corrcoef(hours, score)[0, 1].round(2))  # 두 값의 관계 강도(-1~1). 1에 가까울수록 같이 증가

④ 히트맵 — 학생별·과목별 점수

import numpy as np
import matplotlib.pyplot as plt
import seaborn as sns                                   # Matplotlib 기반의 통계 그래프 도구

scores = np.array([[80, 90, 70, 85],                    # 행 = 학생(S1~S5)
                   [85, 95, 88, 78],                    # 열 = 과목(국어·영어·수학·과학)
                   [75, 80, 90, 92],
                   [60, 70, 65, 80],
                   [95, 85, 90, 88]])
sns.heatmap(scores, annot=True, cmap="Blues",           # annot=True: 칸 안에 숫자 표시, cmap: 색상표(파랑 계열)
            xticklabels=["Kor", "Eng", "Math", "Sci"],  # 가로 눈금 이름(과목)
            yticklabels=["S1", "S2", "S3", "S4", "S5"]) # 세로 눈금 이름(학생)
plt.show()                                              # 화면에 출력
학생 질문: ③에서 점들이 오른쪽 위로 향하는 이유는 무엇일까요? 상관계수가 1에 가까우면 어떤 의미일까요?
정답 보기점수를 40 + 5 * hours + 오차로 만들었기 때문에 공부 시간이 늘수록 점수도 늘어납니다. 상관계수가 1에 가까우면 "한쪽이 커질 때 다른 쪽도 거의 일정하게 커진다"는 뜻이고, 0 근처면 관계가 거의 없다는 뜻입니다.
※ ②, ③은 난수를 사용하므로 seed를 고정해야 매번 같은 그래프가 나옵니다.
