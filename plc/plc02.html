PLC 하드웨어 구조와 시스템 구성

전원·CPU·메모리·I/O·통신을 하나의 시스템으로 이해한다

오늘의 학습 목표

  • PLC 구성 요소의 역할과 신호·전원 경로를 구분한다.
  • 시스템 전원과 부하 전원, 호출 간 기억과 리테인을 구분한다.

  • 신호 종류별 채널 수를 정리하고 가상 확장 수량을 계산한다.

1

하드웨어를 보는 순서 — 신호와 전원 경로

1주차에는 PLC를 입력–처리–출력 구조로 배웠습니다. 이번에는 그 구조를 실제 장치 안에서 구현하는 전원, CPU, 메모리, I/O 모듈, 통신 인터페이스의 역할을 살펴봅니다.

센서·버튼→입력 모듈→CPU·메모리→출력 모듈→구동 인터페이스

위 흐름은 정보 경로입니다. 각 장치에 전력을 공급하는 경로는 따로 있습니다. 통신 케이블이나 백플레인으로 정보가 연결되었다고 센서·접촉기·밸브의 부하 전원까지 모두 공급되는 것은 아닙니다.

하드웨어 점검의 세 질문
① 무엇과 통신하는가? → 정보 경로
② 어디에서 전원을 받는가? → 전원 경로
③ 어떤 모델과 호환되는가? → 구성 규칙
이번 교안은 명판·도면·가상 구성 기반입니다. 제어반을 열거나 전원을 넣고 단자를 만지는 실습은 하지 않습니다.
2

전체 구성 — 컴팩트형도 확장할 수 있다

컴팩트형은 CPU와 일부 입출력이 통합된 형태이고, 모듈형은 필요한 기능을 모듈로 조합하는 형태입니다. 두 개념은 완전히 배타적이지 않습니다. 내장 I/O가 있는 CPU에 확장 모듈을 추가할 수도 있습니다.

AI / AQ아날로그 신호

그림은 역할 개념도입니다. 실제 슬롯 번호·좌우 순서·필수 전원 모듈·장착 규칙은 특정 CPU의 사양을 따릅니다.

분산 I/O 활용현장 근처에 신호 수집 배치네트워크·현장 전원·장애 시 동작
제품군 이름만 보고 모듈 수나 배치 규칙을 외우지 마세요. 기존 S7-1200과 S7-1200 G2, S7-1500 등의 사양을 섞지 않고 해당 주문번호·세대·펌웨어의 자료를 사용합니다.
3

전원 — 시스템 전원과 부하 전원의 차이

CPU 내부 전자회로와 백플레인에 필요한 전원, 현장 센서·액추에이터에 필요한 전원을 구분합니다. S7-1500/ET 200MP 문서에서는 시스템 전원 PS와 부하 전원 PM을 구분해 설명합니다.

구분주요 역할주의점
시스템 전원, PS백플레인 등 내부 시스템 전압 공급외부 밸브·모터 부하 전원과 동일하지 않음
부하 전원, PM 등CPU·I/O 회로·센서·액추에이터 등에 필요한 DC 전원 공급장치별 공급 단자·전압·전류·회로 보호 확인
CPU의 내부 공급 기능모델에 따라 백플레인 전원 공급별도 PS가 항상 필수이거나 항상 불필요한 것은 아님

전원 설계에서는 전압만 같다고 충분하지 않습니다. 소비 전류, 기동 시 특성, 전원 분배, 공통 기준 전위, 접지·보호 및 제조사 규칙을 검토해야 합니다. 백플레인의 전력 예산과 외부 부하 전류 예산은 별도로 계산합니다.

개념 예시: 24V DC 부하가 정상 운전 시 0.4A + 0.3A + 0.5A를 소비하면 합계는 1.2A입니다. 이것만으로 전원장치 정격을 확정할 수는 없습니다. 기동·피크·온도·여유·보호 조건이 추가로 필요합니다.
“PLC 전원은 모두 24V DC”라고 일반화하지 않습니다. AC 전원을 받는 CPU·전원장치도 있으므로 반드시 명판·매뉴얼로 확인합니다. 본 교안은 전원 단자 결선 지침이 아닙니다.

RUN은 사용자 프로그램을 실행하는 상태를 이해하는 출발점이고 STOP은 실행·출력 동작이 다른 상태입니다. STOP 시 출력은 CPU·모듈·설정에 따라 검토해야 하며, STOP이 에너지 격리나 안전 확보를 의미하지 않습니다.

CPU 모델의 숫자가 커 보인다는 이유로 전원·슬롯·모듈까지 호환된다고 판단하지 않습니다. 정확한 주문번호와 지원 자료를 대조합니다.
5

메모리 — 실행 상태와 전원 유지 구분

구분학습할 의미확인 질문
로드 메모리적재되는 프로그램·프로젝트 데이터와 관련된 저장 자원카드 필요 여부·지원 매체는?
작업 메모리프로그램 실행과 데이터 처리에 쓰이는 자원프로그램·데이터 용량이 충분한가?
리테인 영역지정된 조건에서 유지하도록 설정하는 데이터무엇을 유지하고 언제 초기화하는가?
임시 데이터현재 호출 중 계산을 위한 변수읽기 전에 값을 대입했는가?

FB의 Static 변수는 호출 사이 상태를 보관할 때 사용하지만, Static이라는 이유만으로 전원 차단 후 값이 유지된다고 가정하면 안 됩니다. 리테인 설정과 CPU 시작·초기화·다운로드 동작을 구분해야 합니다.

“다음 스캔에도 기억”과 “전원을 껐다 켜도 기억”은 다른 요구사항입니다. 운전 명령·생산 수량·설정값은 각기 다른 재시작 정책이 필요할 수 있습니다.

메모리 카드의 종류·필수 여부·탈착 조건은 CPU마다 다릅니다. 일반 저장장치를 임의로 대체하거나 운전 중 분리하지 않습니다.

기호의미검토 사항

DQ 또는 DO디지털 출력트랜지스터/릴레이 등 출력 방식·부하

모듈의 채널 수가 같아도 기능은 다를 수 있습니다. 8채널 입력 모듈을 골랐다는 사실만으로 전류 입력 센서나 온도 센서를 모두 연결할 수 있는 것은 아닙니다. 센서 신호와 채널 설정 범위가 맞아야 합니다.

출력 방식도 구분합니다

트랜지스터 출력과 릴레이 출력은 허용 전압·전류, 부하 특성, 스위칭 특성이 다릅니다. 출력 모듈 자체의 채널별 한계와 그룹별 한계를 모두 확인해야 합니다.

CPU 출력은 모터 전력 공급 단자가 아닙니다. 접촉기·드라이브·밸브 등의 적합한 인터페이스와 보호 구성이 필요합니다. 실제 배선·접점 방식은 3주차 이후의 모델별 자료로 확인합니다.
7

확장 모듈과 백플레인 — 배치 규칙은 모델별

백플레인은 CPU와 연결 모듈 사이의 내부 통신·전원 경로를 이해하는 개념입니다. 구현 방식은 제품마다 다르며, 눈에 보이는 외형이 비슷하다고 같은 버스 구조는 아닙니다.

명칭 예시역할적용 시 주의
SM, Signal module디지털·아날로그 채널 확장제품군·모델·모듈 수·전원 예산 확인
SB, Signal board지원 CPU의 추가 신호 기능기존 세대 예시를 모든 CPU에 일반화하지 않음
CM/CP통신 기능 확장인터페이스·프로토콜·연결 자원 확인
특수·기술 모듈고속 계수·위치·측정 등필요 기능과 지원 CPU 조합 확인

하드웨어 구성 화면에서 모듈을 추가할 수 있어도 실제 장착 상태·전원 분배·배선까지 검증된 것은 아닙니다. 반대로 실제 모듈과 프로젝트의 주문번호나 슬롯이 다르면 진단 불일치가 발생할 수 있습니다.

확장 가능 여부는 채널 수뿐 아니라 물리 슬롯·모듈 종류·버스 전원·주소·통신 자원의 공통 조건입니다.

중앙 I/O와 분산 I/O

CPU + 중앙 I/O↔산업용 네트워크↔현장 분산 I/O + 센서
구분중앙 I/O분산 I/O
배치CPU와 같은 스테이션의 확장네트워크를 통해 현장에 별도 배치
장점으로 검토구조가 단순한 소규모 장치현장 근처 신호 수집·배선 배치 유연성
주의점CPU·중앙 확장 제한·배선 집중현장 전원·네트워크·갱신·장애 반응

분산 I/O는 “전원 없이 네트워크 선만 꽂으면 되는 장치”가 아닙니다. 인터페이스 모듈, I/O 모듈, 현장 전원과 네트워크 구성을 함께 확인합니다. 통신이 끊겼을 때 대체값·출력 반응·복귀 후 동작도 설계해야 합니다.

분산 배치가 항상 더 빠르거나 저렴한 것은 아닙니다. 거리·배선·통신 부하·유지보수·장애 영향 범위를 기준으로 선택합니다.

통신 포트 — 커넥터와 기능은 다르다

대상읽어야 할 정보
PC 연결선택 어댑터·주소·접근 권한
HMI연결 대상·갱신 데이터·통신 설정
분산 I/O제어기/장치 역할·장치 이름·구성 일치
드라이브제어·상태·속도 데이터 및 지원 텔레그램
추가 통신 모듈전기 규격·지원 프로토콜·자원

RJ45 커넥터가 보인다는 사실만으로 모든 Ethernet 프로토콜과 역할이 지원되는 것은 아닙니다. 두 물리 포트가 하나의 내장 스위치를 공유할 수도 있으므로 포트 수와 독립 인터페이스 수를 구분합니다.

IP·마스크·PROFINET 장치 이름·MAC 주소는 같은 정보가 아닙니다. 구체적인 프로젝트 생성과 주소 설정 절차는 9주차에서 다루며, 지금은 각 인터페이스의 역할을 도면에 표시합니다.

장치 검색이 가능하다는 사실은 수정 권한이나 변경 안전성을 의미하지 않습니다. 승인 없이 생산 네트워크에 연결하거나 IP·보호 설정을 바꾸지 않습니다.

가상 장치 I/O 목록과 수량 계획

아래는 소형 포장 장치의 교육용 가정입니다. 비상정지·안전문 등 안전 기능은 별도 설계이며 이 일반 I/O 수량표에 포함하지 않습니다.

종류가상 신호필요 채널
DI시작·일반 정지 요청·리셋 버튼3
DI입구·작업 위치·출구 제품 센서3
DI드라이브 준비·고장·가상 동작 확인3
DQ운전·완료·고장 표시와 가상 밸브 명령4
AI압력·온도 측정2
AQ가상 속도 지령1

합계는 DI 9점, DQ 4점, AI 2점, AQ 1점입니다. 이 수량은 최소 채널 요구만 나타내며 실제 모듈 선정 결과가 아닙니다.

내장 I/O를 빼고 확장 수량 계산

가상 CPU에 사용 가능한 DI 6점이 있고 DI 9점이 필요하면 3점이 부족합니다. 호환되는 가상 DI 모듈이 8채널이라면 최소 한 모듈이 필요하고 총 14채널 중 5채널이 남습니다.

같은 DI라도 센서 방식·전기 사양이 맞는 채널만 “사용 가능”으로 계산합니다. 모듈 수의 산술 계산은 슬롯·전원·호환성 검토를 대신하지 않습니다.

가상 채널 계산기 — 수량 계획 연습

필요 채널에서 사용 가능한 내장 채널을 빼고 부족분을 모듈 채널 수로 나누어 올림합니다. 브라우저 내부 산술 계산이며 실제 CPU 카탈로그와 연결하지 않습니다.

부족 채널: 3점 필요한 확장 모듈: 최소 1개 구성 후 총 채널: 14점 / 남는 채널: 5점

한 종류의 동일 신호만 계산합니다. DI·DQ·AI·AQ를 한 숫자로 합산해 계산하지 않습니다. 안전 I/O·이중화·예비율·슬롯·전원·성능 제약은 미포함입니다.

명판·구성도 관찰과 진단 체크리스트

  1. 전원이 차단된 실습 장치의 승인된 사진이나 제품 도면을 준비합니다. 실물 조작은 하지 않습니다.
  2. CPU·전원·I/O·통신 모듈을 찾아 역할을 적습니다.
  3. 주문번호와 펌웨어·문서 버전을 구분해 기록합니다.
  4. 입력·출력·전원·네트워크 정보 경로를 다른 색으로 표시합니다.
  5. 표시 LED의 이름과 뜻은 해당 매뉴얼에서 찾습니다.
관찰 현상확인할 방향바로 하면 안 되는 일
CPU 전원 표시 없음공급 계통·상태를 자격 있는 담당자에게 확인활선 단자 측정·임의 배선
CPU는 동작하지만 출력 부하 반응 없음부하 전원·명령·진단·인터페이스 정보 대조출력 강제부터 수행
모듈 불일치 진단실제 모델·슬롯·오프라인 구성 비교유사 모듈로 무단 교체
통신 장애장치 상태·링크·구성·주소·권한 확인방화벽 일괄 해제·생산망 임의 변경

표시등의 색만으로 원인을 단정하지 않습니다. 같은 색이라도 제품별 점등·점멸 의미가 다를 수 있으므로 LED 이름, 진단 메시지와 함께 읽습니다.

확인 문제와 다음 학습

1. CPU 전원이 켜지면 모든 출력 부하도 전원이 있나요?

아닙니다. 시스템·CPU 전원과 부하 전원은 구분해야 하며, 실제 공급 경로와 모듈 단자를 확인합니다.

2. 컴팩트형 CPU는 확장할 수 없나요?

반드시 그렇지 않습니다. 내장 I/O가 있으면서 확장을 지원하는 CPU도 있습니다. 모델별 확장 규칙을 확인합니다.

3. DI 8점과 AI 8점은 같은 모듈로 대체 가능한가요?

아닙니다. 채널 수뿐 아니라 신호 종류·전기 특성·측정 범위가 맞아야 합니다.

4. Static 변수면 전원 차단 후에도 항상 유지되나요?

아닙니다. 호출 사이 상태 유지와 전원 차단 후 데이터 유지 정책은 다릅니다.

5. 2포트 Ethernet이면 독립 인터페이스가 두 개인가요?

항상 그렇지 않습니다. 하나의 인터페이스에 2포트 스위치가 포함된 경우가 있으므로 데이터시트를 읽습니다.

6. DI 23점 필요, 내장 DI 6점, 모듈당 8점이면?

부족분은 17점이고 8채널 모듈은 최소 3개가 필요합니다. 총 30점이므로 7점이 남습니다. 실제 호환성·슬롯·전원 예산은 별도 확인합니다.

다음 주: 디지털·아날로그 I/O 및 센서 연결

이번 주에 구분한 모듈과 신호를 바탕으로 디지털 입력·출력, 센서 방식, 아날로그 전류·전압 신호를 학습합니다. 실제 연결은 대상 장치의 매뉴얼·전원·신호 범위를 일치시키는 데서 출발합니다.

2주차 핵심 정리

  • PLC 시스템은 전원·CPU·메모리·I/O·통신으로 구성됩니다.
  • 신호 연결과 전원 공급은 다른 경로입니다.
  • 시스템 전력 예산과 외부 부하 전류 예산을 따로 확인합니다.
  • 채널은 수량뿐 아니라 전기 특성·범위·출력 방식이 맞아야 합니다.
  • 확장은 슬롯·전원·호환성·통신 자원을 함께 검토합니다.
  • 계산기는 수량 학습 도구이며 실제 장치 선정·안전 검증을 대신하지 않습니다.
