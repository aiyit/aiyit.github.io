예제 9-1. 객체 생성과 메서드

JavaScript 초보자를 위한 설명: 객체, 속성, 메서드, this, do...while 반복문

1. 객체란 무엇인가요?

객체(Object)는 하나의 대상에 관한 정보와 기능을 묶어 놓은 자료입니다. 이 예제에서는 사람을 human이라는 객체로 표현합니다.

구분코드쉬운 설명
속성(Property)name: "Park"사람의 이름 정보
속성(Property)age: 40나이 정보
속성(Property)sex: "female"성별 정보
속성(Property)speed: 20현재 속도 값
메서드(Method)walk: function(){...}걷기 동작을 수행하는 함수
메서드(Method)run: function(){...}달리기 동작을 수행하는 함수
쉽게 말하면 속성은 객체가 가진 정보이고, 메서드는 객체가 할 수 있는 동작입니다. 객체는 중괄호 { } 안에 속성과 메서드를 함께 작성합니다.

2. 원본 코드와 줄별 설명

var human = {
    name: "Park",   // 이름 속성
    age: 40,        // 나이 속성
    sex: "female",  // 성별 속성
    speed: 20,      // 현재 속성 값(초기 속도)

    walk: function() {
        this.speed = 5;
    },              // 걷기 메서드: 속도를 5로 바꿈

    run: function() {
        this.speed += 3;
    }               // 달리기 메서드: 속도에 3을 더함
};

var human = { ... }은 human이라는 객체를 만들고 그 안에 정보와 동작을 저장합니다.

this.speed에서 this는 현재 메서드를 실행한 객체, 이 예제에서는 human을 가리킵니다. 따라서 this.speed += 3은 human.speed = human.speed + 3과 같은 뜻입니다.

주의: 이 예제는 객체 리터럴로 객체를 직접 만듭니다. 제목에 ‘객체 생성자’가 들어 있지만, function Human(){...} 형태의 생성자 함수와 new를 사용하는 코드는 아닙니다. 여기서는 객체와 메서드의 동작을 먼저 익힙니다.

3. 달리기 반복문 이해하기

do {
    document.write("이름:" + human.name
        + " 달리기:" + human.speed + "<br>");
    human.run();
} while (human.speed < 35);
  • do { ... } 안의 코드는 조건을 검사하기 전에 먼저 한 번 실행됩니다.
  • document.write(...)는 현재 이름과 속도를 웹페이지에 출력합니다.
  • human.run()을 호출하면 속도가 3 증가합니다.
  • while (human.speed < 35)는 속도가 35보다 작은 동안 반복합니다.

처음 속도는 20입니다. 반복할 때마다 먼저 현재 속도를 출력하고, 그다음 3을 더합니다.

출력 순서출력되는 속도출력 후 run() 실행
12023
22326
32629
42932
53235

속도가 35가 되면 조건 35 < 35가 거짓이므로 반복문이 종료됩니다. 따라서 마지막에 달리기 속도 35는 출력되지 않습니다.

핵심: do...while은 실행 → 조건 검사 순서입니다. 반면 일반적인 while은 조건 검사 → 실행 순서입니다.

4. 걷기 메서드 실행

human.walk();
document.write("이름:" + human.name
    + " 걷기:" + human.speed + "<br>");

달리기 반복문이 끝나면 human.walk()를 호출합니다. 걷기 메서드 안의 this.speed = 5가 실행되어 속도가 5로 바뀝니다. 마지막 출력은 이름: Park 걷기:5가 됩니다.
