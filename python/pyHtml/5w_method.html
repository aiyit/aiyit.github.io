파이썬 내장 메소드의 종류와 사용법

문자열, 리스트, 튜플, 딕셔너리, 세트, 숫자형까지 — 파이썬이 기본으로 제공하는 자료형별 내장 메소드를 실행 예제와 함께 자세히 정리합니다.

내장 메소드란

별도로 클래스를 정의하지 않아도, 자료형 자체가 이미 갖추고 있는 메소드입니다.

"hello".upper()처럼 값 뒤에 점(.)을 찍고 호출하는 모든 동작이 내장 메소드입니다. 각 자료형(str, list, tuple, dict, set, int, float 등)은 그 자료형의 성질에 맞춰 서로 다른 메소드 집합을 가지고 있습니다.

python
s = "python"
l = [1, 2, 3]
d = {"a": 1}

print(type(s), s.upper())     #  PYTHON
print(type(l), l.append(4))   #  None (l은 [1,2,3,4]로 변경됨)
print(type(d), d.get("a"))    #  1

# 자료형이 다르면 사용할 수 있는 메소드도 다르다
# s.append(1)  -> 오류! str에는 append가 없음

어떤 메소드를 쓸 수 있는지 궁금할 때는 내장 함수 dir(객체)로 목록을 확인하거나, help(str.upper)처럼 help()로 설명을 볼 수 있습니다.

가변(mutable) 자료형과 불변(immutable) 자료형

이 구분이 메소드의 동작 방식(원본 변경 여부)을 결정합니다.

불변 — str, tuple, frozenset 가변 — list, dict, set

불변 자료형의 메소드는 원본을 절대 바꾸지 못하고, 항상 새로운 값을 반환합니다. 가변 자료형의 메소드는 대부분 원본을 직접 수정하며 None을 반환하는 경우가 많습니다.

python
s = "abc"
s.upper()          # 새 문자열 "ABC"를 만들 뿐, s 자신은 그대로 "abc"
print(s)            # abc

l = [3, 1, 2]
l.sort()            # 원본 l 자체를 정렬함
print(l)            # [1, 2, 3]
흔한 실수
s = s.upper()처럼 재할당해야 불변 객체의 변경 결과를 반영할 수 있습니다. 반대로 l = l.sort()는 l을 None으로 만들어버리는 실수이니 주의하세요.

문자열 메소드 — 대소문자 · 공백 처리str

메소드기능
upper()모두 대문자로
lower()모두 소문자로
capitalize()첫 글자만 대문자, 나머지 소문자
title()단어마다 첫 글자를 대문자로
swapcase()대소문자를 서로 반전
strip([chars])양쪽 공백(또는 지정 문자) 제거
lstrip() / rstrip()왼쪽 / 오른쪽만 제거
zfill(width)왼쪽을 0으로 채워 길이를 맞춤
python
title = "python programming"
print(title.title())        # Python Programming

score = "7"
print(score.zfill(3))       # 007

raw = "   note   "
print(raw.strip())          # "note"

문자열 메소드 — 검색 · 치환str

메소드기능
find(sub)위치 반환, 없으면 -1
index(sub)위치 반환, 없으면 예외 발생
count(sub)등장 횟수
replace(old, new)부분 문자열 치환
startswith(sub) / endswith(sub)접두 / 접미 여부
python
log = "2026-09-09 ERROR: connection lost"

print(log.find("ERROR"))            # 11
print(log.count("o"))               # 3
print(log.replace("ERROR", "INFO")) # 2026-09-09 INFO: connection lost
print(log.startswith("2026"))       # True

문자열 메소드 — 분리 · 결합str

메소드기능
split(sep)구분자로 나눠 리스트 반환
rsplit(sep, n)오른쪽부터 n번만 분리
splitlines()줄바꿈 기준으로 분리
join(iterable)리스트 등을 구분자로 이어붙임
partition(sep)구분자를 기준으로 (앞, 구분자, 뒤) 3분할
python
csv_line = "지훈,22,AI소프트웨어과"
fields = csv_line.split(",")            # ['지훈', '22', 'AI소프트웨어과']

rebuilt = " / ".join(fields)             # "지훈 / 22 / AI소프트웨어과"

path = "config.backup.json"
name, dot, ext = path.partition(".")     # ("config", ".", "backup.json")

문자열 메소드 — 판별(is___)str

문자열의 성격을 True/False로 검사하는 메소드로, 입력값 검증에 자주 쓰입니다.

메소드True가 되는 조건
isdigit()모든 문자가 숫자
isalpha()모든 문자가 알파벳(문자)
isalnum()모든 문자가 문자 또는 숫자
isspace()모든 문자가 공백
isupper() / islower()전부 대문자 / 전부 소문자
python
def get_age(text):
    if not text.isdigit():
        raise ValueError("숫자만 입력하세요")
    return int(text)

print(get_age("22"))     # 22
# get_age("스물둘")      # ValueError 발생

리스트 메소드 — 요소 추가list · mutable

메소드기능
append(x)맨 끝에 요소 하나 추가
extend(iterable)다른 반복 가능 객체의 요소들을 이어붙임
insert(i, x)i번째 위치에 삽입
python
tasks = ["설계"]
tasks.append("구현")            # ['설계', '구현']
tasks.extend(["테스트", "배포"]) # ['설계', '구현', '테스트', '배포']
tasks.insert(1, "검토")          # ['설계', '검토', '구현', '테스트', '배포']
append vs extend
append([1,2])는 리스트 자체를 하나의 요소로 추가하지만, extend([1,2])는 그 안의 요소 1, 2를 각각 풀어서 추가합니다.

리스트 메소드 — 요소 삭제list · mutable

메소드기능
pop(i)i번째 요소 제거 후 반환 (기본값: 마지막)
remove(x)값이 x인 첫 요소 제거 (없으면 예외)
clear()모든 요소 제거
python
queue = ["A", "B", "C"]

first = queue.pop(0)     # first = "A", queue = ['B', 'C']
queue.remove("C")         # queue = ['B']
queue.clear()             # queue = []

리스트 메소드 — 정렬 · 순서list · mutable

메소드기능
sort(key=None, reverse=False)원본을 오름차순(기본) 정렬
reverse()순서를 완전히 뒤집음
python
members = [("지훈", 22), ("서연", 20), ("민재", 25)]

members.sort(key=lambda m: m[1])          # 나이 기준 오름차순
print(members)   # [('서연', 20), ('지훈', 22), ('민재', 25)]

members.sort(key=lambda m: m[1], reverse=True)  # 내림차순
sort()는 None을 반환합니다
원본을 유지한 채 정렬된 새 리스트가 필요하면 메소드가 아닌 내장 함수 sorted(members)를 사용하세요.

리스트 메소드 — 탐색 · 복사list · mutable

메소드기능
index(x)값 x의 위치 반환 (없으면 예외)
count(x)값 x의 등장 횟수
copy()얕은 복사본 생성
python
grades = [90, 85, 90, 70]
print(grades.index(90))   # 0
print(grades.count(90))   # 2

backup = grades.copy()    # 원본과 독립된 새 리스트
backup.append(100)
print(grades, backup)     # [90, 85, 90, 70] [90, 85, 90, 70, 100]

튜플 메소드tuple · immutable

튜플은 불변이므로 요소를 추가·삭제하는 메소드가 없고, 조회용 메소드 단 두 개만 제공합니다.

메소드기능
count(x)값 x의 등장 횟수
index(x)값 x의 위치 반환
python
rgb = (255, 0, 0, 0, 255)
print(rgb.count(0))    # 2
print(rgb.index(255))  # 0

# rgb.append(10)  -> 오류! 튜플은 append를 지원하지 않음
왜 튜플을 쓰는가
메소드가 적어 불편해 보이지만, 값이 실수로 바뀌지 않아야 하는 좌표·설정값 등을 안전하게 담을 때 유용합니다. 딕셔너리의 키로도 사용할 수 있다는 점(리스트는 불가능)도 불변성 덕분입니다.

딕셔너리 메소드 — 조회dict · mutable

메소드기능
get(key, default)키가 없어도 예외 없이 default 반환
keys()키만 모은 뷰(view) 반환
values()값만 모은 뷰 반환
items()(키, 값) 쌍의 뷰 반환
python
panel = {"code": "A-101", "voltage": 220}

print(panel.get("voltage"))        # 220
print(panel.get("current", 0))     # 0  (없는 키 -> 기본값)

for key, value in panel.items():
    print(f"{key} = {value}")

딕셔너리 메소드 — 추가 · 수정 · 삭제dict · mutable

메소드기능
update(other)다른 딕셔너리 내용으로 갱신·추가
setdefault(key, default)키가 없으면 default로 설정 후 반환
pop(key)키 제거 후 값 반환
popitem()마지막에 추가된 (키,값) 쌍 제거·반환
clear()모든 항목 제거
python
settings = {"volume": 50}

settings.update({"volume": 80, "brightness": 70})
settings.setdefault("mode", "auto")     # 키 없을 때만 추가

removed = settings.pop("brightness")     # 70
print(settings)   # {'volume': 80, 'mode': 'auto'}

세트 메소드 — 집합 연산set · mutable

메소드연산자기능
union()|합집합
intersection()&교집합
difference()-차집합
symmetric_difference()^둘 중 하나에만 있는 요소
issubset() / issuperset()-부분집합 / 상위집합 여부
python
python_class = {"지훈", "서연", "민재"}
ai_class = {"서연", "하은"}

print(python_class & ai_class)     # {'서연'}  두 수업 모두 듣는 학생
print(python_class | ai_class)     # 합집합
print(python_class - ai_class)     # 파이썬 수업만 듣는 학생

세트 메소드 — 추가 · 삭제set · mutable

메소드기능
add(x)요소 하나 추가 (이미 있으면 무시)
remove(x)요소 제거, 없으면 예외 발생
discard(x)요소 제거, 없어도 예외 없음
python
tags = {"python", "ai"}
tags.add("python")       # 중복 -> 변화 없음, {'python', 'ai'}
tags.discard("java")      # 없는 값이어도 에러 없음

숫자형 메소드int · float

숫자형은 메소드보다 연산자 사용이 많지만, 몇 가지 유용한 내장 메소드가 있습니다.

메소드기능
is_integer()float 값이 정수와 같은 값인지 판별
bit_length()정수를 이진수로 표현했을 때 필요한 비트 수
as_integer_ratio()분수 형태 (분자, 분모)로 반환
python
voltage = 220.0
print(voltage.is_integer())   # True

value = 37
print(value.bit_length())     # 6  (100101 -> 6비트)

한눈에 정리

자료형성격대표 메소드
str불변upper, split, join, find, replace
list가변append, extend, pop, sort, remove
tuple불변count, index
dict가변get, keys, items, update, pop
set가변union, intersection, add, discard
int / float불변is_integer, bit_length

내장 메소드를 고를 때는 먼저 다루려는 값의 자료형과, 원본을 바꿔야 하는지 새 값이 필요한지 두 가지만 확인하면 됩니다. 불변 자료형은 항상 새 값을 반환하고, 가변 자료형은 대부분 원본을 직접 수정합니다.
