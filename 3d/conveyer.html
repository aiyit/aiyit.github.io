설비 설명서

MCCB
전기 설비의 전원 차단 및 보호 (제어반 MCCB 손잡이 또는 제어 패널의 MCCB 버튼으로 ON/OFF). OFF이면 PLC·출력·타워램프가 모두 꺼지고 E-STOP도 동작하지 않음
24V DC SMPS
제어 회로에 필요한 DC 전원 공급
PLC
입력 신호를 받아 프로그램에 따라 출력 장치를 제어
릴레이 (K1)
PLC 출력(Y0) 신호로 모터 회로를 개폐
포토센서
제품의 위치 또는 통과 여부만 감지 (제품 도착 신호). 감지되면 컨베이어가 잠시 멈추고 비전 검사가 진행됨
비전 검사 장치
카메라로 제품 외관을 검사해 불량(NG)이면 PLC에 신호 전달
모터
컨베이어 구동
솔레노이드 밸브
공압 실린더 동작 제어
실린더
불량품을 옆의 불량품 통(REJECT BIN)으로 밀어내 배출
START / STOP
라인 가동 시작·정지 (START는 PLC 입력 X0). E-STOP 작동, MCCB OFF, 안전가드 도어 열림 상태에서는 START가 잠김
Emergency Stop
비상 상황에서 설비 정지 (누르면 래치되어 유지, 해제 후 START를 눌러야 재가동)
타워램프
설비 상태 표시 (PLC 출력 Y2): 녹색 = 가동 중, 황색 점멸 = 센서 감지·검사 중, 적색 점등 = 정상 정지, 적색 점멸 = 비상(E-STOP 작동 또는 안전가드 도어 열림). MCCB OFF이면 모두 소등
안전가드
작업자가 구동부(모터·구동 롤러·벨트 끝단)에 접근하는 것을 방지. 도어를 열면 인터락 스위치(X4)가 OFF되어 설비가 즉시 정지하고, 도어를 닫아도 START를 눌러야 재가동 (자동 재기동 방지)
⚡ 회로도 보기
평소에는 숨겨져 있는 제어반 내부 각 부품(MCCB·SMPS·PLC CPU·I/O모듈·릴레이·단자대)의 세부 회로도를 켜고 끌 수 있는 토글 버튼. 켜면 각 부품 앞에 블록 다이어그램이 떠서 내부 구성과 신호 흐름을 확인할 수 있음
작업자 점검 시연
목적: 점검·정비를 위해 안전가드 도어를 열었을 때 설비가 어떻게 보호되는지, 작업자의 접근부터 퇴장까지 단계별로 보여 주는 안전 교육용 시연입니다.
학습 포인트: ① 도어 열림 = 인터락 X4 OFF → 모터 출력 Y0 차단(즉시 정지) ② 도어가 열린 동안 START 잠금 ③ 도어를 닫아도 자동 재기동 없음(START 필요) ④ 바닥 해저드 표시로 위험구역 인지
사용법: MCCB ON · E-STOP 해제 · 도어 닫힘 상태에서 [작업자 점검 시연] 버튼을 누르면 카메라가 이동하고 화면 하단에 단계별 설명이 표시됩니다. 라인이 정지 상태이면 시연 시작 시 자동으로 가동되며, 시연 중에는 도어를 직접 조작할 수 없습니다. 설명을 탭하면 일시정지/계속할 수 있습니다.

PLC I/O 정리

제어반의 DIGITAL INPUT / OUTPUT 모듈 LED는 해당 신호가 ON일 때 켜집니다.
입력장치핵심 동작
X0STARTSTART를 누르면 ON → 라인 가동 시작
X1PHOTO SENSOR제품이 센서 위치에 도착하면 ON → 컨베이어 정지 후 비전 검사 시작
X2EMERGENCY STOPE-STOP을 누르면 ON → 모터 출력 차단, 설비 정지
X3VISION NG비전이 불량(NG)으로 판정하면 ON → 불량품 배출 동작
X4GUARD CLOSED안전가드 도어가 닫혀 있으면 ON, 열리면 OFF → 설비 정지·START 잠금
출력장치핵심 동작
Y0MOTOR컨베이어 모터 구동 (릴레이 K1 경유). 제품 검사 중, E-STOP, 도어 열림 시 OFF
Y1SOLENOID솔레노이드 밸브 작동 → 실린더가 불량품을 밀어내 배출
Y2TOWER LAMP타워램프 출력(녹색 Y2 / 황색 Y3 / 적색 Y4). 가동=녹색, 센서 검사 중=황색, 정지=적색, 알람=적색 점멸. 제어반 LED는 셋 중 하나라도 켜지면 점등
RUN LED: PLC가 가동 상태일 때 점등
래더 1: (X0 START 또는 Y0 자기유지) + /X2 + X4 GUARD 닫힘 → Y0 MOTOR
자기유지: START를 한 번만 눌러도 모터 출력이 유지됨. /X2는 E-STOP을 누르지 않았을 때 연결되는 접점
래더 2: X1 PHOTO SENSOR + X3 VISION NG → Y1 SOLENOID
제품이 도착했고 비전이 불량으로 판정했을 때만 배출 실린더 작동

스마트 팩토리 기능

라인 탭 (1·2·3)
조작·카운터·PLC 표시 대상 라인을 선택합니다. 라인마다 PLC 입출력 블록(16점)이 따로 있습니다 (LINE 1 = X0~ / Y0~, LINE 2 = X16~ / Y16~ …).
PLC 구조
PLC 엔진이 20ms 주기로 입력 읽기 → 래더 실행 → 출력 쓰기를 반복합니다. 3D 장치는 PLC 출력(Y)만 따르고, 센서·버튼 신호(X)를 PLC에 넣을 뿐입니다. PASS/DEFECT 카운터도 PLC 카운터입니다.
원격 I/O 스테이션
LINE 2·3은 라인 옆 원격 I/O 패널(LED·누름버튼)이 설비 네트워크(청록 케이블)로 중앙 PLC 제어반과 연결됩니다.
FACTORY DASHBOARD
라인별 상태·양품·불량·수율·분당 생산량·가동률과 알람 이력을 표시합니다. 행을 누르면 해당 라인이 선택됩니다.
모터 과부하
열동계전기 트립을 모의합니다. X8이 OFF 되어 라인이 정지하고 알람이 기록됩니다. 해제 후 START로 복귀합니다.
통 비우기
불량품 통이 가득 차면 레벨 스위치(X9)가 동작해 배출 사이클이 끝난 뒤 라인이 멈춥니다. 통을 비우고 START 하세요.
I/O 표
선택한 라인의 입력·출력·내부 메모리 비트를 실시간으로 확인합니다.
※ 본 화면은 PLC I/O 시뮬레이션이며 실제 PLC와 통신하지 않습니다.
