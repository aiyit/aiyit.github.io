3단계 프롬프트 작성법

글쓰기, HTML 문서, 프로그램, 이미지, 동영상 등 어떤 미디어를 만들든 핵심은 같습니다. 목표를 정하고(Aim), 조건과 맥락을 설명하고(Provide context), 결과 형식을 지정한다(Template). 이 페이지에서는 이를 A-P-T 3단계로 연습합니다.

1

A — Aim: 목적

AI에게 무엇을 만들어 달라는지 구체적인 동사로 시작합니다. 예: 작성, 분석, 수정, 비교, 생성, 디버깅.

2

P — Provide context: 조건·맥락

대상, 수준, 자료, 환경, 스타일, 분량, 제한 사항을 알려 줍니다. 모르는 사실은 지어내지 말라고 지정할 수 있습니다.

3

T — Template: 결과 형식

표, 단계별 절차, 전체 HTML 코드, 실행 가능한 파일, 이미지 비율, 영상 길이·장면 구성처럼 결과물의 형태를 정합니다.

기억할 공식: “무엇을 만들지 + 어떤 조건으로 만들지 + 어떤 형태로 받을지.” 첫 결과가 부족하면 빠진 조건을 추가해 다시 요청합니다.

미디어별 최적화 프롬프트 비교표

아래 예시는 그대로 복사해 시작할 수 있는 기본형입니다. 대괄호 안의 내용을 자신의 주제와 조건으로 바꾸세요.

미디어·작업1단계: 목적(Aim)2단계: 조건·맥락(Provide context)3단계: 결과 형식(Template)추가로 지정하면 좋은 항목
글쓰기·보고서[주제]에 대한 글을 작성해 주세요.독자는 [대상], 목적은 [설명/설득/보고], 문체는 [전문적/친근한], 분량은 [글자 수]입니다. 제공 자료 밖의 사실은 추측하지 마세요.제목, 도입, 소제목이 있는 본문, 결론 순서로 작성하고 핵심 요점을 마지막에 정리하세요.독자 수준, 근거·출처, 문체, 분량, 금지 표현
HTML 문서·웹페이지[주제]를 설명하는 교육용 HTML 페이지를 만들어 주세요.학습자는 HTML 초보자입니다. 모바일 반응형, 접근성, 읽기 쉬운 한국어를 적용하고 [색상/디자인]을 사용하세요. 외부 라이브러리는 [허용/금지]입니다.완성된 전체 HTML 파일을 하나의 코드 블록으로 출력하세요. CSS와 JavaScript를 포함하고 저장 파일명은 [파일명.html]로 안내하세요.기존 파일 유지 여부, 브라우저, 반응형, 버튼 동작, 콘솔 오류 확인
프로그램 작성·디버깅[기능]을 수행하는 [Python/JavaScript 등] 프로그램을 작성하거나 오류를 수정해 주세요.실행 환경은 [버전/OS], 입력은 [예시], 출력은 [예시]입니다. 초보자도 이해할 수 있게 주석을 달고 기존 기능은 유지하세요.전체 코드, 실행 방법, 예상 출력, 테스트 사례 3개, 오류 처리 설명 순서로 답하세요. 수정 작업이면 변경점도 요약하세요.언어·버전, 입력/출력, 예외 상황, 성능, 테스트, 기존 코드
이미지 생성[주제와 장면]을 표현한 이미지를 생성해 주세요.주요 대상은 [대상], 배경은 [장소], 분위기는 [감성/사실적/판타지], 조명은 [종류], 색감은 [팔레트], 시점은 [각도]입니다.가로형 16:9 또는 세로형 9:16, 고해상도 이미지로 생성하세요. 이미지 안에 글자는 [넣지 않기/정확한 문구만 넣기]로 설정하세요.대상·행동, 배경, 구도, 카메라, 조명, 재질, 색감, 비율, 제외할 요소
동영상 생성[주제]를 담은 [초] 길이의 짧은 영상을 만들어 주세요.장면은 [장소/시간], 대상은 [대상], 움직임은 [구체적 동작], 카메라는 [고정/천천히 이동/따라가기], 분위기는 [스타일]입니다.장면별 타임라인을 작성하고 각 장면의 시작·끝 동작, 카메라 움직임, 전환, 화면 비율을 지정하세요. 대사·자막·음악은 [조건]으로 처리하세요.길이, 초당 프레임, 화면비, 동작 연속성, 카메라 이동, 사운드, 장면 전환
발표자료·슬라이드[주제]로 발표자료를 만들어 주세요.청중은 [대상], 발표 시간은 [분], 슬라이드 수는 [장], 핵심 메시지는 [메시지]입니다.각 슬라이드마다 제목, 핵심 문장 3개 이하, 추천 시각자료, 발표자 노트를 표로 작성하세요.발표 시간, 슬라이드 수, 핵심 메시지, 시각자료, 출처
데이터 분석·시각화[데이터]를 분석해 [질문]에 답해 주세요.열의 의미는 [설명], 분석 대상 기간은 [기간], 결측값은 [처리 방식]입니다. 상관관계를 인과관계로 단정하지 마세요.데이터 정리, 분석 방법, 결과 표, 적절한 그래프, 해석, 한계 순서로 제시하세요. 코드가 필요하면 재현 가능한 전체 코드를 포함하세요.데이터 사전, 결측치, 단위, 표본 수, 그래프 목적, 한계
음성·내레이션[주제]에 대한 내레이션 대본을 작성해 주세요.청취자는 [대상], 톤은 [차분/활기/전문적], 길이는 [초/분], 발음이 어려운 용어는 [설명 방식]으로 처리하세요.말하기 자연스러운 문장으로 작성하고, 문단별 예상 시간과 [쉼표/강조/발음 지침]을 표시하세요.청취자, 말하기 속도, 감정, 발음, 휴지, 배경음
웹툰·스토리보드[주제]의 짧은 웹툰 또는 영상 스토리보드를 구성해 주세요.등장인물은 [특징], 배경은 [장소], 장르는 [장르], 분위기는 [분위기]이며 캐릭터 외형과 의상은 모든 장면에서 일관되게 유지하세요.컷 번호, 장면 설명, 인물 행동, 대사, 카메라 구도, 이미지 프롬프트를 표로 작성하세요.캐릭터 시트, 컷 수, 대사 길이, 장면 연결, 시각적 일관성
자료 조사·검색[질문]에 대한 최신 정보를 조사해 주세요.기간은 [기간], 지역·범위는 [범위], 신뢰할 자료의 우선순위는 [공식 문서/논문/통계]입니다. 확인할 수 없는 내용은 불확실하다고 표시하세요.핵심 요약, 비교표, 출처 링크와 날짜, 확인이 필요한 쟁점으로 정리하세요.기간, 출처 품질, 발행일, 원문 링크, 사실과 해석 구분

실습: 나만의 프롬프트 만들기

목표·조건·결과 형식을 입력하면 하나의 프롬프트로 합쳐집니다. 완성된 문장을 복사해 원하는 AI 서비스에 붙여 넣으세요.

좋은 프롬프트인지 확인하기

점검 항목확인 질문개선 예시
목적이 명확한가?“좋게 만들어 줘”보다 구체적인 결과를 요청했나요?“학생용 HTML 실습 페이지를 만들어 줘.”
맥락이 충분한가?누가 사용할지, 어떤 환경인지, 무엇을 피해야 하는지 적었나요?“프로그래밍 초보자 대상, 모바일에서도 동작, 외부 라이브러리 없이.”
형식이 명확한가?표·코드·파일·비율·길이 등 결과 기준이 있나요?“전체 HTML을 제공하고 실행 절차와 테스트 방법을 덧붙여 줘.”
검증 방법이 있는가?사실 확인, 실행 테스트, 결과 검토 기준을 지정했나요?“오류 가능성과 한계를 표시하고 테스트 사례 3개를 포함해 줘.”
실무 팁: 프롬프트를 한 번에 완벽하게 작성하려고 하기보다 ① 초안 생성 → ② 부족한 점 확인 → ③ 조건을 구체화해 재요청 → ④ 결과 검증의 순환으로 개선하세요. 이미지·영상은 대상과 움직임을 구체적으로, 코드는 실행 환경과 입력·출력을 구체적으로 지정하는 것이 특히 중요합니다.
