예제 9-16: JavaScript Array 메소드 실습 분석 보고서

본 문서는 JavaScript 배열(Array) 객체가 제공하는 다양한 조작 메서드(concat, indexOf, join, pop, push, shift, slice, sort, splice)의 동작 원리와 배열 데이터 변화 과정을 분석한 내용입니다.

1. HTML 전체 소스코드

<!DOCTYPE html>
<html>
<head>
    <meta charset="utf-8">
    <title>예제 9-16 Array 메소드</title>
</head>
<body>
    <h3>Array 메소드 실습</h3>
    <script>
        var cars = ["Hyundai", "Kia", "Bens"];
        var num = [1, 2, 3, 4];
        var week = ["Mon", "Thu", "Wen"];

        var concatResult = cars.concat(num);
        var indexResult = week.indexOf("Thu");
        var joinResult = num.join("*");
        var popResult = num.pop(); // 마지막 요소 제거
        week.push("Thr");          // 요소 추가
        var pushResult = week;
        var shiftResult = num.shift(); // 첫 요소 제거
        var sliceResult = num.slice(1, 3); // 복사된 부분
        var sortResult = cars.sort();      // 정렬
        cars.splice(1, 0, "BMW");          // 삽입
        var spliceResult = cars;

        document.write("cars.concat(num): " + concatResult + "<br>");
        document.write("week.indexOf('Thu'): " + indexResult + "<br>");
        document.write("num.join('*'): " + joinResult + "<br>");
        document.write("num.pop(): " + popResult + " → [" + num + "]<br>");
        document.write("week.push('Thr'): [" + pushResult + "]<br>");
        document.write("num.shift(): " + shiftResult + " → [" + num + "]<br>");
        document.write("num.slice(1,3): [" + sliceResult + "]<br>");
        document.write("cars.sort(): [" + sortResult + "]<br>");
        document.write("cars.splice(1, 0, 'BMW'): [" + spliceResult + "]<br>");
    </script>
</body>
</html>

2. HTML 구조 및 DOM 요소 설명

  • <script> 내 document.write 방식: DOM 요소를 별도의 id로 지정하여 바인딩하는 기존 방식과 달리, JavaScript 실행 흐름 중에서 브라우저 화면(문서 본문)에 직접 문자열을 출력하는 전통적인 방식을 사용하고 있습니다.

3. JavaScript Array 주요 메서드 상세 분석

메서드명 사용 예시 동작 설명 및 결과
concat() cars.concat(num) 두 개 이상의 배열을 결합하여 새로운 배열을 반환합니다. ➔ Hyundai,Kia,Bens,1,2,3,4
indexOf() week.indexOf("Thu") 지정한 요소가 처음으로 나타나는 인덱스 번호를 반환합니다. ➔ 1
join() num.join("*") 배열의 모든 요소를 지정한 구분자(*)로 연결해 하나의 문자열로 반환합니다. ➔ 1*2*3
pop() num.pop() 배열의 마지막 요소를 제거하고 그 요소를 반환합니다. (남은 배열 변화: [1, 2, 3])
push() week.push("Thr") 배열의 마지막에 새로운 요소를 추가합니다. ➔ Mon,Thu,Wen,Thr
shift() num.shift() 배열의 첫 번째 요소를 제거하고 그 요소를 반환합니다. (남은 배열 변화: [2, 3])
slice() num.slice(1, 3) 지정한 구간(인덱스 1부터 3 전까지)의 요소를 추출하여 새 배열을 만듭니다. ➔ [3]
sort() cars.sort() 배열의 요소들을 알파벳 순서대로 정렬합니다. ➔ [Bens, Hyundai, Kia]
splice() cars.splice(1, 0, "BMW") 특정 인덱스(1번)에서 요소를 제거(0개)하거나 새로운 요소("BMW")를 삽입합니다. ➔ [Bens, BMW, Hyundai, Kia]
