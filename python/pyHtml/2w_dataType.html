자료형. Data Type

파이썬이 데이터를 저장·처리하는 8가지 자료형 — 정수, 실수, 문자열, 논리형부터 리스트·튜플·딕셔너리·집합까지 실습 코드와 함께 정리한 2주차 강의 자료입니다.

01

자료형(Data Type)이란?

자료형(Data Type)이란 프로그램에서 데이터를 저장하고 처리하는 방식을 의미합니다. 컴퓨터는 모든 데이터를 0과 1의 이진수로 처리하지만, 프로그래밍 언어에서는 데이터를 효율적으로 다루기 위해 정수, 실수, 문자열, 논리값 등 다양한 자료형을 제공합니다.

나이
정수 (int)
키
실수 (float)
이름
문자열 (str)
합격 여부
논리형 (bool)

진법이란?

진법(Number System)은 수를 표현할 때 사용하는 자릿수의 기준(밑, base)을 의미합니다. 밑의 크기만큼의 숫자(0부터 밑-1까지)를 사용해 자릿값을 표현합니다.

10진수 (Decimal)
밑(base) = 10
사용 숫자: 0 ~ 9
파이썬 표현: 그대로 사용
45
2진수 (Binary)
밑(base) = 2
사용 숫자: 0, 1
파이썬 표현: 0b 접두사
0b101101
8진수 (Octal)
밑(base) = 8
사용 숫자: 0 ~ 7
파이썬 표현: 0o 접두사
0o55
16진수 (Hexadecimal)
밑(base) = 16
사용 숫자: 0~9, A~F
파이썬 표현: 0x 접두사
0x2D
💡 네 가지 표현 모두 같은 값(45)입니다. 진법이 달라져도 수가 나타내는 실제 값은 동일하며, 표현 방식(자릿수 구성)만 다릅니다.

진법 변환 함수 — bin(), oct(), hex(), int()
convert.py
# 10진수 -> 2진수, 8진수, 16진수 변환
num = 45

print(bin(num))   # '0b101101'
print(oct(num))   # '0o55'
print(hex(num))   # '0x2d'

# 다른 진법 문자열 -> 10진수로 변환 (int(문자열, 밑))
print(int("101101", 2))   # 2진수 -> 10진수 = 45
print(int("55", 8))       # 8진수 -> 10진수 = 45
print(int("2d", 16))      # 16진수 -> 10진수 = 45
변환 방법 예제 — 10진수를 2진수로 직접 변환 (나눗셈 방식)

10진수를 2로 계속 나누어 몫이 0이 될 때까지 반복하고, 나머지를 거꾸로 읽으면 2진수가 됩니다. bin() 함수 없이 직접 변환 원리를 구현한 예제입니다.

decimal_to_binary.py
# 10진수 -> 2진수 변환 (나눗셈-나머지 방식, 직접 구현)
num = 45
result = ""

n = num
while n > 0:
    remainder = n % 2      # 2로 나눈 나머지
    result = str(remainder) + result   # 나머지를 앞쪽에 붙임
    n = n // 2             # 몫을 다음 계산값으로

print(f"{num}(10진수) -> {result}(2진수)")

# bin() 함수 결과와 비교 검증
print("bin() 결과 :", bin(num))

숫자를 2진수(비트) 단위로 계산하는 연산자입니다. 하드웨어 제어, 플래그 처리 등에 자주 사용됩니다.

&
AND
|
OR
^
XOR
~
NOT
<<

>>

bitwise1.py
# 비트 AND, OR, XOR
a = 12   # 0b1100
b = 10   # 0b1010

print(a & b)   # AND -> 8  (0b1000)
print(a | b)   # OR  -> 14 (0b1110)
print(a ^ b)   # XOR -> 6  (0b0110)
bitwise2.py
# 시프트 연산 - 2의 거듭제곱 계산
num = 3

print(num << 1)   # 왼쪽으로 1비트 이동 -> 2배
print(num << 2)   # 왼쪽으로 2비트 이동 -> 4배

value = 40
print(value >> 1)  # 오른쪽으로 1비트 이동 -> 절반

in

not in

result2 = (2 + 3) * 4
print(result2)          # 괄호가 가장 먼저 계산됨 = 20
# 비교 · 논리 · in 연산자 우선순위
score = 85
grade = "B"

# 비교(>) -> in -> and 순서로 계산됨
result = score > 80 and grade in ["A", "B", "C"]
print(result)

# not은 and/or보다 우선순위가 높음
check = not score < 60 and grade == "B"
print(check)
연산자 우선순위 (Operator Precedence)
한 식에 여러 종류의 연산자가 함께 쓰이면 우선순위가 높은 연산자부터 먼저 계산됩니다. 숫자가 작을수록 우선순위가 높습니다.
