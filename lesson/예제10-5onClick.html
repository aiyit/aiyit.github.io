예제 10-5: onClick 이벤트 핸들러 분석 보고서

본 문서는 웹 페이지에서 사용자의 마우스 클릭 상호작용을 감지하고 이에 반응하여 동적으로 화면을 제어하는 `onclick` 이벤트 핸들러의 개념과 동작 방식을 설명합니다.

1. onClick 이벤트 핸들러 개념 및 동작 방식 이해

이벤트(Event)란 웹 브라우저에서 발생하는 사용자의 행동(클릭, 키보드 입력, 마우스 이동 등)이나 브라우저의 상태 변화(페이지 로딩 완료 등)를 의미합니다. 이벤트 핸들러(Event Handler)는 특정 이벤트가 발생했을 때 실행될 JavaScript 함수나 코드를 지정하는 속성입니다.

💡 핵심 포인트 (`onclick`): 사용자가 HTML 요소(버튼, 텍스트, 이미지 등)를 마우스로 클릭할 때 발생하며, 인라인(Inline) 방식으로 HTML 태그 안에 직접 작성하거나 스크립트 함수와 연동하여 동작합니다.

1) 프로그램 주요 동작 방식

  • 인라인 직접 제어 (`this` 키워드 활용): <h4 onclick="this.innerHTML='...'">와 같이 별도의 함수 호출 없이 요소 자체를 가리키는 this를 이용해 클릭 즉시 내용을 바꿉니다.
  • 함수 연동 제어 (`onclick="함수명()"`): <input type="button" onclick="changeText();">처럼 버튼이나 일반 태그에 클릭 이벤트를 걸어 <script> 내부에 정의된 커스텀 함수를 실행합니다.

2. 제공된 HTML 원본 코드

<!DOCTYPE html>
<html>
<head>
<link rel="stylesheet" href="style.css">   
<meta charset="utf-8">
<title>예제 10-5 onClick()</title>
<script>
    function changeText(){
        document.getElementById("one").innerHTML = "입력타입을 눌렀군요!"
    }
    function changeButton(){
        document.getElementById("bttn").innerHTML = "버튼을 눌렀군요!"
    }
</script>
</head>
<body id="main">
    <h3 id="one" style="text-align:center;">onClick()</h3>
    <h4 onclick="this.innerHTML='나를 눌렀군요!!'">Click me!!</h4>
    <h3 id="bttn">Button</h3>
    <input type="button" id="bt1" value="onClick" onclick="changeText();">
    <button onclick="changeButton()">눌러봐!!</button>
</body>
</html>

3. 주요 코드 요소 및 동작 상세 분석

코드 패턴 사용 예시 동작 설명 및 특징
인라인 이벤트와 this <h4 onclick="this.innerHTML='...'"> 별도의 함수 정의 없이 이벤트가 발생한 바로 그 요소를 this로 참조하여 즉각적으로 내용을 수정합니다. 간단한 텍스트 변경에 유용합니다.
입력 버튼(Input) 이벤트 <input type="button" onclick="changeText();"> 클릭 가능한 버튼 컴포넌트에 onclick을 지정하여 document.getElementById("one") 요소를 찾아 문구를 변경합니다.
일반 버튼(Button) 이벤트 <button onclick="changeButton()">눌러봐!!</button> HTML5 표준 <button> 태그를 사용하여 클릭 시 changeButton() 함수를 호출하고 대상 요소를 갱신합니다.

핵심 정리

    이벤트(Event): 사용자의 마우스 클릭 등의 상호작용 이벤트 핸들러(onclick): 클릭 발생 시 실행될 동작을 매핑하는 속성 동적 화면 갱신: 이벤트 발생 ➔ 핸들러 호출 ➔ DOM 요소 내용 변경(innerHTML) 과정으로 사용자에게 즉각 피드백 제공

학습 포인트: 정적인 웹 페이지에 사용자의 마우스 클릭 반응을 부여하는 이벤트 처리의 가장 기초적이고 핵심적인 구조를 익힙니다.
