동영상 생성 프롬프트와 필수 기법

대상과 행동부터 카메라, 조명, 시간 흐름까지 명확하게 지시해 원하는 동영상에 가까워지는 방법을 익힙니다.

학습 목표

좋은 동영상 프롬프트의 구성

동영상 프롬프트는 단순히 무엇을 보여 달라고 말하는 데서 끝나지 않습니다. 무엇이 어디에서 어떻게 움직이는지, 카메라가 어떻게 촬영하는지, 빛과 분위기는 어떤지, 장면이 어떻게 시작하고 끝나는지를 구체적으로 설명합니다.

대상과 배경

인물·사물·장소·시간대

행동과 움직임

대상의 동작과 속도, 방향

카메라와 구도

고정·이동·회전, 와이드·클로즈업

빛과 스타일

조명 방향, 색감, 현실감, 분위기

시간과 마무리

시작 장면, 변화 과정, 마지막 프레임

출력 조건

길이, 가로·세로 비율, 제외할 요소

1. 핵심 기법 6가지

① 대상과 행동을 분명하게 작성하기

모호한 표현보다 관찰할 수 있는 행동을 쓰세요. 예: “아름다운 꽃”보다 “분홍 벚꽃 가지가 바람에 천천히 흔들리고 꽃잎 세 장이 아래로 떨어진다”가 구체적입니다.

② 대상의 움직임과 카메라 움직임 구분하기

“꽃잎이 날린다”는 대상의 움직임이고, “카메라가 나무를 향해 천천히 전진한다”는 카메라 움직임입니다. 두 가지를 따로 적으면 의도가 더 명확해집니다.

Static shot

카메라 고정

Dolly-in / dolly-out

대상 쪽으로 전진 / 뒤로 이동

Pan / tilt

좌우 회전 / 위아래 회전

Tracking shot

움직이는 대상을 따라 이동

③ 조명과 색감 지정하기

“영화처럼”이라고만 쓰기보다 “부드러운 아침 역광, 분홍 꽃잎, 푸른 물빛, 얇은 안개”처럼 빛의 방향과 색을 설명하세요.

④ 장면의 시간 흐름 만들기

짧은 영상에는 시작·전개·마무리의 변화를 간단히 지정합니다. 예: 넓은 풍경으로 시작 → 카메라가 대상에 가까워짐 → 꽃잎의 움직임을 보여 주며 안정적으로 끝남.

⑤ 불필요한 변화를 제한하기

필요한 경우 “갑작스러운 줌 금지”, “인물 외형과 의상 유지”, “배경의 깜박임 방지”처럼 제외 조건을 추가합니다. 모든 생성 도구가 지시를 완벽히 따르는 것은 아니므로 결과를 확인해야 합니다.

⑥ 길이와 화면 비율 정하기

게시할 플랫폼에 맞춰 16:9 가로형 또는 9:16 세로형 등을 지정합니다. 길이와 해상도는 사용하는 생성 서비스가 실제로 지원하는 범위 안에서 선택하세요.

2. 단계별 예제 비교

기초

한 장면

“호숫가 벚꽃나무가 바람에 흔들린다. 카메라는 고정한다. 5초, 16:9.”

개선

구체적인 촬영

“새벽 호숫가의 분홍 벚꽃 가지가 부드러운 바람에 흔들리고 꽃잎 몇 장이 물 위로 떨어진다. 카메라는 고정하고 부드러운 황금빛 역광과 푸른 물빛을 담는다. 5초, 16:9.”

확장

장면 변화

“넓은 풍경으로 시작해 카메라가 나무를 향해 천천히 전진한다. 가지와 꽃잎은 자연스럽게 움직이고, 마지막에는 꽃을 가까이 보여 준다. 조명과 색감은 일정하게 유지한다. 8초, 16:9.”

3. 프롬프트 직접 만들기

항목을 선택하거나 수정한 뒤 생성 버튼을 누르세요. 결과를 복사해 사용 중인 동영상 생성 서비스에 붙여넣을 수 있습니다.

4. 실습 순서와 점검표

  1. 대상·장소·행동을 작성합니다.
  2. 카메라 움직임과 대상의 움직임을 분리해 지정합니다.
  3. 조명·색감·분위기를 더합니다.
  4. 영상 길이·화면 비율·제외 조건을 지정합니다.
  5. 생성 결과를 확인하고 한 번에 한두 조건만 바꾸며 비교합니다.
중요: 프롬프트가 길다고 항상 결과가 좋아지는 것은 아닙니다. 서로 충돌하는 지시를 피하고, 가장 중요한 대상·행동·카메라 조건을 먼저 지정하세요.
