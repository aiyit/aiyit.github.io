Python Turtle 그래픽 완전 정복

거북이 객체의 이동·회전·펜·색상·도형 메소드를 익히고 반복문으로 그림과 패턴을 구현한다.

개념시작하기이동·회전펜·색상 도형·좌표화면 제어통합 예제오류 해결실습 10선

1. Turtle 그래픽이란?

Turtle은 화면 위에 가상의 거북이를 움직여 선과 도형을 그리는 Python 표준 그래픽 모듈이다. 거북이가 이동하는 방향과 거리를 명령하면 이동 경로에 선이 그려진다. 이동, 회전, 반복문, 조건문, 함수와 같은 프로그래밍 개념을 시각적으로 학습하기에 적합하다.

좌표 평면
화면 중앙이 원점 (0, 0)이다. 오른쪽은 x 증가, 위쪽은 y 증가 방향이다.
방향
기본 방향은 오른쪽(동쪽)이며, 표준 모드에서 0° 동쪽, 90° 북쪽이다.
거리
이동 거리의 기본 단위는 화면 픽셀에 대응하는 Turtle 좌표 단위다.
각도
왼쪽 회전은 반시계 방향, 오른쪽 회전은 시계 방향이다.
핵심 원리 거북이는 현재 위치와 방향을 기억한다. 같은 forward(100) 명령도 거북이가 어느 방향을 바라보는지에 따라 다른 위치로 이동한다.

2. Turtle 실행 환경과 기본 구조

2-1. 모듈 불러오기

import turtle

import turtle은 Turtle 모듈을 프로그램에서 사용할 수 있도록 불러온다. 별칭을 사용하면 import turtle as t처럼 작성할 수 있다.

2-2. 화면과 거북이 객체 만들기

import turtle

screen = turtle.Screen()       # 그래픽 화면 객체 생성
screen.title("Turtle 연습")    # 창 제목 지정
screen.setup(800, 600)         # 창 크기 지정

t = turtle.Turtle()            # 거북이 객체 생성
t.shape("turtle")              # 거북이 모양 지정
t.speed(4)                     # 그리기 속도 지정

t.forward(100)                 # 앞으로 100 이동
t.left(90)                     # 왼쪽으로 90도 회전
t.forward(100)

screen.mainloop()              # 창 이벤트 처리 유지
구성 요소설명
turtle그래픽 기능을 제공하는 모듈
screen창의 크기, 배경색, 제목, 이벤트 등을 관리하는 Screen 객체
t실제로 이동하고 그림을 그리는 Turtle 객체
mainloop()창이 사용자 입력을 처리하도록 이벤트 루프를 유지
Jupyter Notebook에서는 실행 환경과 커널의 GUI 지원 여부에 따라 별도 창이 나타나지 않거나 Tkinter 오류가 발생할 수 있다. 일반적인 데스크톱 Python 환경에서 먼저 확인하는 것이 좋다.

3. 이동과 회전 메소드

이동 메소드는 거북이의 현재 방향을 기준으로 움직이거나, 지정한 좌표로 이동한다.

메소드기능사용 예
forward(거리), fd()현재 방향으로 전진t.forward(100)
backward(거리), bk()현재 방향의 반대로 후진t.backward(50)
left(각도), lt()반시계 방향 회전t.left(90)
right(각도), rt()시계 방향 회전t.right(45)
goto(x, y)지정 좌표로 이동t.goto(100, 80)
setx(x) / sety(y)x 또는 y 좌표만 변경t.setx(120)
home()원점으로 이동하고 기본 방향으로 설정t.home()
setheading(각도), seth()절대 방향 지정t.setheading(90)
circle(반지름)현재 위치와 방향을 기준으로 원 또는 호 그리기t.circle(60)

이동과 회전 실습

import turtle
t = turtle.Turtle()
t.speed(3)

for i in range(4):
    t.forward(120)  # 한 변 그리기
    t.left(90)      # 90도 회전

turtle.done()

반복문이 4회 실행되면서 길이 120인 정사각형이 완성된다. 정다각형은 한 바퀴인 360도를 변의 수로 나누어 회전각을 계산한다.

변의 수 = 5
회전각 = 360 / 변의 수

4. 펜 제어와 색상 메소드

메소드기능예시
penup(), up()펜을 들어 이동 경로에 선을 남기지 않음t.penup()
pendown(), down()펜을 내려 이동 경로에 선을 그림t.pendown()
pensize(굵기), width()선의 굵기 설정t.pensize(4)
pencolor(색)선 색상 설정t.pencolor("blue")
fillcolor(색)도형 내부 채우기 색상 설정t.fillcolor("yellow")
color(선, 채움)선 색과 채움 색을 함께 설정t.color("black","orange")
begin_fill()채우기 시작 지점 지정t.begin_fill()
end_fill()도형을 닫고 내부 색 채우기t.end_fill()

펜을 들고 이동하기

t.penup()
t.goto(-100, 0)  # 선을 그리지 않고 이동
t.pendown()
t.forward(150)   # 다시 선을 그림

색이 채워진 도형 그리기

t.color("navy", "skyblue")
t.begin_fill()

for i in range(4):
    t.forward(100)
    t.left(90)

t.end_fill()
begin_fill()과 end_fill()은 한 쌍으로 사용한다. 채우기 전에 도형의 경계를 그린 다음 end_fill()을 호출해야 내부가 색칠된다.

5. 도형·위치·상태 확인 메소드

메소드기능예시
dot(크기, 색)현재 위치에 원형 점 표시t.dot(15, "red")
stamp()현재 위치에 거북이 모양 도장 찍기stamp_id = t.stamp()
shape(모양)거북이 표시 모양 변경t.shape("turtle")
shapesize(배율)거북이 모양 크기 변경t.shapesize(2, 2)
position(), pos()현재 좌표 반환print(t.position())
xcor() / ycor()현재 x, y 좌표 반환print(t.xcor())
heading()현재 바라보는 방향 반환print(t.heading())
distance(x, y)현재 위치에서 지정 위치까지 거리 반환t.distance(100, 100)
speed(값)그리기 속도 설정(0~10, 0은 가장 빠름)t.speed(8)
hideturtle() / showturtle()거북이 숨기기 / 표시t.hideturtle()

원과 호 그리기

t.circle(60)          # 반지름 60인 원
t.circle(60, 180)      # 반지름 60인 반원
t.circle(60, 90)       # 90도 호
t.circle(60, steps=6)  # 원을 6개 선분으로 근사

circle(radius, extent=None, steps=None)에서 radius는 반지름, extent는 그릴 각도, steps는 원을 근사하는 선분 수다.

6. Screen 객체 메소드와 화면 제어

거북이 자체를 제어하는 메소드와 화면 창을 제어하는 메소드는 구분해야 한다. 화면 객체는 screen = turtle.Screen()으로 만든다.

Screen 메소드기능예시
title(문자열)창 제목 설정screen.title("도형 그리기")
setup(너비, 높이)창 크기 설정screen.setup(800, 600)
bgcolor(색)배경색 설정screen.bgcolor("white")
screensize(너비, 높이)그리기 영역 크기 설정screen.screensize(1000, 800)
clearscreen()화면을 지우고 거북이 화면 상태 초기화screen.clearscreen()
bye()그래픽 창 닫기screen.bye()
exitonclick()화면을 클릭하면 종료screen.exitonclick()
tracer(n, delay)화면 갱신 빈도와 지연 설정screen.tracer(0)
update()화면 즉시 갱신screen.update()

화면 갱신을 제어하는 애니메이션 기초

import turtle

screen = turtle.Screen()
screen.tracer(0)  # 자동 화면 갱신 중지
t = turtle.Turtle()

for i in range(36):
    t.forward(100)
    t.right(170)
    screen.update()  # 직접 화면 갱신

screen.mainloop()

7. 메소드 통합 실습: 색이 채워진 별 그리기

화면 설정, 펜 굵기, 색상, 채우기, 반복문, 회전 메소드를 한 프로그램에서 사용한다.

import turtle

screen = turtle.Screen()
screen.setup(700, 600)
screen.bgcolor("midnightblue")
screen.title("Turtle 별 그리기")

t = turtle.Turtle()
t.shape("turtle")
t.speed(5)
t.pensize(3)
t.color("gold", "orange")

t.penup()
t.goto(0, 120)
t.pendown()

t.begin_fill()
for i in range(5):
    t.forward(180)
    t.right(144)
t.end_fill()

t.hideturtle()
screen.exitonclick()

코드 분석

  1. Screen()으로 그래픽 창을 만들고 배경색과 제목을 설정한다.
  2. Turtle()로 거북이 객체를 생성하고 속도와 선 굵기를 지정한다.
  3. penup()과 goto()로 시작 위치까지 선 없이 이동한다.
  4. begin_fill() 이후 반복문으로 별의 다섯 변을 그린다.
  5. end_fill()로 별 내부를 채우고 거북이를 숨긴다.
  6. exitonclick()으로 클릭할 때 창이 닫히도록 한다.

8. 실행 환경 및 오류 해결

8-1. 그래픽 창이 나타나지 않는 경우

  • Jupyter Notebook의 실행 환경이 Tkinter GUI 창을 지원하는지 확인한다.
  • 로컬 PC의 Python 또는 IDLE에서 같은 코드를 실행해 GUI 자체가 정상인지 확인한다.
  • 원격 서버나 브라우저 기반 노트북에서는 데스크톱 GUI 창이 표시되지 않을 수 있다.

8-2. _tkinter 또는 Tk 관련 오류

Turtle은 화면 표시를 위해 Tkinter를 사용한다. Python 설치에 Tk 지원이 빠져 있거나 GUI가 없는 환경에서는 _tkinter 관련 오류가 발생할 수 있다. 운영체제와 Python 배포판에 맞는 Tcl/Tk 지원을 설치하거나 GUI가 지원되는 로컬 Python 환경을 사용한다.

8-3. Terminator 오류

이 오류는 종료된 Turtle 화면 객체를 다시 사용하려 할 때 발생할 수 있다. 이전 실행에서 창을 닫은 뒤 같은 객체를 재사용하지 말고, 새 실행에서 화면과 거북이 객체를 다시 생성한다. Jupyter에서는 커널을 재시작한 뒤 셀을 순서대로 실행하는 방법도 유효하다.

8-4. 실행 후 창이 바로 닫히는 경우

일반 Python 스크립트에서는 마지막에 turtle.done() 또는 screen.mainloop()을 사용해 이벤트 루프를 유지한다. 두 방법을 무조건 중복해서 넣을 필요는 없다.

실습 권장 순서 ① 로컬 Python에서 기본 선 그리기 → ② Jupyter GUI 지원 확인 → ③ 이동·회전 메소드 실습 → ④ 펜과 색상 실습 → ⑤ 반복문 패턴 구현.
