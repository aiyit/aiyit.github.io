window와 navigator,
브라우저가 알려 주는 정보

자바스크립트는 웹 페이지(문서)뿐 아니라 브라우저 자체도 객체로 다룰 수 있다. 아래 창에 나타나는 값은 지금 이 브라우저의 실제 값이다. 창 크기를 바꾸거나 스크롤해 보자.

window.location.href
window.innerWidth-
window.innerHeight-
window.scrollY-
screen.width × height-

값은 resize, scroll 이벤트가 일어날 때마다 다시 읽어 온다.

1. 브라우저 객체 모델(BOM)

웹 페이지의 내용은 document(DOM)로 다루고, 브라우저 창과 환경은 BOM(Browser Object Model)으로 다룬다. BOM의 맨 위에 있는 객체가 window이다.

window ├─ document 웹 페이지 내용 (DOM) ├─ navigator 브라우저·기기 정보 ├─ location 현재 주소(URL) ├─ history 방문 기록 이동 └─ screen 모니터 화면 정보
이 문서에서는 가장 위의 window와, 브라우저 정보를 알려 주는 navigator를 중심으로 배운다.

2. window 객체

window는 브라우저 탭 하나를 나타내는 최상위(전역) 객체이다. 자바스크립트가 제공하는 거의 모든 기능이 window의 속성이나 메서드이다.

window는 생략할 수 있다

window.alert("안녕");   // 원래 형태
alert("안녕");          // window 생략 (같은 동작)

var score = 90;         // 전역 변수는 window의 속성이 된다
console.log(window.score);  // 90
같은 이유로 document도 사실은 window.document이다. let, const로 만든 전역 변수는 window 속성이 되지 않으니 구분하자.

자주 쓰는 속성

속성의미지금 값
innerWidth페이지가 보이는 영역의 너비(px)
innerHeight페이지가 보이는 영역의 높이(px)
outerWidth브라우저 창 전체 너비(테두리 포함)
scrollY세로로 스크롤한 거리
devicePixelRatio화면 선명도 배율(고해상도면 2 이상)

자주 쓰는 메서드

메서드하는 일
alert(글)확인 버튼이 있는 알림창
confirm(글)확인/취소를 묻고 true/false 반환
prompt(글, 기본값)입력을 받고 문자열 반환(취소하면 null)
setTimeout(함수, ms)지정한 시간 뒤에 한 번 실행
setInterval(함수, ms)지정한 간격으로 반복 실행
open(주소, 이름, 옵션) / close()새 창 열기 / 창 닫기
scrollTo(x, y)지정한 위치로 스크롤

직접 해 보기

버튼을 눌러 결과를 확인하자.
if (confirm("계속할까요?")) {
  console.log("확인을 눌렀다");   // 확인 → true
}
let name = prompt("이름은?", "홍길동");  // 취소하면 null
setTimeout(function () { alert("2초 지났다"); }, 2000);
브라우저는 사용자가 누르지 않은 팝업 창을 차단한다. window.open()은 버튼 클릭처럼 사용자의 동작 안에서 호출해야 열린다.

3. navigator 객체

navigator는 이 페이지를 보고 있는 브라우저와 기기에 대한 정보를 담고 있다. 접속 환경에 맞춰 화면이나 기능을 바꿀 때 쓴다.

주요 속성 (지금 이 브라우저의 값)

속성의미지금 값
userAgent브라우저·운영체제를 나타내는 긴 문자열
language브라우저의 기본 언어
platform운영체제 종류(참고용)
onLine인터넷 연결 여부
cookieEnabled쿠키 사용 가능 여부
hardwareConcurrencyCPU 논리 코어 수
maxTouchPoints동시에 인식하는 터치 수(0이면 터치 없음)

연결 상태는 이벤트로도 알 수 있다. 네트워크를 껐다 켜면 아래 표시가 바뀐다.

window.addEventListener("online",  () => console.log("연결됨"));
window.addEventListener("offline", () => console.log("연결 끊김"));

위치 정보: navigator.geolocation

위치는 개인정보이므로 사용자가 허용해야만 얻을 수 있다. 결과는 성공/실패 함수로 나뉘어 돌아온다.

버튼을 누르면 브라우저가 허용 여부를 묻는다.
navigator.geolocation.getCurrentPosition(
  function (pos) { console.log(pos.coords.latitude, pos.coords.longitude); },
  function (err) { console.log("실패:", err.message); }
);
userAgent 문자열로 브라우저를 구분하는 방식은 값이 쉽게 바뀌고 정확하지 않다. 가능하면 "이 기능이 있는가?"를 검사하는 방식(if ("geolocation" in navigator))을 먼저 쓴다.

5. 확인 문제

1. alert("hi")와 window.alert("hi")의 차이는?

차이가 없다. window는 전역 객체라서 생략할 수 있다.

2. 브라우저 창 안에서 페이지가 보이는 영역의 너비를 구하는 속성은?

window.innerWidth

3. confirm()에서 취소를 누르면 반환되는 값은?

false이다. (prompt()에서 취소하면 null)

4. 사용자의 위치를 얻을 때 반드시 필요한 것은?

사용자의 허용이다. 거부하면 실패 함수가 실행되므로 실패 처리도 함께 작성해야 한다.

5. navigator.userAgent만 믿고 기능을 나누면 안 되는 이유는?

문자열이 브라우저마다 다르고 바뀔 수 있어 정확하지 않다. 기능 존재 여부를 직접 검사하는 편이 안전하다.
