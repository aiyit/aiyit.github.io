JavaScript 예제 9-2: this와 객체 생성자

이 예제는 생성자 함수로 사람 객체 두 개를 만들고, 각 객체의 속도 값을 메서드로 변경하는 프로그램입니다.

핵심: new Human(...)을 두 번 실행하면 서로 독립적인 객체인 cmHuman과 cfHuman이 만들어집니다. 각 객체는 자신의 이름과 속도 값을 따로 가집니다.

        function Human(name, age, sex,speed)
        {
            this.name=name;       this.age=age;
            this.sex = sex;         this.speed = speed;
            this.walk = function () { this.speed = 10;  }
            this.run = function () {this.speed += 4; }
    }

3. JavaScript 객체와 생성자 함수

3-1. 생성자 함수란?

Human은 사람 객체를 만들기 위한 생성자 함수입니다. 일반적으로 생성자 함수의 이름은 대문자로 시작하는 관례가 있습니다.

function Human(name, age, sex, speed) {
    this.name = name;
    this.age = age;
    this.sex = sex;
    this.speed = speed;
    this.walk = function () { this.speed = 10; };
    this.run = function () { this.speed += 4; };
}

함수에 전달된 매개변수 name, age, sex, speed의 값을 this가 가리키는 새 객체의 속성에 저장합니다.

3-2. this는 무엇인가요?

이 코드에서 new Human(...)으로 생성자 함수를 호출하면, this는 새로 만들어지는 객체를 가리킵니다.

  • this.name = name; — 새 객체의 이름을 저장합니다.
  • this.speed = speed; — 새 객체의 초기 속도를 저장합니다.
  • this.walk = function () { this.speed = 10; } — 해당 객체의 속도를 10으로 설정하는 메서드입니다.
  • this.run = function () { this.speed += 4; } — 해당 객체의 속도에 4를 더하는 메서드입니다.

3-3. new를 이용해 객체 두 개 만들기

var cmHuman = new Human("Park", 12, "male", 20);
var cfHuman = new Human("Kim", 12, "female", 15);
객체 변수nameagesex초기 speed
cmHumanPark12male20
cfHumanKim12female15

두 객체는 같은 Human 생성자 함수로 만들어졌지만, 각각의 speed 속성은 독립적으로 관리됩니다. cmHuman.run()은 Park의 속도만 바꾸고, cfHuman.run()은 Kim의 속도만 바꿉니다.

4. 실행 과정 분석

반복문 안에서는 먼저 Park의 속도를 출력한 뒤 Park의 속도를 4 증가시킵니다. 다음으로 Kim의 속도를 출력한 뒤 Kim의 속도를 4 증가시킵니다. 반복 조건은 Park의 속도(cmHuman.speed)만 검사합니다.

반복Park 출력 시 속도Park run() 후Kim 출력 시 속도Kim run() 후Park 속도로 조건 검사
12024151924 < 35 → 참
22428192328 < 35 → 참
32832232732 < 35 → 참
43236273136 < 35 → 거짓, 종료

따라서 반복문은 총 4회 실행됩니다. 네 번째 반복에서 Park의 속도는 32로 출력되고, 그 후 36이 됩니다. 조건 검사에서 36은 35보다 작지 않으므로 반복이 종료됩니다. Kim의 속도는 반복 종료 시 31입니다.

4-1. 반복문이 끝난 뒤

cmHuman.walk();
cfHuman.walk();

각 객체의 walk() 메서드를 실행하므로 Park와 Kim 모두 속도가 10으로 설정됩니다. 이때 Kim의 속도가 반복문 종료 직전에 31이었더라도, walk()가 실행되면 10으로 바뀝니다.
