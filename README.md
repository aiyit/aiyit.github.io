# 여주대학교 AI소프트웨어과

## 기술 구성

현재 웹사이트의 확인 가능한 구성은 다음과 같습니다.

- **HTML5** — 웹 문서 구조
- **CSS** — 반응형 레이아웃과 시각 디자인
- **JavaScript** — 웹 상호작용 및 콘텐츠 동작
- **Google Fonts** — 웹 글꼴
- **GitHub Pages** — 정적 웹사이트 배포

개별 콘텐츠는 파일에 따라 사용하는 기술과 라이브러리가 다를 수 있습니다. 별도의 빌드 도구가 필요한 프로젝트인지 여부는 해당 콘텐츠의 소스 파일과 설정을 기준으로 확인해 주세요.

## 실행 방법

대부분의 정적 HTML 콘텐츠는 웹 브라우저에서 확인할 수 있습니다.

1. 저장소를 내려받거나 복제합니다.
2. 확인하려는 HTML 파일을 찾습니다.
3. 파일을 브라우저에서 열어 실행합니다.

Git을 사용한다면 다음 명령으로 저장소를 복제할 수 있습니다.

```bash
git clone https://github.com/aiyit/aiyit.github.io.git
cd aiyit.github.io
```

일부 콘텐츠는 브라우저 보안 정책, 외부 라이브러리 또는 로컬 서버 실행 여부에 따라 동작이 달라질 수 있습니다. 해당 콘텐츠에 별도 실행 안내가 있다면 그 안내를 우선해 주세요.

## 교육 및 활용 목적

이 저장소는 AI 소프트웨어 교육과 웹 기반 실습을 지원하기 위한 자료를 제공합니다. 프로그래밍 입문자는 예제 코드를 직접 실행하고 수정하면서 웹 기술의 기본 원리를 익힐 수 있으며, 학습자는 3D·VR 및 시뮬레이션 콘텐츠를 통해 추상적인 개념을 시각적으로 탐색할 수 있습니다.

오류를 발견하거나 교육용 콘텐츠 개선 아이디어가 있다면 저장소의 이슈(Issues)를 통해 제안할 수 있습니다. 코드를 수정할 때는 기존 파일의 경로와 링크가 유지되는지 확인해 주세요.
