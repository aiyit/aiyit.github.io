1. 파이썬과 알고리즘

파이썬(Python)은 문법이 간결하고 읽기 쉬운 프로그래밍 언어다. 데이터 분석, 웹 개발, 자동화, 인공지능 등에 활용한다.

개념의미
알고리즘(Algorithm)문제를 해결하기 위한 순서와 방법
프로그램(Program)알고리즘을 프로그래밍 언어로 작성한 명령의 모음
실행(Execution)작성한 명령을 컴퓨터가 수행하는 과정
문제 이해→알고리즘→파이썬 코드→실행 결과
핵심 흐름은 입력 → 처리 → 출력이다.

bool참 또는 거짓True, False

dict키와 값의 쌍{"name":"민수"}

3. 연산자

종류연산자의미
산술+, -, *, /, //, %, **더하기, 빼기, 곱하기, 나누기, 몫, 나머지, 거듭제곱
비교==, !=, >, <, >=, <=비교 결과는 True 또는 False
논리and, or, not논리곱, 논리합, 부정
대입=, +=, -=, *=값 저장 또는 갱신
포함in, not in자료 안에 값이 있는지 확인
a = 17
b = 5
print(a / b)    # 3.4 나눈 결과
print(a // b)   # 3 몫
print(a % b)    # 2 나머지
print(2 ** 3)   # 8 거듭제곱
시험 핵심: //는 몫, %는 나머지다. 17을 5로 나누면 몫은 3, 나머지는 2다.

4. 조건문과 반복문

4-1. 조건문 if

조건이 참인지 거짓인지 판단해 실행할 내용을 선택한다.

점수 입력→점수 ≥ 60?→참: 합격
거짓: 불합격
score = 75

if score >= 60:
    print("합격")
else:
    print("불합격")

4-2. 반복문 for와 while

for는 자료의 항목이나 정해진 범위를 하나씩 꺼내 반복한다. while은 조건이 참인 동안 반복하므로 종료 조건을 확인해야 한다.

# 1부터 5까지 출력
for number in range(1, 6):
    print(number)

# while 반복
count = 1
while count <= 5:
    print(count)
    count += 1
명령기능
break반복문을 즉시 종료
continue현재 반복을 건너뛰고 다음 반복으로 이동
pass아무 동작 없이 문법상 자리를 채움

range(1, 6)은 1부터 6 미만까지의 정수를 만든다.

리스트는 여러 값을 순서대로 저장하며 항목을 추가·수정·삭제할 수 있다.

scores = [80, 90, 75]
scores.append(100)   # 끝에 추가
scores[0] = 85       # 첫 번째 값 수정
scores.remove(90)    # 값 90 삭제
print(scores)

reverse()순서 뒤집기

6. 세트(Set)와 딕셔너리(Dictionary)

6-1. 세트

세트는 중복된 값을 하나만 남기는 자료형이다. 항목의 순서를 기준으로 사용하지 않는다.

numbers = {1, 2, 2, 3, 3, 3}
print(numbers)       # {1, 2, 3}과 같은 집합
print(2 in numbers)  # True

6-2. 딕셔너리

딕셔너리는 키(Key)와 값(Value)을 한 쌍으로 저장한다.

키: name→값: 홍길동
student = {"name": "홍길동", "score": 95}
print(student["name"])
print(student["score"])
student["grade"] = "A"   # 새 항목 추가
print(student.keys())    # 키 목록
print(student.values())  # 값 목록

7. 함수(Function)

함수는 자주 사용하는 코드를 하나의 이름으로 묶은 것이다. 입력값을 받을 수 있고 return으로 결과를 돌려줄 수 있다.

입력값 3, 5→add() 처리
3 + 5→반환 결과 8
def add(a, b):
    result = a + b
    return result

total = add(3, 5)
print(total)  # 8
용어설명
매개변수(Parameter)함수를 정의할 때 입력받도록 만든 변수
인수(Argument)함수를 호출할 때 실제 전달하는 값
return실행 결과를 호출한 곳으로 돌려줌
지역 변수함수 내부에서 만들어져 주로 함수 안에서 사용
전역 변수함수 바깥에서 정의된 변수
lambda간단한 함수를 한 줄 식으로 표현
def greet(name, message="안녕하세요"):
    print(name, message)

greet("민수")
greet("영희", "반갑습니다")

square = lambda x: x * x
print(square(4))  # 16

8. 클래스와 객체지향 프로그래밍

클래스(Class)는 객체를 만들기 위한 설계도이고, 객체(Object)는 클래스를 바탕으로 실제 생성한 대상이다. 객체는 데이터인 속성과 기능인 메서드를 가진다.

Student 클래스
속성: name, score
기능: introduce()→객체 1
민수, 90점객체 2
영희, 95점
class Student:
    def __init__(self, name, score):
        self.name = name
        self.score = score

    def introduce(self):
        print(self.name, "학생의 점수는", self.score)

student1 = Student("민수", 90)
student2 = Student("영희", 95)

student1.introduce()
student2.introduce()

self는 현재 객체 자신을 가리킨다. __init__()은 객체가 생성될 때 속성을 초기화하는 메서드다.

객체지향 특징설명
캡슐화(Encapsulation)데이터와 기능을 하나로 묶고 접근을 관리
상속(Inheritance)기존 클래스의 속성과 기능을 물려받음
다형성(Polymorphism)같은 기능 이름이 객체에 따라 다르게 동작
추상화(Abstraction)복잡한 내부 구현은 감추고 핵심 기능을 표현

9. 파일 입출력

파일 입출력(File Input/Output)은 프로그램의 데이터를 파일에 저장하거나 파일에서 읽어오는 기능이다.

파이썬 프로그램↔파일 data.txt
저장 공간
모드의미
r읽기. 파일이 없으면 오류
w쓰기. 기존 내용이 있으면 덮어씀
a추가. 기존 내용 뒤에 이어 씀
x새 파일 생성. 같은 이름이 있으면 오류
b바이너리 모드(예: rb, wb)
t텍스트 모드(기본값)

실습 9-1. 텍스트 파일 저장과 읽기

# 파일에 쓰기
with open("memo.txt", "w", encoding="utf-8") as file:
    file.write("파이썬 파일 입출력 실습이다.\\n")
    file.write("데이터를 저장한다.")

# 파일 읽기
with open("memo.txt", "r", encoding="utf-8") as file:
    content = file.read()

print(content)

with open()을 사용하면 작업이 끝난 뒤 파일이 자동으로 닫힌다. 한글 파일은 encoding="utf-8"을 지정해 인코딩 문제를 줄인다.

실습 9-2. CSV 파일

import csv

students = [
    ["이름", "점수"],
    ["민수", 90],
    ["영희", 95],
    ["철수", 82]
]

with open("scores.csv", "w", newline="", encoding="utf-8-sig") as file:
    writer = csv.writer(file)
    writer.writerows(students)

with open("scores.csv", "r", encoding="utf-8-sig") as file:
    reader = csv.reader(file)
    for row in reader:
        print(row)

10. 예외 처리

예외(Exception)는 프로그램 실행 중 발생하는 오류 상황이다. try와 except를 이용해 오류에 대응한다.

try 실행→정상: else오류: except→finally
try:
    number = int(input("숫자를 입력한다: "))
    result = 100 / number
except ValueError:
    print("정수로 입력해야 한다.")
except ZeroDivisionError:
    print("0으로 나눌 수 없다.")
else:
    print("계산 결과:", result)
finally:
    print("프로그램을 종료한다.")
구문역할
try오류 가능성이 있는 코드 실행
except발생한 예외 처리
else예외가 발생하지 않았을 때 실행
finally예외 여부와 관계없이 실행
raise예외를 직접 발생

모듈(Module)은 파이썬 코드가 들어 있는 파일이다. 라이브러리(Library)는 특정 기능을 편리하게 사용하도록 제공하는 코드의 모음이다.

모듈주요 기능예시

12. 자료구조와 알고리즘

자료구조(Data Structure)는 데이터를 효율적으로 저장하고 관리하는 방법이다. 알고리즘은 그 데이터를 이용해 문제를 해결하는 절차다.

자료구조특징비유
배열(Array)인덱스로 데이터에 접근번호가 붙은 사물함
스택(Stack)후입선출(LIFO): 나중에 넣은 것이 먼저 나옴접시 쌓기
큐(Queue)선입선출(FIFO): 먼저 넣은 것이 먼저 나옴줄 서기
리스트(List)순서에 따라 데이터 관리할 일 목록
딕셔너리(Dictionary)키로 값을 찾음전화번호부
스택
마지막 데이터부터 꺼냄
3 → 2 → 1큐
먼저 들어온 데이터부터 꺼냄
1 → 2 → 3

스택 구현

stack = []
stack.append("첫 번째")
stack.append("두 번째")
stack.append("세 번째")

print(stack.pop())  # 세 번째
print(stack.pop())  # 두 번째

큐 구현

from collections import deque

queue = deque()
queue.append("첫 번째")
queue.append("두 번째")
queue.append("세 번째")

print(queue.popleft())  # 첫 번째
print(queue.popleft())  # 두 번째

탐색과 정렬

  • 순차 탐색(Linear Search): 처음부터 차례대로 비교한다.
  • 이진 탐색(Binary Search): 정렬된 데이터의 가운데 값과 비교해 탐색 범위를 절반씩 줄인다.
  • 버블 정렬(Bubble Sort): 이웃한 두 값을 비교하고 필요하면 교환한다.
numbers = [12, 7, 25, 9, 18]
target = 25

for index, value in enumerate(numbers):
    if value == target:
        print("찾은 위치:", index)
        break

13. 종합 실습: 학생 성적 관리

학생 이름과 점수를 저장하고 평균, 최고 점수, 합격 여부를 출력한다. 리스트, 딕셔너리, 반복문, 조건문, 함수를 함께 사용한다.

students = [
    {"name": "민수", "score": 90},
    {"name": "영희", "score": 85},
    {"name": "철수", "score": 72},
    {"name": "지민", "score": 98},
    {"name": "수현", "score": 55}
]

def get_average(data):
    total = sum(student["score"] for student in data)
    return total / len(data)

for student in students:
    result = "합격" if student["score"] >= 60 else "불합격"
    print(student["name"], student["score"], result)

average = get_average(students)
top_student = max(students, key=lambda x: x["score"])

print("평균:", round(average, 1))
print("최고 점수:", top_student["name"], top_student["score"])
코드 분석
students는 학생 데이터를 저장한다. for문은 학생을 한 명씩 처리한다. get_average()는 평균을 계산하고 max()는 최고 점수 학생을 찾는다.

응용 과제

  1. 학생을 2명 추가한다.
  2. 합격 기준을 70점으로 변경한다.
  3. 평균보다 높은 학생만 출력한다.
  4. 결과를 CSV 파일로 저장한다.
