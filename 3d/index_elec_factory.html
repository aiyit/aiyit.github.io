전기 설비 3D 구현과 안전 설치

PLC로 제어되는 불량 선별 컨베이어를 3D로 옮겨 놓고, 설비의 상태와 안전 인터락을 직접 눌러 보며 익히는 전기안전 교육용 디지털 트윈입니다. 아래로 내려가면 형광등이 켜진 공장 한가운데에 서서 이 설비를 PC나 구글 카드보드로 둘러볼 수 있습니다.

이 프로그램은 무엇인가요

설비를 “보는” 것에서 끝나지 않고, 버튼을 누르면 신호가 흘러 모터가 돌고, 위험한 상황에서는 설비가 스스로 멈추는 과정을 눈으로 확인하는 시뮬레이터입니다.

쉽게 말하면

공장에 있는 컨베이어 벨트를 컴퓨터 속에 똑같이 만들어 둔 것입니다. 상자가 벨트를 타고 오다가 센서 앞에서 멈추고, 카메라가 불량인지 검사해서 불량이면 실린더가 옆으로 밀어냅니다. 안전문을 열면 기계가 즉시 멈추고, 문을 닫아도 저절로 다시 돌지 않는다는 점까지 직접 확인할 수 있습니다.

전문적으로 말하면

입력(X: START, 포토센서, E-STOP, 비전 NG, 가드 인터락)을 PLC 래더 로직이 처리해 출력(Y: 모터 릴레이 K1, 솔레노이드, 타워램프)을 내는 구조를 Three.js 3D 장면과 1:1로 연결했습니다. 3D 객체의 동작은 설비 상태 변수와 PLC I/O 값에서 계산되므로, 모델이 단순한 그림이 아니라 설비 데이터의 시각화가 됩니다.

  1. 센서·버튼·인터락START, 포토센서, E-STOP, 도어
  2. PLC 입력 XX0 ~ X4
  3. 제어 로직자기유지·인터락 래더
  4. PLC 출력 YY0 ~ Y2
  5. 모터·솔레노이드릴레이 K1, 공압 밸브
  6. 설비 동작벨트 이동, 불량 배출

구현된 기능

모두 첨부된 index_elec.html 안에서 실제로 동작하는 기능이며, 아래 3D 체험 영역에서 그대로 사용할 수 있습니다.

3D 설비 모델
컨베이어 벨트·롤러·프레임, 포토센서, 비전 검사 장치, 불량품 푸셔 실린더와 불량통, 구동 모터, 타워램프, 그리고 MCCB·24V SMPS·PLC·릴레이 K1·단자대가 들어 있는 제어반까지 한 장면에 구성했습니다.
HMI 제어 패널
START · STOP · E-STOP · MCCB · 안전가드 버튼, 벨트 속도 슬라이더(0.5배 ~ 5배), TOTAL / PASS / DEFECT 카운터, RUN · SENSOR · ALARM 램프를 화면 안에서 조작합니다.
PLC I/O 실시간 표시
하단 도크에 신호 흐름과 래더 두 줄(렁)이 표시되고, 설비가 움직이는 순간 접점과 코일이 켜지고 꺼집니다. 제어반의 입력·출력 모듈 LED도 같은 값으로 점등합니다.
불량 선별 시퀀스
상자가 포토센서(X1)에 도착하면 컨베이어가 멈추고 비전이 OK/NG를 판정합니다. NG이면 솔레노이드(Y1)가 작동해 실린더가 상자를 불량통으로 밀어냅니다.
안전가드 인터락
도어를 열면 인터락 스위치(X4)가 꺼져 모터 출력(Y0)이 즉시 차단됩니다. 도어가 열려 있는 동안은 START가 잠기고, 도어를 닫아도 자동 재기동하지 않습니다. 바닥의 위험구역은 붉게 점멸합니다.
작업자 점검 시연
작업자가 안전가드로 접근해 도어를 열고, 점검한 뒤 나가서 문을 닫기까지 8단계를 자막과 함께 보여 줍니다. 자막을 탭하면 일시정지됩니다.
3D 직접 조작
제어 스테이션의 START·STOP·E-STOP 버튼, 제어반의 MCCB 손잡이, 안전가드 도어를 3D 화면에서 직접 클릭(VR에서는 응시)해서 조작합니다.
배선 신호 흐름
켜진 신호의 배선에는 전류 펄스가 흐르고, 꺼진 배선은 어둡게 표시되어 어느 신호가 어디로 가는지 따라가 볼 수 있습니다.
설비 설명서
각 장치의 역할과 PLC 입출력 표, 래더 설명을 팝업으로 확인합니다.
공장 실내 관찰
설비를 형광등이 켜진 공장 한가운데 놓고 관찰자가 공장 중앙에서 둘러봅니다. 시점 버튼으로 제어반 · 안전가드 · 센서 앞으로 이동할 수 있습니다.
PC · VR 두 가지 모드
PC 모드는 마우스·터치 드래그로 둘러보고, VR 모드는 휴대폰을 구글 카드보드에 끼워 좌우 분할 화면과 자이로 센서로 체험합니다.

사용 방법

PC 모드

마우스로 화면을 끌면 공장 중앙에서 사방을 둘러봅니다. Ctrl 키를 누른 채 휠을 돌리거나 확대·축소 버튼을 누르면 줌이 바뀝니다. 제어 스테이션 버튼, 제어반 MCCB 손잡이, 안전가드 도어를 클릭해 조작하고, 오른쪽 시점 버튼으로 제어반·안전가드·센서 앞으로 이동합니다. 화면 왼쪽의 제어 패널로도 같은 조작을 할 수 있습니다.

VR 모드 (구글 카드보드)

스마트폰의 Chrome이나 Safari로 이 페이지를 열고 VR 모드 버튼을 누릅니다. iPhone은 모션 센서 권한을 허용해야 합니다. 화면이 좌우로 나뉘면 폰을 가로로 돌려 카드보드에 끼우세요. 고개를 돌리면 시야가 따라 움직이고, 가운데 점을 버튼이나 설비에 1.5초 두면 선택됩니다. 카드보드 버튼이 있으면 누르는 즉시 선택됩니다. 종료는 화면 아래 중앙의 종료 버튼입니다.

이 프로그램은 교육용 시뮬레이션이며 실제 PLC와 통신하지 않습니다. 실제 전기 설비의 설치·점검 작업에 적용하려면 관련 전기안전 규정을 확인하고 전기 전문가의 검토를 받아야 합니다. VR은 모션 센서 사용을 위해 https 주소(GitHub Pages 포함)에서만 동작하며, 장시간 사용하면 휴대폰이 뜨거워질 수 있습니다.

설비 설명서

MCCB
전기 설비의 전원 차단 및 보호 (제어반 MCCB 손잡이 또는 제어 패널의 MCCB 버튼으로 ON/OFF). OFF이면 PLC·출력·타워램프가 모두 꺼지고 E-STOP도 동작하지 않음
24V DC SMPS
제어 회로에 필요한 DC 전원 공급
PLC
입력 신호를 받아 프로그램에 따라 출력 장치를 제어
릴레이 (K1)

포토센서
제품의 위치 또는 통과 여부만 감지 (제품 도착 신호). 감지되면 컨베이어가 잠시 멈추고 비전 검사가 진행됨
비전 검사 장치
카메라로 제품 외관을 검사해 불량(NG)이면 PLC에 신호 전달
모터
컨베이어 구동
솔레노이드 밸브
공압 실린더 동작 제어
실린더
불량품을 옆의 불량품 통(REJECT BIN)으로 밀어내 배출
START / STOP
라인 가동 시작·정지 (START는 PLC 입력 X0). E-STOP 작동, MCCB OFF, 안전가드 도어 열림 상태에서는 START가 잠김
Emergency Stop
비상 상황에서 설비 정지 (누르면 래치되어 유지, 해제 후 START를 눌러야 재가동)
타워램프
설비 상태 표시 (PLC 출력 Y2): 녹색 = 가동 중, 황색 점멸 = 센서 감지·검사 중, 적색 점등 = 정상 정지, 적색 점멸 = 비상(E-STOP 작동 또는 안전가드 도어 열림). MCCB OFF이면 모두 소등
안전가드
작업자가 구동부(모터·구동 롤러·벨트 끝단)에 접근하는 것을 방지. 도어를 열면 인터락 스위치(X4)가 OFF되어 설비가 즉시 정지하고, 도어를 닫아도 START를 눌러야 재가동 (자동 재기동 방지)
작업자 점검 시연
목적: 점검·정비를 위해 안전가드 도어를 열었을 때 설비가 어떻게 보호되는지, 작업자의 접근부터 퇴장까지 단계별로 보여 주는 안전 교육용 시연입니다.
학습 포인트: ① 도어 열림 = 인터락 X4 OFF → 모터 출력 Y0 차단(즉시 정지) ② 도어가 열린 동안 START 잠금 ③ 도어를 닫아도 자동 재기동 없음(START 필요) ④ 바닥 해저드 표시로 위험구역 인지
사용법: MCCB ON · E-STOP 해제 · 도어 닫힘 상태에서 [작업자 점검 시연] 버튼을 누르면 카메라가 이동하고 화면 하단에 단계별 설명이 표시됩니다. 라인이 정지 상태이면 시연 시작 시 자동으로 가동되며, 시연 중에는 도어를 직접 조작할 수 없습니다. 설명을 탭하면 일시정지/계속할 수 있습니다.
