예제 10-3: DOM 노드 추가 및 삭제(addChild/removeChild) 분석 문서

본 문서는 JavaScript를 활용하여 웹 페이지에 새로운 HTML 요소를 동적으로 생성하고 추가(Append)하거나 제거(Remove)하는 DOM 노드 조작 원리와 관련 메서드들의 상세한 동작 방식을 설명합니다.

1. DOM 노드 동적 추가·삭제 개념 상세 이해

정적(Static)으로 작성된 HTML 문서와 달리, 사용자의 버튼 클릭이나 데이터 입력에 반응하여 화면의 리스트나 카드 요소를 실시간으로 생성하거나 지우는 기능은 모던 웹 개발의 핵심입니다. JavaScript는 DOM API를 통해 문서 트리에 새로운 노드를 자유롭게 붙이고 뗄 수 있습니다.

💡 핵심 포인트: 노드를 추가할 때는 createElement로 뼈대를 만들고, createTextNode로 내용을 채운 뒤 appendChild로 부모 요소에 조립하는 단계를 거칩니다. 삭제할 때는 부모 요소를 통해 자식 요소를 지목하여 제거합니다.

1) 노드 추가 과정 (Add)

  • document.createElement("li"): 메모리상에 지정한 태그 이름(<li>)의 새로운 요소 노드를 생성합니다.
  • document.createTextNode("오렌지"): 화면에 출력될 텍스트 노드를 생성합니다.
  • add.appendChild(cnode): 생성한 텍스트 노드를 새로 만든 <li> 요소의 자식으로 포함시킵니다.
  • 부모요소.appendChild(add): 최종 완성된 <li>오렌지</li> 요소를 <ul id="myList"> 리스트의 마지막 자식으로 추가하여 화면에 렌더링합니다.

2) 노드 삭제 과정 (Remove)

  • list.lastElementChild: 대상 부모 요소(<ul>)의 마지막 자식 요소(가장 최근에 추가되었거나 맨 아래에 있는 <li>)를 선택합니다.
  • if (rnode) list.removeChild(rnode): 삭제할 대상 노드가 존재하는지 안전성 검사(유효성 검사)를 거친 후, 부모 노드 입장에서 removeChild()를 호출하여 DOM 트리에서 완전히 제거합니다.

2. 제공된 HTML 원본 코드

<!DOCTYPE html>
<html>
<head>
<link rel="stylesheet" href="style.css">   
<meta charset="utf-8">
<title>예제 10-3 노드 추가/삭제(addChild/removeChild)</title>
<script>
    function Add() {
        var add = document.createElement("li");
        var cnode = document.createTextNode("오렌지");
        add.appendChild(cnode);
        document.getElementById("myList").appendChild(add); 
    }
    
    function remove() {
        var list = document.getElementById("myList");
        var rnode = list.lastElementChild;
        if (rnode) list.removeChild(rnode);
    } 
</script>
</head>
<body id='main'>
    <h3 style="text-align:center;">노드 추가/삭제(addChild/removeChild)</h3>
    <h4>클릭버튼 추가/삭제</h4>
    <ul id="myList">
        <li>사과</li>
        <li>바나나</li>
    <ul>
    <input type="button" id="bt1" value="추가" onclick="Add();">
    <input type="button" id="bt2" value="삭제" onclick="remove();">
</body>
</html>

3. 노드 제어 주요 메서드 상세 분석

메서드명 사용 예시 동작 설명 및 특징
document.createElement() document.createElement("li") 지정한 태그 명의 새로운 HTML 요소 노드를 생성하여 메모리에 올립니다. 아직 화면에는 보이지 않는 상태입니다.
document.createTextNode() document.createTextNode("오렌지") 요소 내부에 들어갈 순수한 텍스트 조각을 노드 형태로 생성합니다.
appendChild() parent.appendChild(child) 특정 부모 노드의 자식 노드 리스트 중 맨 마지막 위치에 새로운 노드를 추가합니다. 요소 생성 과정과 조립 과정 모두에 활용됩니다.
removeChild() parent.removeChild(child) 부모 노드로부터 특정 자식 노드를 전달받아 DOM 트리에서 분리 및 제거합니다.

핵심 정리

  • 요소 생성: createElement()와 createTextNode()로 빈 껍데기와 내용물 제작
  • 트리 결합: appendChild()를 이용해 자식을 부모에게 소속시키고 화면에 반영
  • 노드 제거: lastElementChild 등으로 타겟을 선정하고 removeChild()로 삭제

학습 포인트: 정적인 HTML 구조를 벗어나 스크립트로 요소를 동적 생성하고 구조를 재편하는 DOM 조작의 핵심 매커니즘을 익힙니다.
