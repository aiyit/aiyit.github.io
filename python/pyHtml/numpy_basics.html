NumPy 핵심 개념

ndarray
NumPy의 배열 객체. 같은 자료형의 값이 모여 있어 리스트보다 빠르고 메모리를 적게 씁니다.
shape · ndim · dtype
배열의 모양(행, 열), 차원 수, 원소 자료형. 배열을 만나면 가장 먼저 확인합니다.
벡터화 연산
반복문 없이 배열 전체에 계산을 적용합니다. scores + 5는 모든 원소에 5를 더합니다.
인덱싱·슬라이싱
위치(0부터 시작)로 원소를 꺼냅니다. a[1], a[1:4], m[행, 열]
불리언 마스크
조건(a >= 85)으로 True/False 배열을 만들어 원하는 값만 선택합니다.
axis
계산 방향. axis=0은 열 방향(위에서 아래), axis=1은 행 방향(왼쪽에서 오른쪽)입니다.
브로드캐스팅
모양이 다른 배열끼리도 규칙에 맞으면 자동으로 늘려서 계산합니다.
리스트와의 차이
리스트에 + 5는 오류, 리스트끼리 +는 이어 붙이기입니다. 배열은 원소별 계산입니다.

1. NumPy 기초와 배열 생성

학습 목표: NumPy가 무엇인지 이해하고 1차원·2차원 배열을 직접 생성할 수 있다.

핵심 개념 설명

개념 ① NumPy란?
NumPy(Numerical Python)는 파이썬에서 숫자 데이터를 효율적으로 계산하고 분석하기 위한 라이브러리입니다. 학생 5명의 점수를 리스트 [80, 90, 75, 85, 95]로 저장할 수도 있지만, NumPy 배열로 만들면 배열 전체에 대한 계산과 통계 처리가 편리합니다.
개념 ② 배열(Array)이란?
1차원 배열: 숫자가 한 줄로 나열된 구조. 각 위치를 인덱스(index)라 하며 0부터 시작합니다.
값8090758595
인덱스01234
2차원 배열: 행과 열로 구성된 표 구조. 아래는 2행 3열이며 shape은 (2, 3)입니다.
809075
859588

print(scores.shape)
print(scores.ndim)

(5,)

dtype은 실행 환경에 따라 int32 등으로 표시될 수 있습니다.

배열 생성 방법

import numpy as np
a = np.array([10, 20, 30])
b = np.arange(1, 6)
c = np.zeros(3)
d = np.ones(3)
print(a)  # [10 20 30]
print(b)  # [1 2 3 4 5]
print(c)  # [0. 0. 0.]
print(d)  # [1. 1. 1.]

np.arange(1, 6)은 1부터 5까지 생성하며 끝값 6은 포함하지 않습니다. np.zeros(3)은 0이 3개, np.ones(3)은 1이 3개인 배열을 만듭니다.

2. 인덱싱·슬라이싱과 배열 연산

학습 목표: 배열에서 원하는 값을 꺼내고, 반복문 없이 배열 전체를 한 번에 계산할 수 있다.

핵심 개념 설명

개념 ① 인덱싱과 슬라이싱
a[0]은 첫 값, a[-1]은 마지막 값, a[1:4]는 1번부터 3번까지(끝 인덱스 미포함)입니다. 2차원은 m[행, 열], m[:, 0](모든 행의 0열), m[1:, 1:]처럼 씁니다.
개념 ② 벡터화 연산과 불리언 마스크
scores + 5, scores * 2는 모든 원소에 적용됩니다. scores >= 85는 True/False 배열을 만들고, 이를 scores[scores >= 85]처럼 넣으면 조건에 맞는 값만 뽑힙니다.

필수 코드 이해

import numpy as np
scores = np.array([80, 90, 75, 85, 95])
print(scores[0], scores[-1], scores[1:4])
print(scores + 5)
print(scores >= 85)
print(scores[scores >= 85])
80 95 [90 75 85]
[85 95 80 90 100]
[False  True False  True  True]
[90 85 95]

3. 통계, axis, 모양 변경, 브로드캐스팅

학습 목표: 행·열 방향으로 통계를 계산하고, 배열의 모양을 바꾸며, 서로 다른 모양의 배열을 계산할 수 있다.

핵심 개념 설명

개념 ① axis(계산 방향)
2차원 배열에서 axis=0은 같은 열끼리(세로 방향), axis=1은 같은 행끼리(가로 방향) 계산합니다. 학생(행)별 평균은 axis=1, 과목(열)별 평균은 axis=0입니다.
개념 ② reshape와 브로드캐스팅
reshape는 원소 수를 유지한 채 모양만 바꿉니다. 브로드캐스팅은 작은 배열을 자동으로 늘려 큰 배열과 계산하는 규칙입니다. 예: (3,3) 배열 + (3,) 배열은 각 행에 같은 값을 더합니다.

필수 코드 이해

import numpy as np
m = np.arange(1, 13).reshape(3, 4)
print(m)
print(m.sum())
print(m.sum(axis=0))
print(m.sum(axis=1))
print(m.mean(axis=0))

실습 2 — 보너스 점수와 순위 구하기

4. 난수, 선형대수, 파일 입출력, 종합 응용

학습 목표: 난수 생성, 행렬 곱, 파일 저장·불러오기를 익히고 작은 데이터 분석 프로젝트를 완성한다.

핵심 개념 설명

개념 ① 난수와 시뮬레이션
np.random.randint(1, 7, size=1000)은 주사위 1000번 던지기와 같습니다. np.random.seed(42)로 시드를 고정하면 매번 같은 결과가 나와 수업과 검증에 편리합니다(시드 없이는 실행마다 결과가 다름).
개념 ② 행렬 곱과 파일 입출력
scores @ weights(또는 np.dot)는 과목별 가중치를 적용한 총점을 한 번에 계산합니다. np.savetxt/np.loadtxt는 배열을 CSV로 저장하고 불러옵니다.

필수 코드 이해

import numpy as np
np.random.seed(42)
dice = np.random.randint(1, 7, size=1000)
print(dice[:5])               # 처음 5번 결과
print(np.bincount(dice)[1:])  # 1~6 각각 나온 횟수 (합계 1000)

실습 1 — 주사위 1000번 시뮬레이션

목표: 난수와 통계로 확률을 확인한다.

import numpy as np
np.random.seed(42)
dice = np.random.randint(1, 7, size=1000)
counts = np.bincount(dice)[1:]
for face, n in zip(range(1, 7), counts):
    print(face, "의 눈:", n, "번", f"({n/10:.1f}%)")
print("평균 눈:", dice.mean())

이론 확률은 약 16.7%, 평균은 3.5입니다. 결과가 이와 비슷한지 비교해 봅니다.

실습 2 — 성적 분석 프로젝트

목표: 앞의 내용을 종합해 총점 계산, 등급 구분, 파일 저장까지 수행한다.

import numpy as np
scores = np.array([[80, 90, 70],
                   [85, 95, 88],
                   [75, 80, 90]])
weights = np.array([0.3, 0.3, 0.4])   # 과목별 반영 비율
total = scores @ weights
print("가중 총점:", total)
grade = np.where(total >= 80, "우수", "보통")
print("등급:", grade)
np.savetxt("scores.csv", scores, delimiter=",", fmt="%d")
loaded = np.loadtxt("scores.csv", delimiter=",", dtype=int)
print("불러온 배열 shape:", loaded.shape)
가중 총점: [79.  89.2 82.5]
등급: ['보통' '우수' '우수']
불러온 배열 shape: (3, 3)
