자료구조와 알고리즘 이론

정보처리산업기사 필기에 자주 나오는 자료구조와 알고리즘을 그림과 함께 정리한 문서이다. 처음 배우는 사람도 따라올 수 있도록 일상 비유와 단계별 예시를 함께 넣었다. 비유로 감을 잡고, 그림으로 확인한 뒤, 시험 포인트로 마무리한다.

시작 전에배열·연결리스트스택큐트리그래프정렬탐색복잡도

0. 시작하기 전에

이 문서를 읽기 전에 두 단어의 뜻부터 잡고 가자.

자료구조는 물건을 정리하는 방법이다. 옷을 서랍에 개어 넣을지, 옷걸이에 걸지에 따라 꺼내기 쉬운 정도가 달라진다. 컴퓨터도 데이터를 어떻게 넣어 두느냐에 따라 찾고 지우는 속도가 달라진다.

알고리즘은 문제를 푸는 순서이다. 라면 끓이는 레시피처럼 ‘물 끓이기 → 면 넣기 → 스프 넣기’ 하는 식으로, 정해진 순서대로 하면 같은 결과가 나온다.

자주 나오는 용어

  • 노드(Node): 데이터 하나를 담은 상자이다.
  • 인덱스(Index): 배열에서 칸의 번호이다. 컴퓨터는 0부터 센다.
  • 포인터(Pointer): 다른 노드가 어디 있는지 적어 둔 주소이다. 쪽지에 적힌 ‘다음 장소’와 같다.
  • n: 데이터의 개수이다. 알고리즘이 빠른지 느린지는 n이 커질 때 비교한다.

공부 순서는 배열 → 스택·큐 → 트리·그래프 → 정렬·탐색을 권한다. 앞에서 배운 개념이 뒤에서 계속 쓰인다.

1. 배열과 연결리스트

자료구조는 데이터를 저장하고 관리하는 방법이다. 가장 기본이 되는 선형 구조는 배열과 연결리스트이다.

배열은 같은 자료형의 값을 메모리에 연속해서 저장한다. 인덱스로 바로 접근할 수 있어 조회가 빠르다. 반면 중간에 값을 넣거나 지우면 뒤의 값을 모두 밀거나 당겨야 한다.

연결리스트는 노드가 데이터와 다음 노드의 주소(포인터)를 함께 가진다. 노드가 흩어져 있어도 포인터로 이어지므로, 삽입과 삭제는 포인터만 바꾸면 된다. 대신 n번째 노드를 찾으려면 처음부터 따라가야 한다.

  • 배열: 조회 O(1), 삽입·삭제 O(n)
  • 연결리스트: 조회 O(n), 삽입·삭제 O(1) (위치를 알고 있을 때)

쉽게 이해하기 배열은 번호가 붙은 사물함 줄이다. 3번 사물함을 열고 싶으면 3번 앞으로 가면 된다. 대신 사물함은 줄지어 붙어 있어서, 중간에 하나를 끼워 넣으려면 뒤의 물건을 전부 옆으로 옮겨야 한다.

연결리스트는 보물찾기이다. 첫 쪽지에 ‘다음 쪽지는 놀이터에 있다’고 적혀 있고, 그 쪽지에 또 다음 장소가 적혀 있다. 중간에 쪽지를 하나 끼우려면 앞 쪽지의 안내만 새 쪽지로 바꾸면 된다.

예: 20과 30 사이에 25를 넣기

  1. 배열 [10, 20, 30, 40, 50]에서는 50, 40, 30을 차례로 한 칸씩 오른쪽으로 민다(3번 이동).
  2. 빈 자리에 25를 넣는다. 데이터가 많을수록 미는 횟수가 늘어난다.
  3. 연결리스트에서는 새 노드 25를 만들고, 25가 30을 가리키게 한 다음, 20이 25를 가리키게 바꾼다(포인터 2개만 변경).
시험 포인트 삽입·삭제가 잦으면 연결리스트, 조회가 잦으면 배열이 유리하다. 연결리스트의 마지막 노드의 포인터는 NULL이다.

2. 스택 (Stack)

스택은 한쪽 끝(top)에서만 삽입과 삭제가 일어나는 구조이다. 가장 나중에 들어온 데이터가 가장 먼저 나가므로 LIFO(Last In First Out)라고 한다. 쌓아 둔 접시를 위에서부터 꺼내는 모습과 같다.

삽입을 push, 삭제를 pop이라 한다. 스택이 가득 찬 상태에서 push하면 오버플로, 빈 상태에서 pop하면 언더플로가 발생한다.

스택의 활용

  • 함수 호출과 복귀 주소 관리(재귀 호출)
  • 괄호 검사, 후위 표기식 계산
  • 웹 브라우저의 ‘뒤로 가기’, 실행 취소(Undo)

쉽게 이해하기 스택은 한쪽만 뚫린 과자 통이다. 위에서 넣고 위에서만 꺼낼 수 있으니 가장 먼저 넣은 과자는 맨 마지막에 나온다.

예 1: 괄호가 짝이 맞는지 검사하기

식 (a+b)를 왼쪽부터 읽는다. 여는 괄호 (를 만나면 push하고, 닫는 괄호 )를 만나면 pop한다. 끝났을 때 스택이 비어 있으면 괄호가 올바르다. 닫는 괄호인데 스택이 비어 있거나, 끝났는데 스택에 남은 것이 있으면 짝이 맞지 않는 식이다.

예 2: 후위 표기식 3 4 + 2 * 계산하기

  1. 3을 만나 push → 스택 [3]
  2. 4를 만나 push → 스택 [3, 4]
  3. +를 만나면 두 개를 pop(4, 3)해서 3+4=7을 계산하고 push → 스택 [7]
  4. 2를 만나 push → 스택 [7, 2]
  5. *를 만나면 7×2=14를 계산하고 push → 스택 [14]. 최종 결과는 14이다.

파이썬에서는 리스트로 스택을 쉽게 만든다.

stack = []
stack.append("A")   # push
stack.append("B")   # push
print(stack.pop())  # pop -> B
시험 포인트 중위식 A+B*C를 후위식으로 바꾸면 ABC*+이다. 후위식은 피연산자를 만나면 스택에 쌓고, 연산자를 만나면 두 개를 꺼내 계산한다.

3. 큐 (Queue)

큐는 한쪽에서 삽입하고 반대쪽에서 삭제하는 구조이다. 먼저 들어온 데이터가 먼저 나가므로 FIFO(First In First Out)라고 한다. 줄을 서서 기다리는 모습과 같다.

삭제가 일어나는 앞쪽을 front, 삽입이 일어나는 뒤쪽을 rear라 한다. 삽입은 enqueue, 삭제는 dequeue이다.

  • 원형 큐: 배열의 끝과 처음을 이어 공간 낭비를 줄인 큐
  • 데크(Deque): 양쪽 끝에서 삽입과 삭제가 모두 가능한 큐
  • 활용: 프린터 대기열, 프로세스 스케줄링, 너비 우선 탐색(BFS)

쉽게 이해하기 큐는 매표소 앞의 줄이다. 먼저 온 사람이 먼저 표를 사고 나가며, 새로 온 사람은 맨 뒤에 선다. 새치기는 없다.

구분스택큐
규칙LIFO (나중에 넣은 것이 먼저 나옴)FIFO (먼저 넣은 것이 먼저 나옴)
드나드는 곳한쪽 끝(top)양쪽 끝(front, rear)
비유과자 통, 쌓은 접시매표소 줄

원형 큐는 왜 필요할까?

배열로 만든 일반 큐는 앞에서 계속 꺼내면 앞쪽 칸이 비어도 다시 쓰지 못한다. 그래서 끝에 도착하면 다시 처음 칸으로 돌아가도록 배열을 원처럼 이어 붙인다. 시계에서 12시 다음이 다시 1시인 것과 같다. 이렇게 하면 빈 칸을 낭비하지 않는다.

시험 포인트 스택은 LIFO, 큐는 FIFO이다. 시험에서 가장 자주 나오는 비교 문제이다.

4. 트리 (Tree)

트리는 노드가 계층 구조로 연결된 비선형 자료구조이다. 맨 위 노드를 루트(root), 자식이 없는 노드를 단말(leaf) 노드라 한다. 노드가 가진 자식의 수를 차수(degree), 루트에서 가장 깊은 노드까지의 단계를 높이(level)라 한다.

이진 트리는 각 노드의 자식이 최대 2개인 트리이다. 노드를 방문하는 순서에 따라 세 가지 순회 방법이 있다.

순회방문 순서그림 4의 결과
전위(Preorder)루트 → 왼쪽 → 오른쪽A B D E C F
중위(Inorder)왼쪽 → 루트 → 오른쪽D B E A C F
후위(Postorder)왼쪽 → 오른쪽 → 루트D E B F C A

이진 탐색 트리는 왼쪽 자식이 부모보다 작고 오른쪽 자식이 부모보다 큰 트리이다. 중위 순회를 하면 오름차순으로 정렬된 결과가 나온다.

쉽게 이해하기 트리는 가계도나 회사 조직도를 뒤집어 놓은 모양이다. 맨 위에 사장(루트)이 있고, 아래로 부장, 과장, 사원이 이어진다. 한 사람의 바로 위 노드를 부모, 바로 아래 노드를 자식, 같은 부모를 가진 노드를 형제라 한다.

순회 순서 쉽게 외우기

루트를 N, 왼쪽을 L, 오른쪽을 R이라 하면 전위는 N-L-R, 중위는 L-N-R, 후위는 L-R-N이다. 이름은 ‘루트(부모)를 언제 방문하느냐’를 뜻한다. 전위는 앞, 중위는 가운데, 후위는 뒤에서 방문한다.

예: 그림 4를 후위 순회하기

  1. 루트 A의 왼쪽 B부터 간다. B의 왼쪽 D를 방문한다(D).
  2. B의 오른쪽 E를 방문한다(E). 그다음 B를 방문한다(B).
  3. A의 오른쪽 C로 간다. C의 왼쪽은 없으므로 오른쪽 F를 방문한다(F). 그다음 C를 방문한다(C).
  4. 마지막으로 A를 방문한다(A). 결과는 D E B F C A이다.
시험 포인트 루트의 이름이 앞에 오면 전위, 가운데 오면 중위, 뒤에 오면 후위이다. 레벨이 k인 이진 트리의 최대 노드 수는 2k−1이다(루트 레벨 1 기준).

5. 그래프 (Graph)

그래프는 정점(Vertex)과 정점을 잇는 간선(Edge)으로 이루어진 구조이다. 도로망, 지하철 노선, 친구 관계처럼 ‘연결’이 중요한 문제를 표현한다. 간선에 방향이 있으면 방향 그래프, 없으면 무방향 그래프라 한다.

그래프를 탐색하는 대표적인 방법은 두 가지이다. 깊이 우선 탐색(DFS)은 한 방향으로 끝까지 들어간 뒤 되돌아오며 스택(또는 재귀)을 사용한다. 너비 우선 탐색(BFS)은 가까운 정점부터 차례로 방문하며 큐를 사용한다.

  • DFS는 2번에서 4번으로 깊이 들어갔다가, 막히면 돌아와 3번을 방문한다.
  • BFS는 1번과 가까운 2, 3번을 먼저 방문하고, 그다음 4번, 5번 순으로 간다.
  • 표현 방법: 인접 행렬(정점이 적고 간선이 많을 때), 인접 리스트(간선이 적을 때)

쉽게 이해하기 그래프는 지하철 노선도이다. 역이 정점이고 역과 역을 잇는 선이 간선이다. 트리는 그래프의 한 종류로, 순환(돌고 도는 길)이 없는 그래프이다.

DFS는 미로에서 한 길을 막힐 때까지 쭉 가다가 되돌아오는 방식이다. BFS는 호수에 돌을 던졌을 때 물결이 가까운 곳부터 바깥으로 퍼지는 방식이다. 최단 경로(거쳐 가는 간선 수)를 찾을 때는 BFS가 적합하다.

그래프를 컴퓨터에 저장하는 법

그림 5의 그래프를 인접 리스트로 나타내면 ‘각 정점과 연결된 이웃 목록’이 된다.

1: 2, 3
2: 1, 4
3: 1, 4
4: 2, 3, 5
5: 4

인접 행렬은 정점 n개를 가로·세로로 놓은 n×n 표에 연결된 곳은 1, 아닌 곳은 0을 적는 방법이다. 표가 커서 메모리를 많이 쓰지만, 두 정점이 연결됐는지 바로 확인할 수 있다.

시험 포인트 DFS는 스택, BFS는 큐를 쓴다. n개의 정점을 모두 연결하는 최소 간선 수는 n−1개이다(신장 트리).

6. 정렬 알고리즘

정렬은 데이터를 일정한 기준(오름차순 또는 내림차순)으로 나열하는 작업이다. 알고리즘마다 방식과 속도가 다르다.

기본 정렬 (느리지만 단순)

  • 버블 정렬: 이웃한 두 값을 비교해 큰 값을 뒤로 보낸다. 한 번 돌 때마다 가장 큰 값이 맨 뒤에 자리 잡는다.
  • 선택 정렬: 남은 값 중 가장 작은 값을 골라 앞에서부터 채운다.
  • 삽입 정렬: 이미 정렬된 부분에 새 값을 알맞은 자리에 끼워 넣는다. 거의 정렬된 데이터에서 빠르다.

고급 정렬 (빠름)

  • 퀵 정렬: 기준값(피벗)을 정해 작은 값은 왼쪽, 큰 값은 오른쪽으로 나눈 뒤 각각 같은 방법으로 반복한다(분할 정복).
  • 병합 정렬: 데이터를 반으로 계속 나눈 뒤 정렬하면서 합친다. 항상 O(n log n)이다.
  • 힙 정렬: 힙 트리를 만들어 최댓값(또는 최솟값)을 차례로 꺼낸다.
알고리즘평균최악특징
버블O(n²)O(n²)안정, 구현 쉬움
선택O(n²)O(n²)교환 횟수 적음
삽입O(n²)O(n²)거의 정렬되면 O(n)
퀵O(n log n)O(n²)평균 가장 빠름
병합O(n log n)O(n log n)추가 메모리 필요
힙O(n log n)O(n log n)제자리 정렬

쉽게 이해하기 카드 게임에서 손에 든 카드를 정리하는 방법으로 생각하면 쉽다. 선택 정렬은 남은 카드 중 가장 작은 카드를 골라 앞에 놓는 방법이다. 삽입 정렬은 새로 받은 카드를 이미 정리된 카드 사이의 알맞은 자리에 끼우는 방법이다.

예: 퀵 정렬 [5, 2, 8, 1, 9]

  1. 첫 값 5를 피벗으로 잡는다.
  2. 5보다 작은 값 [2, 1]은 왼쪽, 큰 값 [8, 9]는 오른쪽으로 나눈다.
  3. 왼쪽 [2, 1]과 오른쪽 [8, 9]를 같은 방법으로 각각 정렬한다. [1, 2]와 [8, 9]가 된다.
  4. 합치면 [1, 2, 5, 8, 9]이다. 큰 문제를 작은 문제로 쪼개 푸는 이 방식을 분할 정복이라 한다.

예: 병합 정렬 [4, 1, 3, 2]

[4, 1, 3, 2]를 [4, 1]과 [3, 2]로 나누고, 더 나누어 [4] [1] [3] [2]로 만든다. 이제 두 개씩 크기를 비교해 합친다. [1, 4]와 [2, 3]이 되고, 마지막으로 앞에서부터 작은 값을 골라 합치면 [1, 2, 3, 4]가 된다.

정렬이 ‘안정적’이라는 말은, 값이 같은 두 데이터가 정렬 전후에 순서가 바뀌지 않는다는 뜻이다. 예를 들어 점수가 같은 학생의 이름 순서가 유지된다.

시험 포인트 퀵 정렬은 이미 정렬된 데이터에서 최악(O(n²))이 된다. 같은 값의 순서가 유지되는 정렬을 안정 정렬이라 하며 버블, 삽입, 병합이 여기에 속한다.

7. 탐색 알고리즘

탐색은 원하는 값을 찾는 작업이다. 선형 탐색은 처음부터 하나씩 비교하므로 O(n)이며, 정렬되지 않은 데이터에도 쓸 수 있다.

이진 탐색은 정렬된 데이터의 가운데 값과 비교해 찾을 범위를 절반씩 줄인다. 한 번 비교할 때마다 후보가 반으로 줄어 O(log n)이다.

해싱은 키를 해시 함수에 넣어 저장 위치를 바로 계산하는 방법이다. 평균 O(1)로 매우 빠르다. 서로 다른 키가 같은 위치를 가리키는 충돌이 생기면 개방 주소법이나 체이닝으로 해결한다.

쉽게 이해하기 선형 탐색은 책을 첫 쪽부터 한 장씩 넘기며 단어를 찾는 방법이다. 이진 탐색은 국어사전에서 단어를 찾는 방법이다. 사전 한가운데를 펴서 찾는 단어가 앞쪽인지 뒤쪽인지 보고, 해당하는 절반만 다시 편다.

얼마나 차이가 날까?

데이터가 1,000개일 때 선형 탐색은 최대 1,000번 비교한다. 이진 탐색은 1,000 → 500 → 250 → ... 식으로 절반씩 줄어 최대 10번이면 된다(210=1,024). 데이터가 많을수록 차이는 더 커진다.

해싱 예: 학번 % 10으로 사물함 정하기

학번 25번 학생은 25를 10으로 나눈 나머지 5번 사물함에 넣는다. 찾을 때도 같은 계산만 하면 바로 5번으로 간다. 그런데 학번 35번도 나머지가 5라서 같은 사물함을 가리킨다. 이것이 충돌이다. 체이닝은 같은 사물함 안에 줄을 이어 붙이는 방법이고, 개방 주소법은 비어 있는 다음 사물함에 넣는 방법이다.

시험 포인트 이진 탐색은 반드시 정렬된 데이터에서만 사용한다. 대표적인 해시 함수에는 나머지(제산)법, 접기법, 숫자 분석법이 있다.

8. 시간 복잡도

알고리즘의 효율은 입력 크기 n이 커질 때 실행 시간이 얼마나 늘어나는지로 비교한다. 이를 빅오(Big-O) 표기법으로 나타내며, 가장 영향이 큰 항만 남긴다. 예를 들어 3n²+5n+2는 O(n²)이다.

빠른 순서는 O(1) < O(log n) < O(n) < O(n log n) < O(n²) < O(2n)이다.

쉽게 이해하기 시간 복잡도는 ‘일의 양이 늘 때 시간이 얼마나 늘까?’를 묻는 것이다. 숙제 분량이 2배가 되었을 때, O(n)이면 시간도 2배, O(n²)이면 4배, O(log n)이면 겨우 한 단계만 늘어난다.

코드로 감 잡기

# O(1): 한 번만 실행
print(arr[0])

# O(n): 반복문 하나
for x in arr:
    print(x)

# O(n²): 반복문 안에 반복문
for x in arr:
    for y in arr:
        print(x, y)

n이 100일 때 실행 횟수는 O(n)이 약 100번, O(n²)은 약 10,000번이다. 반복문이 겹칠수록 횟수가 크게 늘어난다는 점만 기억하면 된다.

시험 포인트 이중 반복문은 보통 O(n²), 반으로 줄여 가는 구조는 O(log n)이다. 최선·평균·최악의 경우를 구분해서 묻는 문제가 자주 나온다.
