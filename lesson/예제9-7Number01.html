예제 9-7: JavaScript Number 객체 속성 분석 보고서

본 문서는 JavaScript 숫자(Number) 객체가 제공하는 주요 정적 속성(MAX_VALUE, MIN_VALUE, POSITIVE_INFINITY, NEGATIVE_INFINITY)의 개념과 표현 범위를 분석한 내용입니다.

1. HTML 전체 소스코드

<!DOCTYPE html>
<html>
<head>
	<title>예제9-7Number 속성</title>
</head>
<body>
<h3>Number 속성</h3>
<p>MAX_VALUE : <b id="ca"></b></p>
<p>MIN_VALUE : <b id="cca"></b></p>
<p>POSITIVE_INFINITY : <b id="cnct"></b></p>
<p>NEGATIVE_INFINITY : <b id="ido"></b></p>
<script>
	document.getElementById("ca").innerHTML = Number.MAX_VALUE;
	document.getElementById("cca").innerHTML = Number.MIN_VALUE;
	document.getElementById("cnct").innerHTML = Number.POSITIVE_INFINITY;
	document.getElementById("ido").innerHTML = Number.NEGATIVE_INFINITY; 
</script>
</body>
</html>

2. HTML 구조 및 DOM 요소 설명

  • <h3>: 화면 대표 제목(Number 속성)을 정의합니다.
  • <p> 및 <b id="..."> 태그: Number 객체의 속성 값을 동적으로 바인딩하여 출력하기 위한 DOM 구역입니다. ca, cca, cnct, ido 등의 고유 ID가 부여되어 있습니다.

3. JavaScript Number 주요 속성 상세 분석

속성명 사용 표현 동작 설명 및 의미
Number.MAX_VALUE Number.MAX_VALUE JavaScript에서 표현할 수 있는 가장 큰 양의 숫자를 나타냅니다. (약 1.79E+308) 이 값을 초과하면 무한대(Infinity)로 처리됩니다.
Number.MIN_VALUE Number.MIN_VALUE JavaScript에서 표현할 수 있는 0에 가장 가까운 양의 숫자를 나타냅니다. (약 5E-324) 0은 아니지만 0에 근접한 가장 작은 양수입니다.
Number.POSITIVE_INFINITY Number.POSITIVE_INFINITY 양의 무한대(Infinity)를 나타내는 특수한 상숫값입니다. 오버플로우 발생 시 반환됩니다.
Number.NEGATIVE_INFINITY Number.NEGATIVE_INFINITY 음의 무한대(-Infinity)를 나타내는 특수한 상숫값입니다.

4. 실행 과정 및 브라우저 최종 출력 결과

Number 속성

MIN_VALUE : 5e-324

POSITIVE_INFINITY : Infinity

NEGATIVE_INFINITY : -Infinity
