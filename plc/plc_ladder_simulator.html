웹 기본 래더 PLC 시뮬레이터

래더 로직

입력 I

출력 Q

내부 릴레이 M

타이머 T

사용법

  1. ▶ 실행을 누르면 100ms마다 한 번씩 스캔 사이클이 실행됩니다.
  2. 왼쪽의 I0, I1, I2를 클릭하면 입력 스위치가 ON/OFF됩니다.
  3. 래더의 요소 상자를 클릭하면 a접점 → b접점 → 코일 → TON 타이머 순서로 바뀝니다.
  4. + 랑 추가로 새 논리 줄을 만들고, + 요소로 접점·코일·타이머를 추가합니다.
  5. ⏭ 1스캔은 실행을 멈춘 상태에서 논리를 한 주기만 평가합니다.
  6. 초록색 선과 상자는 현재 통전 중임을 뜻합니다.

예제 1: 기본 ON/OFF

스위치 I0를 ON하면 램프 Q0가 켜집니다.

I0 ──[ ]── ( Q0 )

설정: 첫 요소 a접점 I0, 마지막 요소 코일 Q0. `I0`를 클릭해 ON으로 바꾸면 `Q0`가 ON됩니다.

예제 2: AND 조건

안전 스위치와 시작 스위치가 모두 ON일 때만 모터가 작동합니다.

I0 ──[ ]── I1 ──[ ]── ( Q0 )

설정: a접점 I0, a접점 I1, 코일 Q0. 두 입력이 모두 ON되어야 `Q0`가 ON됩니다.

예제 3: 지연 켜짐

스위치를 켠 뒤 약 1초 후에 램프가 켜집니다.

I1 ──[ ]── TON T0 ── ( Q1 )

설정: a접점 I1, TON 타이머 T0, 코일 Q1. `I1`을 ON하면 `T0`가 100ms씩 누적되고, 1000ms가 되면 `Q1`이 ON됩니다. `I1`을 끄면 타이머가 초기화됩니다.

예제 4: 정지 우선

비상정지 I2가 ON이면 시작 스위치를 눌러도 출력이 켜지지 않습니다.

I2 ──[/]── I0 ──[ ]── ( Q2 )

설정: b접점 I2, a접점 I0, 코일 Q2. `I2`가 OFF이고 `I0`가 ON일 때만 `Q2`가 ON됩니다.

예제 5: 3상 모터 기본 기동

시작 스위치와 열동계전기 접점으로 주접촉기 MC를 제어합니다.

I2 ──[/]── I0 ──[ ]── ( Q0 )

해석: `I0`=운전 스위치, `I2`=열동계전기/비상정지 접점, `Q0`=주접촉기 MC. `I2`가 OFF이고 `I0`가 ON이면 모터용 접촉기 `Q0`가 ON됩니다. 실제 3상 전원에는 R·S·T 상에 MC 주접점과 과부하계전기가 직렬로 배치됩니다.

예제 6: 자기유지 회로

누름 후 손을 떼어도 출력이 유지되고, 정지 스위치로만 해제됩니다.

I2 ──[/]── I0 ──[ ]── (SET M0)
M0 ──[ ]──────────────── ( Q0 )
I1 ──[ ]──────────────── (RST M0)

조작: `I0`를 한 번 ON하면 `M0`가 SET되어 유지됩니다. 이후 `I0`를 OFF해도 `Q0`는 ON 상태를 유지합니다. `I1`=정지 스위치를 ON하면 `M0`가 RST되어 `Q0`가 OFF됩니다. `I2`=열동계전기 접점이면 이상 시 자기유지가 해제됩니다.

예제 7: Y-Δ 기동

기동 초기에는 Y결선으로 저전압 기동하고, 일정 시간 후 Δ결선으로 전환합니다.

I2 ──[/]── I0 ──[ ]── (SET M0)
M0 ──[ ]── TON T0 ── ( Q1 ) // Y접촉기
T0 ──[ ]────────────── ( Q2 ) // Δ접촉기
Q2 ──[/]───────────── ( Q1 ) // Y 차단 인터록
Q1 ──[/]───────────── ( Q2 ) // Δ 차단 인터록

해석: `Q0`=주접촉기 MC, `Q1`=Y접촉기, `Q2`=Δ접촉기입니다. 기동 시 `Q0`와 `Q1`이 ON되고, `T0`가 설정시간에 도달하면 `Q2`가 ON됩니다. `Q1`과 `Q2`의 b접점 인터록으로 두 접촉기가 동시에 ON되는 것을 방지합니다. 실제 전환 시에는 Y접촉기가 먼저 완전히 OFF된 뒤 Δ접촉기가 ON되도록 순서와 지연을 검증해야 합니다.

예제 8: 정회전·역회전 인터록

정회전과 역회전 접촉기가 동시에 ON되어 상간 단락되는 것을 방지합니다.

I2 ──[/]── I0 ──[ ]── Q2 ──[/]── ( Q1 ) // 정회전
I2 ──[/]── I1 ──[ ]── Q1 ──[/]── ( Q2 ) // 역회전

해석: `Q1`=정회전 접촉기, `Q2`=역회전 접촉기입니다. 정회전 중에는 `Q2`의 b접점이 열려 역회전 명령이 무시되고, 역회전 중에는 반대로 작동합니다. 안전을 위해 실제 배선에도 전기적 인터록과 기계적 인터록을 함께 적용하는 것이 표준적인 방법입니다.
