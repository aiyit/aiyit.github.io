예제 10-6: onLoad() 이벤트와 쿠키(Cookie) 분석 문서

본 문서는 웹 페이지 로딩 완료 시점을 제어하는 `onload` 이벤트와, 웹 브라우저가 사용자 상태 정보를 기억하기 위해 사용하는 HTTP 쿠키(Cookie)의 개념 및 제어 방법을 상세히 설명합니다.

1. HTTP 쿠키(Cookie) 개념 및 제어 방법 상세 이해

쿠키(Cookie)란 웹사이트가 사용자의 웹 브라우저에 전송하는 작고 가벼운 데이터 파일 조각입니다. 브라우저는 이 쿠키를 로컬에 저장해 두었다가, 동일한 웹사이트에 다시 방문할 때 서버로 해당 쿠키를 자동으로 함께 전송합니다.

💡 중요 참고사항: 사용자의 브라우저 전역 설정인 navigator.cookieEnabled(쿠키 허용/차단 여부)는 보안상의 이유로 자바스크립트로 강제 설정하거나 해제할 수 없습니다(읽기 전용 속성). 쿠키 기능 설정/해제는 브라우저의 환경 설정 메뉴에서 직접 수행해야 합니다. 대신 자바스크립트로는 쿠키 데이터의 생성, 조회, 삭제를 제어할 수 있습니다.

1) 자바스크립트 쿠키 생성 및 삭제 코드 (주석문 포함)

아래는 소스코드 내에서 쿠키를 다룰 때 사용하는 전형적인 구문과 주석 설명입니다.

// 1. 쿠키 생성(저장) 예시
// 이름, 값, 만료 시간(max-age, 초 단위), 경로(path)를 지정하여 저장합니다.
// document.cookie = "username=SmartPark; max-age=3600; path=/";

// 2. 쿠키 삭제(만료) 예시
// 쿠키의 만료 시간(max-age)을 0으로 설정하면 브라우저가 즉시 해당 쿠키를 폐기합니다.
// document.cookie = "username=; max-age=0; path=/";

2. 제공된 HTML 원본 코드 (주석 포함)

<!DOCTYPE html>
<html>
<head>
  <link rel="stylesheet" href="style.css">
  <meta charset="utf-8">
  <title>예제 10-6 onLoad()</title>
</head>
<body onload="checkCookies()">
  <p id="cook">onLoad()</p>
  
  <script>
    function checkCookies() {
      var text = "";
      
      // 브라우저의 쿠키 활성화 여부 확인 (읽기 전용 속성이므로 강제 설정/해제 불가)
      if (navigator.cookieEnabled) {
        text = "브라우저의 쿠키 기능이 설정되어 있습니다.";
      } else {
        text = "브라우저의 쿠키 기능이 꺼져 있습니다.";
      }
      
      document.getElementById("cook").innerHTML = text;

      /*
        [참고: 자바스크립트를 통한 쿠키 제어 주석문 코드]
        - 쿠키 생성: document.cookie = "user=Park; max-age=60; path=/";
        - 쿠키 삭제: document.cookie = "user=; max-age=0; path=/";
      */
    }
  </script>
</body>
</html>

3. 주요 코드 요소 및 동작 상세 분석

코드 요소 사용 예시 동작 설명 및 특징
navigator.cookieEnabled if (navigator.cookieEnabled) { ... } 사용자의 브라우저에서 쿠키 사용이 허용되어 있는지를 확인하는 읽기 전용 부울리언 속성입니다.
쿠키 생성/삭제 주석문 document.cookie = "...; max-age=0;"; 브라우저 설정 자체는 스크립트로 바꿀 수 없으나, 저장된 쿠키 데이터는 document.cookie를 통해 생성 및 만료(삭제) 처리할 수 있습니다.
onload 이벤트 <body onload="checkCookies()"> 페이지가 열리는 시점에 브라우저의 쿠키 지원 환경 여부를 자동으로 검사합니다.

핵심 정리

  • 브라우저 설정: navigator.cookieEnabled는 읽기 전용이므로 자바스크립트로 강제 ON/OFF 불가
  • 데이터 제어: document.cookie를 통한 쿠키 데이터 생성 및 만료(삭제) 처리는 가능
  • 환경 검사: 쿠키 사용 필수 웹 앱에서 클라이언트 환경을 사전 진단하는 데 활용

학습 포인트: 브라우저 쿠키의 제약 사항(설정 변경 불가)과 자바스크립트를 통한 데이터 관리 방식의 차이를 이해합니다.
