예제 10-1: DOM(Document Object Model) 요소 찾기 분석 문서

본 문서는 웹 페이지의 구조와 동적 제어의 핵심인 DOM(문서 객체 모델)의 상세 개념과, HTML 문서 내에서 태그명, ID, 클래스 이름을 기반으로 요소를 탐색하고 제어하는 JavaScript 메서드들의 활용법을 설명합니다.

1. DOM (Document Object Model) 개념 상세 이해

DOM(Document Object Model, 문서 객체 모델)은 웹 브라우저가 HTML 또는 XML 문서를 메모리에 적재한 후, 문서의 구조화된 요소를 객체(Object)의 트리 구조(Tree Structure)로 표현하여 프로그램(JavaScript 등)이 문서에 접근하고 제어할 수 있도록 제공하는 인터페이스입니다.

💡 핵심 포인트: DOM은 단순한 HTML 소스 코드가 아닙니다. 브라우저가 HTML 코드를 읽어 들여 파싱(Parsing)한 결과물로 생성되는 동적인 메모리 객체 모델입니다.

1) DOM 트리 구조 (Hierarchy & Nodes)

브라우저는 HTML 문서를 로드할 때 각 태그와 텍스트, 속성을 계층적인 노드(Node) 단위로 변환합니다. 모든 노드는 부모-자식 및 형제 관계로 연결되어 거대한 '트리'를 형성합니다.

  • 문서 노드 (Document Node): 트리의 최상위 루트(Root) 객체로 전체 문서 자체를 가리킵니다 (`document`).
  • 요소 노드 (Element Node): HTML 태그(예: <h1>, <p>, <body> 등)를 의미하며, DOM 트리의 뼈대를 이룹니다.
  • 텍스트 노드 (Text Node): HTML 태그가 담고 있는 순수 텍스트 내용(예: "요소찾기(Find Element)")을 의미하며, 요소 노드의 자식 노드로 존재합니다.
  • 속성 노드 (Attribute Node): HTML 태그의 속성(예: id="txt", class="cls")을 의미합니다. (※ 최신 사양에서는 요소 노드의 프로퍼티로 주로 취급됩니다.)

2) DOM이 필요한 이유와 역할

웹 초기에는 HTML 문서가 정적(Static)이었으나, 오늘날의 웹 애플리케이션은 사용자 인터랙션에 따라 실시간으로 화면 내용이 바뀌어야 합니다(동적 웹). JavaScript는 자체적으로 브라우저 화면을 그릴 수 있는 능력이 없기 때문에, 브라우저가 제공하는 DOM API를 통해 문서 구조에 접근하여 요소를 추가, 수정, 삭제하거나 스타일을 변경할 수 있습니다.

2. 제공된 HTML 원본 코드

<!DOCTYPE html>
<html>
<head>  
    <link rel="stylesheet" href="style.css">  
    <meta charset="utf-8">  
    <title>예제10-1요소찾기(Find Element)</title>  
    <script>    
        function changeTag() {      
            document.getElementsByTagName("h1")[0].innerHTML = '첫번째 h1: getElementsByTagName';    
        }
        function changeId() {      
            document.getElementById('txt').innerHTML = 'getElementById';    
        }
        function changeCls() {      
            document.getElementsByClassName('cls')[0].innerHTML = 'getElementsByClassName';    
        }  
    </script>
</head>
<body id="main">  
    <h1 style="text-align:center;">요소찾기(Find Element)</h1>
    <p id="txt">이 문장은 p 태그의 내용입니다.</p>  
    <h1 class="cls" style="color:blue;">두 번째 h1 요소</h1>
    <input type="button" id="bt1" value="change_title" onclick="changeTag();">  
    <input type="button" id="bt2" value="change_id" onclick="changeId();">  
    <input type="button" class="bt3" value="change_class" onclick="changeCls();">
</body>
</html>

3. DOM 요소 탐색 메서드 상세 분석

메서드명 사용 예시 동작 설명 및 특징
getElementsByTagName() document.getElementsByTagName("h1")[0] 지정한 태그 이름을 가진 모든 요소를 찾아 HTMLCollection(배열 유사 객체) 형태로 반환합니다. 복수 개가 존재할 수 있으므로 인덱스([0])를 지정해 접근합니다.
getElementById() document.getElementById('txt') HTML 요소의 고유 id 속성값을 기준으로 단 하나의 고유한 요소를 정확히 찾아 반환합니다. 페이지 내에서 ID는 유일해야 합니다.
getElementsByClassName() document.getElementsByClassName('cls')[0] 지정한 클래스 이름을 가진 모든 요소를 찾아 HTMLCollection 형태로 반환합니다. 같은 클래스를 공유하는 여러 요소 중 특정 요소를 인덱스로 선택합니다.

핵심 정리

  • DOM(Document Object Model): HTML 문서를 브라우저가 계층적 트리 구조(노드 객체)로 변환하여 스크립트로 제어할 수 있게 하는 모델
  • 태그명 탐색: getElementsByTagName() (복수 반환, 인덱스 필요)
  • ID 탐색: getElementById() (단일 고유 요소 반환)
  • 클래스 탐색: getElementsByClassName() (복수 반환, 인덱스 필요)

학습 포인트: DOM의 트리 구조와 노드 개념을 이해하고, 목적에 맞는 선택자 메서드를 통해 HTML 요소를 정확히 탐색·제어하는 기법을 익힙니다.
