📂 파이썬 파일 입출력 (File Input / Output)

1. 파일(File)이란?

파일(File)이란 데이터를 영구적으로 저장하는 공간입니다. 프로그램이 종료되면 일반 변수는 모두 사라지지만, 파일에 저장한 데이터는 컴퓨터에 계속 남아 있습니다.

📌 대표적인 활용 예시
  • 학생 성적 저장
  • 회원 정보 저장
  • 시스템 로그 기록
  • 환경 설정값 저장

2. 파일 입출력 과정

파일 열기 (open) │ ▼ 읽기 (Read) 또는 쓰기 (Write) │ ▼ 파일 닫기 (close)

3. open() 함수

파일을 열 때 사용하는 기본 함수입니다.

# 파일객체 = open(파일명, 모드)
f = open("student.txt", "r")

4. 주요 파일 모드(Mode)

모드 의미 파일이 없을 경우
"r" 읽기 (Read) 오류 발생
"w" 쓰기 (Write) 새 파일 생성 (기존 내용 삭제)
"a" 추가 (Append) 새 파일 생성 (기존 내용 뒤에 이어 쓰기)
"x" 새 파일 생성 (Create) 이미 존재하면 오류 발생
"rb" 바이너리 읽기 이미지, 동영상 파일 등
"wb" 바이너리 쓰기 이미지, 동영상 파일 등

5~18. 파일 입출력 통합 프로그램

아래 코드는 5~18절의 파일 쓰기, 읽기, 추가, 인코딩, CSV, 복사, 예외 처리를 한 프로그램으로 보여줍니다. 각 절의 제목은 코드 안의 주석으로 표시했습니다.


import os

os.makedirs("output", exist_ok=True)

# 5. 파일 쓰기 (write)
with open("output/hello.txt", "w", encoding="utf-8") as f:
    f.write("안녕하세요.")
    f.write("나는 여주대학교 AI 소프트웨어학과에 다니는 홍길동입니다.")
# 6. 여러 줄 저장
with open("output/student.txt", "w", encoding="utf-8") as fn:
    fn.write("홍길동\n")
    fn.write("김철수\n")
    fn.write("이영희\n")

# 7. 파일 전체 읽기 (read)
with open("output/hello.txt", "r", encoding="utf-8") as f:
    text = f.read()
with open("output/student.txt", "r", encoding="utf-8") as fn:
    textn =fn.read()
    print(text)
    print(textn)

# 8. 한 줄씩 읽기 (readline)
with open("output/student.txt", "r", encoding="utf-8") as f:
    print(f.readline(), end="")
    print(f.readline(), end="")
    print(f.readline(), end="")

# 9. 모든 줄을 리스트로 읽기 (readlines)
with open("output/student.txt", "r", encoding="utf-8") as f:
    lines = f.readlines()
    print(lines)

# 10. 반복문으로 읽기
# for 반복문은 파일에서 한 줄씩 읽어 line 변수에 저장합니다.
# strip()은 줄 끝의 줄바꿈 문자와 양쪽 공백을 제거한 뒤 해당 줄을 출력합니다.
with open("output/student.txt", "r", encoding="utf-8") as f:
    for line in f:
        print(line.strip())

# 11. 내용 추가하기 ("a" 모드)
with open("output/student.txt", "a", encoding="utf-8") as f:
    f.write("박민수\n")

# 12. with 문으로 파일 자동 닫기
with open("output/student.txt", "r", encoding="utf-8") as f:
    print(f.read())

# 13. UTF-8 인코딩 처리
with open("output/student.txt", "w", encoding="utf-8") as f:
    f.write("안녕하세요.\n")
with open("output/student.txt", "r", encoding="utf-8") as f:
    print(f.read())

# 14. 사용자 입력값 저장
name = input("이름: ")
score = input("점수: ")
with open("output/student.txt", "a", encoding="utf-8") as f:
    f.write(f"{name},{score}\n")

# 15. CSV(Comma-Separated Values) 형태 저장
with open("output/score.csv", "w", encoding="utf-8") as f:
    f.write("이름,Python,AI\n")
    f.write("홍길동,95,90\n")
    f.write("김철수,88,85\n")

# 16. 파일 복사
with open("output/student.txt", "r", encoding="utf-8") as source:
    with open("output/copy.txt", "w", encoding="utf-8") as target:
        target.write(source.read())

# 17. 학생 성적 데이터 저장 및 읽기
students = ["홍길동,95", "김철수,88", "이영희,100"]
with open("output/student.txt", "w", encoding="utf-8") as f:
    for student in students:
        f.write(student + "\n")
with open("output/student.txt", "r", encoding="utf-8") as f:
    for line in f:
        name, score = line.strip().split(",")
        print(name, score)

# 18. 파일 읽기 예외 처리
try:
    with open("output/test.txt", "r", encoding="utf-8") as f:
        print(f.read())
except FileNotFoundError:
    print("파일이 없습니다.")

실제 응용 예제: 학생 성적 기록 및 평균 확인

학생 이름과 점수를 입력해 파일에 저장하고, 지금까지 저장된 성적 목록과 평균을 출력합니다.


file_name = "output/grade_book.csv"

# 1. 학생 정보를 반복해서 입력받기
while True:
    name = input("학생 이름 (종료하려면 '종료' 입력): ")
    # 종료 조건
    if name == "종료":
        break
    score = int(input("학생 점수: "))
    # 파일에 학생 정보 추가
    with open(file_name, "a", encoding="utf-8") as file:
        file.write(f"{name},{score}\n")
    print(f"{name} 학생 성적 저장 완료!\n")

# 2. 파일에 저장된 모든 학생 정보 읽기
students = []
with open(file_name, "r", encoding="utf-8") as file:
    for line in file:
        student_name, student_score = line.strip().split(",")
        students.append((student_name, int(student_score)))

# 3. 학생 성적 출력
print("\n========== 학생 성적 목록 ==========")

for student_name, student_score in students:
    print(f"{student_name}: {student_score}점")

# 4. 전체 평균 계산
if len(students) > 0:
    average = sum(score for _, score in students) / len(students) #_는 사용하지 않을 값을 표시하는 관례
    print("===================================")
    print(f"학생 수: {len(students)}명")
    print(f"평균 점수: {average:.1f}점")
else:
    print("저장된 학생 정보가 없습니다.")

19. 자주 발생하는 오류 체크

  • 파일을 닫지 않음: close()를 누락하여 리소스가 낭비되는 경우. → with open() 사용 권장.
  • 잘못된 경로: 존재하지 않는 폴더 경로 지정 시 오류 발생 (예: open("abc/test.txt")).
  • 인코딩 오류 (UnicodeDecodeError): 한글 깨짐 및 오류 방지를 위해 encoding="utf-8" 지정.

20. open() 주요 메서드 요약

함수 / 메서드 설명
open() 파일 열기
read() 파일 내용 전체를 문자열로 읽기
readline() 파일에서 한 줄씩 읽기
readlines() 파일의 모든 줄을 읽어 리스트로 반환
write() 파일에 내용 쓰기
writelines() 문자열 리스트를 파일에 쓰기
close() 열린 파일 닫기
