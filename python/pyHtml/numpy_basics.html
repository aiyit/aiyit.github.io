1. NumPy란?

NumPy는 숫자를 한꺼번에 계산해 주는 파이썬 도구입니다. 엑셀에서 열 전체를 드래그해서 계산하는 것과 비슷합니다.

❌ 파이썬 리스트
a = [80, 90, 75]
a + 5   # 오류!
# 반복문으로 하나씩 더해야 함
✅ NumPy 배열
import numpy as np
a = np.array([80, 90, 75])
print(a + 5)  # 한 번에 계산
[85 95 80]
💡 import numpy as np 는 NumPy를 불러와 np라는 짧은 이름으로 쓰겠다는 뜻입니다. 아래 메소드 예제는 이 줄을 한 번 실행한 뒤 각각 실행하면 됩니다. 파이썬 리스트는 [80, 90, 75] + [5]처럼 연결되지만, NumPy 배열은 + 5로 모든 원소에 5를 더합니다.

2. 배열은 어떻게 생겼을까?

1차원 배열 = 숫자가 한 줄로 늘어선 상자

위의 작은 숫자가 인덱스(번호표). 반드시 0부터 시작! a[0]=80, a[-1]=95(맨 끝)

2차원 배열 = 행(가로)과 열(세로)로 된 표

2행 3열 → shape = (2, 3). 노란 칸은 m[1, 2] = 88 (1번 행, 2번 열)

배열 정보 보기

속성뜻(2,3) 배열일 때
m.shape모양(행, 열)(2, 3)
m.ndim차원 수2
m.size전체 원소 개수6
m.dtype원소 자료형int64 (환경에 따라 int32)

3. axis(계산 방향) 그림으로 이해하기

axis는 없애고 계산할 축입니다. 2차원 표에서 axis=0은 행 방향으로 더해 열별 결과를 만들고, axis=1은 열 방향으로 더해 행별 결과를 만듭니다. 화살표는 더하는 방향을 나타냅니다.

axis=0 ↓ (열끼리)
1+4=5, 2+5=7, 3+6=9 → [5 7 9]
axis=1 → (행끼리)
1+2+3=6, 4+5+6=15 → [6 15]
m = np.array([[1,2,3],[4,5,6]])
print(m.sum(axis=0))
print(m.sum(axis=1))
[5 7 9]
[ 6 15]
💡 학생(행)별 평균 → axis=1, 과목(열)별 평균 → axis=0. axis는 “남길 방향”이 아니라 “계산으로 줄이는 방향”입니다.

4. 슬라이싱: 표에서 원하는 부분 오려내기

a[시작:끝] 에서 끝 번호는 포함하지 않습니다. 2차원은 m[행범위, 열범위] 입니다.

m[1:, 1:] → 1행부터 끝, 1열부터 끝
m[:, 0] → 모든 행의 0번 열
a = np.array([80, 90, 75, 85, 95])
print(a[1:4])        # 1,2,3번
print(a[a >= 85])    # 조건에 맞는 값만 (불리언 마스크)
[90 75 85]
[90 85 95]

5. 브로드캐스팅: 작은 배열이 자동으로 늘어난다

두 배열의 모양을 오른쪽 끝부터 비교합니다. 각 차원의 크기가 같거나, 둘 중 하나가 1이면 계산할 수 있습니다. 크기가 맞지 않으면 오류가 납니다. 아래에서는 길이 3인 배열이 각 행에 적용됩니다(실제로 배열을 복제해 저장하는 것은 아닙니다).

+
→ 각 행에 똑같이 복사됨
= 
scores = np.array([[80,90,70],[85,95,88]])
bonus = np.array([0, 5, 10])   # 과목별 가산점
print(scores + bonus)
[[ 80  95  80]
 [ 85 100  98]]
