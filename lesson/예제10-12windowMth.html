예제 10-12: Window 객체 및 window.open() 분석 보고서

본 문서는 브라우저의 최상위 전역 객체인 `window` 객체의 구조와, 브라우저 창의 크기 측정, 그리고 새 창을 생성하는 window.open() 메서드의 상세 매개변수 및 윈도우 조작 방법을 설명합니다.

1. Window 객체 및 window.open() 매개변수 상세 이해

`window.open(URL, windowName, windowFeatures)` 메서드는 새로운 브라우저 탭이나 팝업 창을 열 때 사용하며, 총 3개의 매개변수를 가집니다.

💡 window.open() 구문 구조: window.open(url, name, specs)

1) window.open() 매개변수 상세 설명

매개변수명 타입 설명 및 주요 값
1. URL String 새 창에서 로드할 웹 페이지의 주소(URL). 빈 문자열("")을 전달하면 비어 있는 팝업 창(about:blank)이 열립니다.
2. windowName (또는 target) String 새 창의 이름 또는 타겟 속성.
- "_blank": 새 탭 또는 새 창에서 열기 (기본값)
- "_self": 현재 창에서 열기
- 사용자 정의 이름(예: "myWindow"): 지정한 이름을 가진 창이 이미 존재하면 그 창을 재사용하고, 없으면 새로 만듦.
3. windowFeatures (옵션) String 새 창의 크기, 위치, UI 표시 여부 등을 쉼표(,)로 구분하여 지정하는 문자열 (※ 값 사이에 공백을 포함하면 안 됨)
- width=값, height=값 (창의 너비와 높이, 픽셀 단위)
- left=값, top=값 (창이 생성될 모니터 화면상의 X, Y 좌표)
- resizable=yes/no (창 크기 조절 허용 여부)
- scrollbars=yes/no (스크롤바 표시 여부)

	var myWindow;

3. 주요 윈도우 제어 메서드 상세 분석

메서드명 사용 예시 동작 설명 및 특징
window.open() window.open("", "myWindow", "width=250,height=100") 새 창을 열며 URL, 타겟 창 이름, 크기 및 속성 옵션을 매개변수로 받아 생성된 창 객체를 반환합니다.
moveTo() myWindow.moveTo(600, 600) 생성된 자식 창의 화면 상 절대 좌표(X, Y)를 지정한 위치로 이동시킵니다.
resizeTo() myWindow.resizeTo(600, 600) 생성된 자식 창의 가로, 세로 크기를 지정한 픽셀 단위로 강제 조절합니다.
close() myWindow.close() 해당 윈도우 인스턴스 창을 닫습니다. (스크립트로 생성한 창에 주로 유효함)

핵심 정리

    window.open(url, name, specs): 새 창을 생성하는 3가지 매개변수(주소, 창 이름, 속성 설정) 활용 창 인스턴스 제어: 반환된 변수(myWindow)를 통해 moveTo, resizeTo, close 등 후속 조작 수행 브라우저 보안 제약: 사용자의 명시적인 상호작용(버튼 클릭 등) 없이 스크립트 단독으로 메인 창을 임의 조작하는 것은 보안상 제한됨

학습 포인트: `window.open()`의 매개변수 구조를 정확히 이해하고, 팝업 창의 크기, 이름, 속성을 동적으로 제어하는 기법을 익힙니다.
