VS Code, 설치부터 GitHub 연동까지

프로그래밍을 처음 접하는 분도 따라 할 수 있도록 순서대로 정리했습니다. 위에서부터 차례로 따라 하면 HTML, Python, C 코드를 실행하고 GitHub에 올릴 수 있습니다. 설명은 Windows 기준이며, Mac은 별도로 표시했습니다.

1. VS Code란?

Visual Studio Code(줄여서 VS Code)는 Microsoft에서 만든 무료 코드 편집기입니다. 가볍고 빠르며, 확장 프로그램(Extension)을 설치하면 HTML, Python, C 등 거의 모든 언어를 하나의 프로그램에서 작성하고 실행할 수 있습니다.

용어뜻
편집기(Editor)코드를 쓰는 창. 메모장에 색상 표시와 자동 완성 기능이 더해진 것
확장 프로그램VS Code에 기능을 추가하는 플러그인
터미널명령어를 입력해 컴퓨터를 조작하는 창
Git코드의 변경 이력을 기록하는 도구
GitHubGit으로 기록한 코드를 인터넷에 저장하고 공유하는 서비스

2. 설치하기

  1. 다운로드 브라우저에서 code.visualstudio.com에 접속하고 Download 버튼을 누릅니다. 운영체제(Windows, Mac, Linux)는 자동으로 선택됩니다.
  2. 설치 파일 실행 내려받은 VSCodeUserSetup-x64-버전.exe를 실행하고 사용권 계약에 동의합니다.
  3. 추가 작업 선택 아래 두 항목을 꼭 체크하세요.
    • "PATH에 추가": 터미널에서 code . 명령을 쓰기 위해 필요합니다.
    • "Code로 열기" 작업을 탐색기 폴더 컨텍스트 메뉴에 추가: 폴더에서 오른쪽 클릭 한 번으로 VS Code를 열 수 있습니다.
  4. 설치 완료 "설치" → "마침"을 누르면 VS Code가 실행됩니다.
Mac 사용자내려받은 zip 파일을 풀고 Visual Studio Code.app을 응용 프로그램(Applications) 폴더로 옮기세요. 터미널 명령을 쓰려면 VS Code에서 Cmd+Shift+P → Shell Command: Install 'code' command in PATH를 실행합니다.

4. 화면 설정 (한글·테마·글꼴)

4-1. 한국어 메뉴로 바꾸기

  1. Ctrl+Shift+X로 확장 화면을 엽니다.
  2. 검색창에 Korean Language Pack을 입력하고 Install을 누릅니다.
  3. 오른쪽 아래에 나오는 Restart 버튼으로 다시 시작하면 메뉴가 한글로 바뀝니다.

4-2. 테마(색상) 바꾸기

Ctrl+K 다음 Ctrl+T를 누르면 테마 목록이 나옵니다. 방향키로 이동하면 미리 볼 수 있고, Enter로 확정합니다. 밝은 강의실에서는 "Light Modern", 일반 작업에는 "Dark Modern"이 읽기 편합니다.

4-3. 글꼴 크기 조절

  • 코드 글자 확대·축소: Ctrl+마우스 휠 (먼저 설정에서 Mouse Wheel Zoom을 켜야 합니다)
  • 화면 전체 확대·축소: Ctrl+= / Ctrl+-

4-4. 꼭 켜 둘 설정

Ctrl+,로 설정 화면을 열고 검색창에 아래 이름을 입력해 바꿉니다.

5. 폴더와 파일 다루기

VS Code는 파일 하나가 아니라 폴더 단위로 작업합니다. 처음 시작할 때 이 순서를 습관으로 만드세요.

  1. 바탕화면이나 문서 폴더에 작업용 폴더를 만듭니다. 이름은 영문·숫자로 합니다. (예: myweb) 한글이나 공백이 있으면 C 컴파일이나 Git에서 오류가 날 수 있습니다.
  2. VS Code에서 파일 → 폴더 열기 (Ctrl+K 다음 Ctrl+O)로 그 폴더를 엽니다.
  3. "이 폴더의 작성자를 신뢰합니까?"라는 창이 나오면 본인이 만든 폴더이므로 예, 신뢰합니다를 선택합니다.
  4. 탐색기 위쪽의 새 파일 아이콘을 눌러 index.html처럼 확장자까지 입력합니다.
확장자를 꼭 쓰세요파일 이름 끝의 .html, .css, .js, .py, .c가 있어야 VS Code가 언어를 알아보고 색상과 자동 완성을 제공합니다.

6. HTML · CSS · JavaScript

웹 페이지는 세 가지 파일이 역할을 나눕니다. HTML은 뼈대, CSS는 모양, JavaScript는 동작입니다.

6-1. 파일 만들기

폴더에 index.html, style.css, script.js 세 파일을 만듭니다.

6-2. HTML 뼈대 자동 입력 (Emmet)

index.html에서 ! 한 글자를 입력하고 Tab을 누르면 기본 구조가 한 번에 완성됩니다.

index.html
<!DOCTYPE html>
<html lang="ko">
<head>
  <meta charset="UTF-8">
  <title>나의 첫 페이지</title>
  <link rel="stylesheet" href="style.css">
</head>
<body>
  <h1 id="title">안녕하세요!</h1>
  <button id="btn">클릭</button>
  <script src="script.js"></script>
</body>
</html>
style.css
body { font-family: sans-serif; text-align: center; }
h1   { color: royalblue; }
button { padding: 8px 20px; font-size: 16px; }
script.js
const btn = document.getElementById("btn");
const title = document.getElementById("title");

btn.addEventListener("click", function () {
  title.textContent = "버튼을 눌렀어요!";
});

6-3. Live Server로 실행하기

  1. 확장 화면에서 Live Server(제작자 Ritwick Dey)를 설치합니다.
  2. index.html을 연 상태에서 편집기 안을 오른쪽 클릭 → Open with Live Server를 선택합니다.
  3. 브라우저가 http://127.0.0.1:5500 주소로 열립니다. 이후 코드를 저장(Ctrl+S)하면 화면이 자동으로 바뀝니다.
  4. 종료하려면 상태 표시줄 오른쪽 아래의 Port: 5500을 누릅니다.
자주 쓰는 Emmetdiv.box + Tab → <div class="box"></div>, ul>li*3 + Tab → 목록 항목 3개가 한 번에 생성됩니다.
개발자 도구브라우저에서 F12를 누르면 오류 메시지(Console)와 요소 구조(Elements)를 볼 수 있습니다. 동작하지 않을 때 가장 먼저 확인하세요.

7. Python

7-1. Python 설치

  1. python.org → Downloads에서 최신 버전을 내려받습니다.
  2. 설치 첫 화면 아래의 "Add python.exe to PATH"를 반드시 체크한 뒤 Install Now를 누릅니다.
  3. 설치 후 VS Code 터미널(Ctrl+`)에서 확인합니다.
터미널
python --version

버전 번호(예: Python 3.13.x)가 나오면 성공입니다. Mac에서는 python3 --version을 사용합니다.

7-2. VS Code 설정

  1. 확장 화면에서 Python(Microsoft)을 설치합니다.
  2. Ctrl+Shift+P → Python: Select Interpreter → 설치한 Python 버전을 선택합니다.

7-3. 코드 작성과 실행

hello.py
name = input("이름을 입력하세요: ")
print("안녕하세요,", name)

for i in range(1, 4):
    print(i, "번째 반복")
  • 방법 1: 편집기 오른쪽 위의 ▶ (Run Python File) 버튼
  • 방법 2: 터미널에 python hello.py 입력
들여쓰기가 문법입니다Python은 줄 앞의 공백(보통 4칸)으로 코드 블록을 구분합니다. for나 if 다음 줄은 반드시 들여쓰기하세요.

8. C언어

C는 Python과 달리 코드를 기계어로 바꾸는 컴파일러가 따로 필요합니다. 흐름은 작성 → 컴파일 → 실행 세 단계입니다.

8-1. 컴파일러(gcc) 설치 - Windows

  1. msys2.org에서 설치 파일을 내려받아 설치합니다. (기본 경로 C:\msys64 유지)
  2. 설치 끝에 열리는 MSYS2 창에 아래 명령을 입력하고 질문에는 Enter를 누릅니다.
MSYS2 터미널
pacman -S --needed base-devel mingw-w64-ucrt-x86_64-toolchain
  1. 환경 변수 PATH 추가: 윈도우 검색에서 "시스템 환경 변수 편집" → 환경 변수 → 사용자 변수 Path → 편집 → 새로 만들기 → C:\msys64\ucrt64\bin 입력 → 모두 확인.
  2. VS Code를 완전히 종료했다가 다시 실행하고 터미널에서 확인합니다.
터미널
gcc --version
Mac 사용자터미널에서 xcode-select --install을 실행하면 컴파일러(clang)가 설치됩니다. 이후 아래 명령에서 gcc를 그대로 사용할 수 있습니다.

8-2. 코드 작성, 컴파일, 실행

VS Code에서 C/C++ 확장(Microsoft)을 설치한 뒤 hello.c를 만듭니다.

hello.c
#include <stdio.h>

int main(void) {
    int age;
    printf("나이를 입력하세요: ");
    scanf("%d", &age);
    printf("내년에는 %d살입니다.\n", age + 1);
    return 0;
}
터미널
gcc hello.c -o hello
./hello

PowerShell에서는 .\hello로 실행합니다. -o hello는 만들어질 실행 파일 이름을 정하는 옵션입니다. 코드를 고칠 때마다 컴파일을 다시 해야 반영됩니다.

한글이 깨질 때터미널에서 chcp 65001을 입력해 UTF-8로 바꾸세요. 파일 경로에 한글이 있으면 컴파일이 실패할 수 있으니 영문 폴더를 사용합니다.

10. Git과 GitHub 연동

Git은 내 컴퓨터에서 변경 이력을 기록하고, GitHub는 그 기록을 인터넷에 저장합니다. 관계는 작업 폴더 → (add) → (commit) → 내 컴퓨터 저장소 → (push) → GitHub 순서입니다.

10-1. 준비하기

  1. GitHub 가입 github.com에서 계정을 만들고 이메일 인증을 합니다.
  2. Git 설치 git-scm.com에서 내려받아 설치합니다. 옵션은 모두 기본값으로 Next를 눌러도 됩니다.
  3. 설치 확인 및 사용자 등록 처음 한 번만 합니다. 이름과 이메일은 GitHub 계정과 같게 입력합니다.
터미널
git --version
git config --global user.name "홍길동"
git config --global user.email "me@example.com"
git config --global init.defaultBranch main

10-2. GitHub에 저장소(Repository) 만들기

  1. GitHub 오른쪽 위 + → New repository를 누릅니다.
  2. Repository name에 영문 이름(예: myweb)을 입력하고 Public을 선택합니다.
  3. README 등 체크 항목은 선택하지 않은 채로 Create repository를 누릅니다. 이후 나오는 주소(https://github.com/아이디/myweb.git)를 복사해 둡니다.

10-3. 명령어로 올리기

터미널
git init                         # 이 폴더를 Git 저장소로 만들기 (처음 1회)
git add .                        # 모든 변경 파일을 올릴 목록에 담기
git commit -m "첫 번째 커밋"       # 변경 이력으로 기록하기
git remote add origin https://github.com/아이디/myweb.git
git push -u origin main          # GitHub로 올리기 (처음 1회)

push할 때 로그인 창이 뜨면 Sign in with your browser를 선택하고, 브라우저에서 승인하면 완료됩니다.

그 다음부터는 코드를 고칠 때마다 아래 세 줄만 반복합니다.

터미널
git add .
git commit -m "무엇을 바꿨는지 짧게"
git push

10-4. 마우스로 올리기 (소스 제어 화면)

  1. Ctrl+Shift+G로 소스 제어 화면을 엽니다. 바뀐 파일 목록이 나타납니다.
  2. 파일 옆의 +(스테이징)를 눌러 올릴 파일을 선택합니다. 전체는 "변경 사항" 옆의 +를 누릅니다.
  3. 위쪽 메시지 칸에 변경 내용을 쓰고 ✓ 커밋을 누릅니다.
  4. 나타나는 변경 내용 동기화(또는 Publish Branch) 버튼을 누르면 GitHub에 올라갑니다.

파일 이름 옆의 글자는 상태를 뜻합니다. U는 새 파일, M은 수정됨, D는 삭제됨입니다.

10-5. 가져오기와 되돌리기

터미널
git clone https://github.com/아이디/myweb.git   # GitHub 저장소를 내 컴퓨터로 복사
git pull                                        # GitHub의 최신 내용 받아오기
git status                                      # 현재 변경 상태 보기
git log --oneline                               # 커밋 기록 보기
git restore 파일명                               # 저장 안 한 수정 취소

10-6. GitHub Pages로 웹 페이지 공개하기

  1. 저장소 첫 화면의 index.html이 있는 상태에서 Settings → Pages를 엽니다.
  2. Source를 Deploy from a branch, Branch를 main / (root)로 선택하고 Save를 누릅니다.
  3. 1~2분 뒤 https://아이디.github.io/저장소이름/ 주소로 접속할 수 있습니다.
.gitignore 알아 두기비밀번호, API 키가 든 파일은 올리면 안 됩니다. 올리지 않을 파일 이름을 .gitignore 파일에 한 줄씩 적으면 Git이 무시합니다. 이미 올린 키는 삭제해도 기록에 남으므로 반드시 키를 새로 발급받아야 합니다.

12. 문제 해결 (FAQ)

"python"이나 "gcc"를 인식할 수 없다고 나와요

PATH 등록이 안 된 경우입니다. 설치 시 PATH 체크 여부를 확인하고, 환경 변수를 수정했다면 VS Code를 완전히 종료한 뒤 다시 실행해야 적용됩니다.

PowerShell에서 "스크립트를 실행할 수 없습니다" 오류가 나요

터미널 종류를 Command Prompt 또는 Git Bash로 바꾸세요. 패널 오른쪽 위의 화살표에서 선택할 수 있습니다.

Live Server를 눌러도 브라우저가 열리지 않아요

폴더가 아니라 파일만 열었을 때 자주 생깁니다. 폴더 열기로 작업 폴더를 연 뒤 다시 시도하세요.

git push에서 권한 오류(403, Authentication failed)가 나요

저장된 이전 계정 정보가 원인일 수 있습니다. 윈도우 검색에서 자격 증명 관리자 → Windows 자격 증명에서 git:https://github.com 항목을 삭제하고 다시 push하면 새 로그인 창이 열립니다.

한글이 깨져 보여요

상태 표시줄 오른쪽의 인코딩(예: UTF-8)을 눌러 인코딩하여 열기 → UTF-8을 선택합니다. 새 파일은 UTF-8로 저장하는 것을 기본으로 하세요.

설정을 처음 상태로 되돌리고 싶어요

Ctrl+, 설정 화면에서 바꾼 항목의 톱니바퀴 → 설정 초기화를 누릅니다.
