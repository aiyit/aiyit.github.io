1. C 프로그램의 구조

C언어는 명령문을 순서대로 실행하는 절차 지향 프로그래밍 언어입니다. 일반적인 프로그램은 main() 함수에서 실행을 시작합니다.

#include <stdio.h>
int main(void) {
    printf("Hello, C!\\n");
    return 0;
}
  • #include: 헤더 파일 포함 지시문
  • stdio.h: 표준 입출력 함수 선언
  • printf(): 화면 출력 함수
  • return 0: 정상 종료를 나타내는 반환값
프로그램 번역 과정: 전처리 → 컴파일 → 어셈블 → 링크 → 실행

2. 변수와 기본 자료형

변수는 데이터를 저장하는 메모리 공간에 붙인 이름이며, 자료형은 저장할 데이터의 종류를 지정합니다.

자료형용도printf 형식 지정자
char문자 또는 작은 정수%c
int정수%d
float단정밀도 실수%f
double배정밀도 실수%f
unsigned int음수가 없는 정수%u
int age = 20;
double average = 87.5;
char grade = 'A';
printf("%d %.1f %c", age, average, grade);

자료형의 실제 크기는 환경에 따라 다를 수 있으며 sizeof(int)처럼 확인합니다.

3. 형 변환과 연산자

정수끼리 나눗셈하면 소수점 이하가 버려집니다. 실수 결과가 필요하면 명시적 형 변환을 사용합니다.

int a = 7, b = 2;
printf("%d\\n", a / b);          // 3
printf("%.1f\\n", (double)a / b); // 3.5
종류연산자기능
산술+ - * / %사칙연산과 나머지
관계< > <= >= == !=비교 결과 1 또는 0
논리&& || !논리 AND, OR, NOT
대입= += -= *=값 대입
증감++ --1 증가 또는 감소
비트& | ^ ~ << >>비트 단위 연산
전위와 후위: ++x는 먼저 증가한 뒤 사용하고, x++는 현재 값을 사용한 뒤 증가합니다.

5. 배열과 문자열

배열은 같은 자료형의 값을 연속된 메모리에 저장합니다. 인덱스는 0부터 시작합니다.

int score[3] = {80, 90, 100};
printf("%d", score[0]); // 80

char word[4] = "CAT"; // C A T \\0

C 문자열은 마지막에 널 문자 '\\0'가 포함된 문자 배열입니다.

함수기능
strlen()문자열 길이(널 문자 제외)
strcpy()문자열 복사
strcat()문자열 연결
strcmp()문자열 비교

위 함수들은 string.h 헤더를 사용합니다.

6. 포인터

포인터는 다른 변수의 메모리 주소를 저장하는 변수입니다. &는 주소를 구하고 *는 포인터가 가리키는 값을 참조합니다.

int value = 10;
int *ptr = &value;
*ptr = 50;
printf("%d", value); // 50
배열 이름은 대부분 첫 번째 원소의 주소로 변환됩니다. arr[i]와 *(arr + i)는 같은 원소를 가리킵니다.

초기화되지 않은 포인터나 유효하지 않은 주소를 역참조하면 정의되지 않은 동작이 발생할 수 있습니다.

7. 함수와 재귀 함수

함수는 특정 작업을 수행하는 코드의 묶음입니다. C언어의 일반적인 인수 전달 방식은 값에 의한 호출입니다.

int add(int x, int y) {
    return x + y;
}

int factorial(int n) {
    if (n <= 1) return 1; // 종료 조건
    return n * factorial(n - 1);
}

호출한 쪽의 변수를 함수에서 변경하려면 해당 변수의 주소를 포인터 매개변수로 전달할 수 있습니다.
