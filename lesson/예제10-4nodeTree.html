예제 10-4: 노드 트리(Node Tree) 탐색 분석 문서

본 문서는 DOM 트리 구조에서 특정 노드를 기준으로 부모, 자식, 그리고 형제(Sibling) 요소를 상대적으로 찾아가는 노드 탐색 프로퍼티의 원리와 활용법을 설명합니다.

1. DOM 노드 트리 탐색 개념 상세 이해

HTML 문서가 브라우저에 의해 파싱되면 계층적인 트리 구조가 완성됩니다. 개발자는 getElementById처럼 직접 ID를 지정해 요소를 찾을 수도 있지만, 특정 요소의 상대적인 위치(바로 다음 요소, 이전 요소, 첫째 자식 등)를 기반으로 노드를 탐색해야 할 때가 많습니다.

💡 핵심 포인트 (Node vs Element): DOM에는 공백이나 줄바꿈을 텍스트 노드로 취급하는 속성(예: nextSibling, firstChild)과, 순수하게 HTML 태그(요소)만을 대상으로 하는 속성(예: nextElementSibling, firstElementChild)이 있습니다. 실무에서는 주로 태그 단위로 제어하기 때문에 후자(`Element`가 붙은 속성)를 주로 사용합니다.

1) 주요 탐색 프로퍼티의 종류

  • nextElementSibling: 현재 요소의 바로 다음 형제 요소를 반환합니다. (없으면 null)
  • previousElementSibling: 현재 요소의 바로 이전 형제 요소를 반환합니다. (없으면 null)
  • firstElementChild: 부모 요소의 첫 번째 자식 요소를 반환합니다.
  • lastElementChild: 부모 요소의 마지막 자식 요소를 반환합니다.

2. 제공된 HTML 원본 코드

<!DOCTYPE html>
<html>
<head>
<link rel="stylesheet" href="style.css">   
<meta charset="utf-8">
<title>예제 10-4 노드 트리(Node Tree)</title>
<script>
    function next() {
        let elem = document.getElementById("one").nextElementSibling;
        document.getElementById("next").innerHTML = elem ? elem.innerHTML : "없음";
    }

    function previous() {
        let elem = document.getElementById("two").previousElementSibling;
        document.getElementById("prev").innerHTML = elem ? elem.innerHTML : "없음";
    }

    function child() {
        let list = document.getElementById("myList");
        document.getElementById("firstC").innerHTML = list.firstElementChild.innerHTML;
        document.getElementById("lastC").innerHTML = list.lastElementChild.innerHTML;
    }
</script>
</head>
<body id="main">
    <h3 style="text-align:center;">노드의 구조(Tree)</h3>
    <h4>Node Tree</h4>
    <ul id="myList">
        <li id="one">사과</li>
        <li id="two">바나나</li>
    </ul>

    <p>사과의 nextSibling은 <b id="next"></b>입니다.</p>
    <p>바나나의 previousSibling은 <b id="prev"></b>입니다.</p>
    <p>리스트의 First Child는 <b id="firstC"></b>입니다.</p>
    <p>리스트의 Last Child는 <b id="lastC"></b>입니다.</p>

    <input type="button" id="bt1" value="nextSibling" onclick="next();">
    <input type="button" id="bt2" value="previousSibling" onclick="previous();">
    <input type="button" id="bt3" value="Tree" onclick="child();">
</body>
</html>

3. 노드 트리 탐색 프로퍼티 상세 분석

프로퍼티명 사용 예시 동작 설명 및 특징
nextElementSibling document.getElementById("one").nextElementSibling 기준 요소의 바로 다음에 위치한 형제 태그(요소)를 선택합니다. <li id="one">사과</li>의 다음 요소인 <li>바나나</li>를 가리킵니다.
previousElementSibling document.getElementById("two").previousElementSibling 기준 요소의 바로 이전 형제 태그(요소)를 선택합니다. <li id="two">바나나</li>의 이전 요소인 <li>사과</li>를 가리킵니다.
firstElementChild list.firstElementChild 부모 요소 내부의 첫 번째 자식 요소를 반환합니다. <ul id="myList">의 첫 자식인 "사과"를 선택합니다.
lastElementChild list.lastElementChild 부모 요소 내부의 마지막 자식 요소를 반환합니다. <ul id="myList">의 마지막 자식인 "바나나"를 선택합니다.

핵심 정리

  • 형제 탐색: nextElementSibling(다음), previousElementSibling(이전)으로 인접 요소 이동
  • 자식 탐색: firstElementChild(첫째), lastElementChild(막내)로 부모 안의 자식 요소 접근
  • 안전성: 탐색 결과 대상이 없을 경우 null을 반환하므로 삼항 연산자(elem ? ... : "없음") 등을 활용해 예외 처리를 해주는 것이 안전함

학습 포인트: ID나 클래스 없이도 DOM 트리의 상대적 위치 관계를 이용해 원하는 요소를 정확하게 찾아내는 탐색 기법을 익힙니다.
