주요 AI 서비스 한눈에 보기

대화형 AI부터 자료 조사, 문서 기반 학습, 이미지 제작, 여러 단계를 대신 수행하는 AI 에이전트까지 살펴봅니다. 기능은 요금제와 계정, 지역에 따라 달라질 수 있으므로 목적에 맞게 선택하세요.

ChatGPT

OpenAI
  • 글쓰기, 요약, 코딩, 이미지 생성까지 폭넓게 쓰는 범용 서비스
  • 사용자가 가장 많아 참고 자료와 활용 사례가 풍부함
사이트 열기맞춤 설정

Gemini

Google
  • Gmail, 문서, 드라이브, 유튜브 등 구글 서비스와 연결해 쓰기 좋음
  • 구글 계정만 있으면 바로 시작할 수 있음
사이트 열기맞춤 설정

Claude

Anthropic
  • 긴 글 작성, 문서 분석, 코딩 작업에서 자주 활용됨
  • 프로젝트 기능으로 자료와 지침을 묶어 관리할 수 있음
사이트 열기맞춤 설정

Grok

xAI
  • X(옛 트위터)와 연결되어 최근 화제와 실시간 정보를 다루기 좋음
  • 이미지와 영상 생성 기능을 함께 제공함
사이트 열기맞춤 설정

Manus

Manus · AI 에이전트
  • 목표를 입력하면 작업을 단계별로 계획하고 웹 조사, 보고서·슬라이드·웹사이트 제작 등을 진행하는 에이전트형 서비스
  • 단순 답변보다 여러 단계가 필요한 결과물 제작과 업무 자동화에 적합함
  • 실행 모드에 따라 크레딧이 소모될 수 있고, 결과와 외부 작업은 사용자가 검토해야 함
사이트 열기모드 설명

Perplexity

Perplexity · 검색·조사형 AI
  • 웹에서 관련 자료를 찾아 요약하고, 답변에 출처 링크를 함께 제시하는 데 초점을 둠
  • 최신 정보 조사, 제품 비교, 보고서의 참고자료 탐색에 유용함
  • 출처가 있다고 해서 내용이 모두 정확한 것은 아니므로 원문과 날짜를 확인해야 함
사이트 열기

NotebookLM

Google · 자료 기반 학습 도구
  • 사용자가 제공한 문서와 자료를 중심으로 질문에 답하고 핵심 내용을 정리함
  • 강의자료, PDF, 연구자료를 바탕으로 요약·질의응답·학습용 콘텐츠를 만들 때 유용함
  • 자료에 없는 정보까지 일반적으로 정확하게 안다고 가정하지 말고 인용된 근거를 확인함
사이트 열기

Microsoft Copilot

Microsoft · 업무 생산성 AI
  • 질문 답변, 글 작성, 요약과 아이디어 정리 등 일반 업무를 지원함
  • Microsoft 365 앱과 연결된 기능은 해당 계정과 라이선스에 따라 제공 범위가 다름
  • 회사·학교 계정의 데이터 보호 정책과 연결 권한을 확인한 뒤 사용함
사이트 열기

DeepSeek

DeepSeek · 대화·추론·코딩
  • 질문 답변, 논리적 문제 풀이, 코드 작성과 설명 등에 활용할 수 있음
  • 개념 학습이나 코드 초안 작성에 쓰되, 실행 결과와 오류 여부를 직접 확인함
  • 민감한 개인정보나 비공개 자료를 입력하기 전 서비스의 개인정보 처리 조건을 확인함
사이트 열기

Canva AI

Canva · 시각 콘텐츠 제작
  • 프레젠테이션, 포스터, 카드뉴스, SNS 콘텐츠 등 시각 자료 제작을 지원함
  • 템플릿과 편집 도구를 활용해 비전문가도 디자인 초안을 빠르게 만들 수 있음
  • 생성 이미지·글꼴·템플릿의 이용 조건과 저작권을 확인하고 최종 편집함

서비스를 고르는 기준

  • 목적: 글, 이미지, 영상 중 무엇을 주로 만들 것인지 먼저 정합니다.
  • 비용: 무료 범위로 충분한지, 유료가 필요한지 확인합니다. 자세한 내용은 계정 가입과 요금제 확인에서 볼 수 있습니다.
  • 한국어 품질: 같은 질문을 여러 서비스에 던져 보고 답변을 비교합니다.
  • 개인정보: 입력한 내용이 학습에 쓰이는지 설정을 확인하고, 민감한 정보는 입력하지 않습니다.
알아 두기. 일반 대화형 AI는 주로 질문에 답하고 초안을 만드는 데 강점이 있습니다. Manus와 같은 AI 에이전트는 여러 단계를 계획하고 도구를 사용해 결과물을 완성하는 작업에 초점을 둡니다. 자동 실행이 편리한 만큼 중요한 변경이나 외부 전송은 승인·검토 절차를 두세요. 각 서비스의 기능, 무료 한도, 개인정보 정책은 수시로 바뀌므로 공식 사이트에서 최신 내용을 확인하세요.
