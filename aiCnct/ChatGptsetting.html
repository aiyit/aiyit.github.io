🤖 ChatGPT 메뉴·설정 가이드

일반 사용자가 ChatGPT를 편리하고 안전하게 사용하기 위한 핵심 설정 안내

📌 먼저 알아두세요
ChatGPT의 메뉴와 설정 항목은 요금제, 지역, 운영체제, 앱 버전 및 계정 유형에 따라 다르게 표시될 수 있습니다. 따라서 아래 경로가 본인의 화면과 조금 다르더라도 정상입니다.
STEP 1

⚙️ 설정 메뉴 열기

1
ChatGPT에 로그인합니다.
2
화면의 프로필 아이콘 / 계정 메뉴를 선택합니다.
3
설정(Settings)을 선택합니다.

프로필 메뉴 → 설정

⭐ 일반 사용자가 먼저 확인할 6가지

개인화

🧠 Personalization

ChatGPT가 사용자의 선호와 대화 맥락을 반영하도록 설정하는 영역입니다.

설정 → Personalization(개인화)

  • Memory(메모리): 관련 정보를 기억하고 개인화에 활용
  • Custom Instructions: 답변 방식과 사용자 정보를 직접 지정

추천: 자주 사용하는 사용자라면 자신의 답변 선호를 설정해 두면 편리합니다.

개인정보·학습

🔐 Data Controls

대화 데이터와 모델 개선 사용 여부, 데이터 내보내기 등의 관리 영역입니다.

설정 → Data Controls(데이터 제어)

  • Improve the model for everyone: 개인용 계정에서 새 대화를 모델 개선에 사용할지 선택
  • 데이터 내보내기
  • 계정 삭제 등

주의: 모델 개선을 끄더라도 대화가 반드시 채팅 기록에서 사라지는 것은 아닙니다.

화면

🎨 Appearance

ChatGPT 화면의 밝기와 시각적 표시를 조절합니다.

설정 → General(일반) → Appearance

  • System: 기기 설정에 맞춤
  • Light: 밝은 화면
  • Dark: 어두운 화면
  • 웹/Windows에서는 Contrast(대비) 옵션도 제공될 수 있음
답변 스타일

✍️ Custom Instructions

ChatGPT에게 어떤 방식으로 답변해 달라는 지침을 지속적으로 제공할 수 있습니다.

웹/데스크톱: 설정 → Personalization → Custom Instructions

예: “한국어로 답변하고, 핵심 내용을 표로 정리해 주세요.”

일회성 대화

🕶️ Temporary Chat

개인화와 일반 채팅 기록의 영향을 줄이고 싶은 일회성 대화에 활용할 수 있습니다.

  • 일반적인 채팅 기록과 다른 방식으로 처리
  • 메모리를 만들거나 업데이트하지 않음
  • 민감한 작업에는 필요한 정보만 입력하는 것이 안전
개인정보 확인

🛡️ Privacy Center

개인정보와 데이터 관련 기능을 한 곳에서 이해하고 관련 설정으로 이동할 수 있는 안내 영역입니다.

설정 자체를 자동으로 변경하는 기능은 아니므로, 필요한 항목을 직접 확인해야 합니다.

📋 설정별 핵심 기능 한눈에 보기

🎯 추천 기본 설정

  1. Personalization에서 자신에게 필요한 개인화 기능을 확인합니다.
  2. Custom Instructions에서 원하는 답변 언어와 형식을 지정합니다.
  3. Memory를 사용할 경우 어떤 정보가 개인화에 활용되는지 주기적으로 확인합니다.
  4. Data Controls에서 모델 개선 관련 설정을 자신의 개인정보 보호 기준에 맞게 선택합니다.
  5. 민감하거나 일회성인 내용은 필요에 따라 Temporary Chat을 고려합니다.
  6. 화면이 불편하면 Appearance에서 Light / Dark / System을 변경합니다.

💡 Custom Instructions 예시

아래처럼 자신의 사용 목적에 맞는 지침을 입력할 수 있습니다.

저는 한국어 사용자를 위한 답변을 선호합니다.
어려운 전문용어는 쉬운 말로 먼저 설명해 주세요.
복잡한 내용은 단계별로 정리하고 필요한 경우 표를 사용해 주세요.
사실과 추론을 구분하고, 확실하지 않은 내용은 모른다고 표시해 주세요.

⚠️ 개인정보를 다룰 때의 기본 원칙

  • 비밀번호, 인증번호, 신용카드 번호 등 불필요한 민감정보는 입력하지 않습니다.
  • 업무·연구자료를 업로드하기 전 개인정보와 기밀정보를 확인합니다.
  • Memory를 사용할 경우 개인화에 필요하지 않은 정보는 저장하지 않는 것이 좋습니다.
  • 연결된 앱이나 외부 서비스는 어떤 데이터를 사용할 수 있는지 확인한 뒤 연결합니다.
