전기 기초자를 위한
PLC와 컨베이어 시스템

이 문서는 PLC로 움직이는 컨베이어 분류 설비를 쉽게 설명한다. 설비는 제품을 컨베이어로 운반하고, 센서와 비전 검사로 불량품을 판정한 뒤, 실린더로 불량품을 배출한다.

1. 전체 그림

컨베이어 시스템은 단순히 벨트를 돌리는 장치가 아니다. 전원·센서·PLC·모터·공압 실린더·안전장치가 서로 신호를 주고받으며 제품을 운반하고 분류한다.

버튼 / 센서→PLC 입력 X→PLC 프로그램→PLC 출력 Y→모터 / 솔레노이드 / 램프→설비 동작

예를 들어 제품이 포토센서 앞에 오면 센서가 PLC에 “제품 도착” 신호를 보낸다. PLC는 컨베이어를 잠시 멈추고 비전 검사 결과를 확인한 후, 불량이면 실린더로 제품을 옆으로 밀어 낸다.

2. 설비를 이루는 주요 부품

MCCB

배전반의 전원 차단기이다. 과전류나 단락이 생기면 전원을 차단해 설비와 사람을 보호한다. MCCB가 OFF이면 PLC, 출력, 타워램프가 모두 꺼진다.

24V DC SMPS

교류 전원을 제어용 24V 직류 전원으로 바꾸는 장치이다. PLC 입력·출력 회로와 센서 등에 전원을 공급한다.

PLC

Programmable Logic Controller의 약자이다. 버튼, 센서, 안전스위치 신호를 읽고 프로그램대로 모터·밸브·램프를 제어하는 설비용 제어 컴퓨터이다.

릴레이 K1

PLC의 작은 출력 신호로 큰 전류가 흐르는 모터 회로를 켜고 끄는 전기적 스위치이다. PLC는 직접 큰 모터 전류를 다루기보다 릴레이를 통해 모터를 제어한다.

포토센서

제품이 특정 위치에 도착했는지 감지한다. 이 설비에서는 센서가 감지되면 컨베이어가 멈추고 비전 검사가 진행된다.

비전 검사 장치

카메라로 제품 외관을 검사한다. 불량(NG)이면 PLC에 신호를 보내고, PLC는 불량품 배출 동작을 수행한다.

모터

컨베이어 벨트를 구동한다. PLC 출력 Y0가 릴레이 K1을 통해 모터 회로를 제어한다.

솔레노이드 밸브와 실린더

솔레노이드 밸브는 공기 흐름을 제어하고, 공압 실린더는 그 공기로 로드를 밀어낸다. 이 로드가 불량품을 옆의 불량품 통으로 밀어 낸다.

타워램프

녹색은 가동, 황색은 센서 감지·검사 중, 적색은 정지 또는 알람을 뜻한다. 적색이 점멸하면 비상정지 또는 안전가드 개방 상태이다.

안전가드

작업자가 회전하는 모터, 구동 롤러, 벨트 끝단 등 위험 부위에 접근하지 못하게 막는 보호 장치이다. 도어가 열리면 설비가 즉시 정지한다.

3. PLC란 무엇인가

PLC는 공장 설비를 자동으로 제어하는 장치이다. 일반 컴퓨터와 비슷하게 프로그램을 실행하지만, 진동·먼지·전기적 노이즈가 있는 공장 환경에서 센서와 모터를 안정적으로 제어하도록 만들어졌다.

PLC의 반복 동작

이 시뮬레이션의 PLC는 약 20ms마다 다음 세 단계를 반복한다.

1. 입력 읽기  : 버튼·센서·스위치 상태를 X 입력으로 읽음
2. 래더 실행  : 프로그램 논리에 따라 내부 상태와 출력을 계산
3. 출력 쓰기  : 계산 결과를 Y 출력으로 보내 장치를 동작시킴

즉, PLC는 입력을 보고 → 판단하고 → 출력을 내는 장치이다. 이 주기가 매우 빠르게 반복되기 때문에 사람이 보기에는 센서 감지와 모터 정지가 거의 동시에 일어난 것처럼 보이다.

4. PLC의 X, Y, M 이해하기

PLC 프로그램에서 가장 먼저 익혀야 할 것은 입력 X, 출력 Y, 내부 메모리 M이다. 이 설비에서는 라인마다 16점씩 입출력 주소를 사용한다. 예를 들어 LINE 1은 X0~X15, Y0~Y15를 사용하고, LINE 2는 X16~, Y16~를 사용한다.

5. 래더논리: PLC의 언어

래더논리(Ladder Logic)는 계전기 제어회로를 닮은 PLC 프로그래밍 방식이다. 왼쪽에서 오른쪽으로 전기가 흐르는 그림처럼 생각하면 이해하기 쉽다. 접점이 모두 조건을 만족하면 오른쪽의 코일이 ON된다.

래더 1: 모터 가동

┣ X0 START ──┬── /X2 E-STOP ── X4 GUARD 닫힘 ── ( Y0 MOTOR )
                     └── Y0 자기유지 ──────────────────────────┘

뜻은 다음과 같다.

  • X0 START: START 버튼을 눌렀다.
  • /X2 E-STOP: 비상정지 버튼을 누르지 않았다. 슬래시(/)는 “반대 상태”를 뜻한다.
  • X4 GUARD 닫힘: 안전가드 도어가 닫혀 있다.
  • Y0 자기유지: START를 떼어도 모터가 계속 동작하도록 기억하는 접점이다.
  • Y0 MOTOR: 모든 조건이 만족되면 모터 출력이 ON된다.

자기유지(Self-holding)는 매우 중요한 개념이다. START 버튼은 사람이 잠깐만 누르지만, Y0가 ON되면 Y0 자신의 접점이 X0를 대신해 회로를 계속 이어 준다. 그래서 START를 떼어도 컨베이어는 계속 돌아간다.

래더 2: 불량품 배출

┣ X1 PHOTO SENSOR ── X3 VISION NG ── ( Y1 SOLENOID )

제품이 센서에 도착했고(X1), 비전 검사 결과가 불량이면(X3) 솔레노이드 밸브 Y1이 작동한다. 그러면 공압 실린더가 제품을 옆으로 밀어 불량품 통으로 보낸다.

기초 용어: X1처럼 조건을 확인하는 부분을 접점, Y1처럼 동작을 명령하는 부분을 코일이라고 한다. 접점이 닫혀 전기가 흐르면 코일이 동작한다.

6. 컨베이어의 동작 순서

이 설비는 단순히 벨트만 움직이는 것이 아니라, 공급 → 이송 → 감지 → 검사 → 판정 → 분류 → 계수 순서로 동작한다.

  1. 전원 투입: MCCB를 ON한다. 그래야 PLC와 제어회로에 전원이 들어온다.
  2. 안전 조건 확인: E-STOP이 눌리지 않았고, 안전가드 도어가 닫혀 있으며, 모터 과부하 보호가 정상이어야 한다.
  3. START: START 버튼을 누르면 PLC가 라인 가동 상태가 되고, 모터와 공급 장치가 동작한다.
  4. 제품 이송: 모터가 컨베이어 벨트를 구동하고 제품이 앞으로 이동한다.
  5. 제품 감지: 제품이 포토센서에 도착하면 X1이 ON되고, 컨베이어가 잠시 멈춘다.
  6. 비전 검사: 카메라가 제품을 검사한다. 이 설비에서는 검사 시간이 지난 뒤 결과를 확인한다.
  7. 양품 통과: 검사 결과가 OK이면 잠시 대기한 뒤 컨베이어가 다시 움직이고, 제품은 출구 센서를 지나며 PASS 카운터가 증가한다.
  8. 불량 배출: 검사 결과가 NG이면 일정 시간 후 솔레노이드 밸브가 작동하고 실린더가 제품을 밀어 낸다.
  9. 불량 계수: 실린더가 원위치로 돌아오고 제품이 실제로 벨트에서 빠져나가면 DEFECT 카운터가 증가한다.

7. 왜 컨베이어가 멈추는가

제품이 센서에 도착하면 컨베이어가 멈춘다. 이유는 간단한다. 제품이 움직이는 상태에서 카메라 검사를 하면 사진이 흐려지거나, 실린더가 제품을 정확히 밀어내지 못할 수 있기 때문이다.

이 시뮬레이션에서는 센서와 실린더가 같은 위치에 맞춰져 있다. 제품이 센서 빔을 지나는 순간 벨트가 멈추고, 실린더가 그 위치의 제품을 밀어낸다.

핵심 원리: PLC는 단순히 “불량이면 밀어라”가 아니라, 제품이 올바른 위치에 멈춰 있는지 → 검사가 끝났는지 → 실린더가 원위치인지까지 순서대로 확인한 뒤 동작시킨다.

8. 안전은 왜 가장 중요한가

컨베이어에는 회전하는 모터, 구동 롤러, 움직이는 벨트가 있다. 작업자가 이 부분에 손이나 옷이 말리면 심각한 부상으로 이어질 수 있다. 따라서 안전가드와 비상정지는 선택 사항이 아니라 필수이다.

안전 인터락의 원리

안전가드 도어가 열리면 X4 GUARD CLOSED가 OFF된다. 그러면 래더 1의 안전 조건이 깨져 Y0 MOTOR가 OFF되고 컨베이어는 즉시 정지한다.

도어 열림 → X4 OFF → 안전조건 불충족 → Y0 OFF → 모터 정지

또한 도어를 다시 닫다고 설비가 자동으로 다시 시작되지 않다. 반드시 작업자가 START 버튼을 눌러야 재가동된다. 이를 자동 재기동 방지라고 한다.

비상정지 E-STOP

E-STOP은 위험 상황에서 사람이 즉시 설비를 멈추기 위해 사용한다. 이 설비에서는 E-STOP이 눌리면 X2가 ON되고, 모터 출력이 차단된다. E-STOP은 누른 상태를 유지하는 래치 방식이며, 해제한 뒤에도 START를 눌러야 재가동된다.

모터 과부하 보호

모터에 과부하가 걸리면 열동계전기가 트립된다. 이때 X8 MOTOR OVERLOAD OK가 OFF되어 라인이 정지하고 알람이 기록된다. 원인을 확인하고 해제한 뒤 START로 복귀해야 한다.

10. 실제 조작 순서

정상 가동

  1. MCCB를 ON한다.
  2. E-STOP이 해제되어 있는지 확인한다.
  3. 안전가드 도어를 닫다.
  4. START를 누른다.
  5. 녹색 램프가 들어오고 컨베이어가 움직이는지 확인한다.

정상 정지

  1. STOP 버튼을 누른다.
  2. 컨베이어가 멈추고 적색 램프가 들어오는지 확인한다.

비상정지 후 복귀

  1. 위험을 제거한다.
  2. E-STOP을 해제한다.
  3. 안전가드 도어가 닫혀 있는지 확인한다.
  4. START를 눌러 재가동한다.

불량품 통이 가득 찬 경우

불량품 통이 가득 차면 레벨 스위치 X9가 동작한다. PLC는 현재 진행 중인 배출 동작이 끝난 뒤 라인을 멈춘다. 통을 비운 뒤 START를 눌러야 다시 가동된다.

11. 자주 하는 오해

“센서가 불량을 판정한다?”

아니다. 포토센서는 제품의 존재나 위치만 감지한다. 외관 불량 여부는 비전 검사 장치가 판정하고 그 결과가 X3로 PLC에 들어온다.

“PLC가 모터에 직접 전원을 준다?”

이 설비에서는 PLC 출력 Y0가 릴레이 K1을 동작시키고, K1이 모터 회로를 개폐한다.

“도어를 닫으면 자동으로 다시 돌아간다?”

아니다. 도어를 닫아도 자동 재기동되지 않으며, 반드시 START를 눌러야 한다.

“E-STOP을 풀면 바로 재가동된다?”

아니다. E-STOP 해제만으로는 재가동되지 않고, 안전조건 확인 후 START를 눌러야 한다.

13. 학습 정리

  • PLC는 센서와 버튼 신호를 받아 프로그램대로 모터·밸브·램프를 제어한다.
  • X는 입력, Y는 출력, M은 내부 상태이다.
  • START 자기유지는 버튼을 떼어도 설비가 계속 동작하게 하는 핵심 논리이다.
  • 포토센서는 제품 위치를 감지하고, 비전 장치는 불량 여부를 판정한다.
  • 솔레노이드 밸브와 실린더는 불량품을 배출한다.
  • 안전가드, E-STOP, 과부하 보호는 설비보다 사람의 안전을 우선한다.
  • 도어 개방이나 E-STOP 후에는 반드시 수동 START가 필요한다.
이 문서는 PLC 컨베이어 분류 설비를 처음 배우는 분을 위한 쉬운 설명 자료이다.
