Claude 메뉴 설정 방법과 예제

claude.ai 웹과 앱에서 자주 쓰는 설정(개인 맞춤, 기능 켜고 끄기, 메모리)을 어디서 어떻게 바꾸는지 예제와 함께 정리했습니다.

메뉴 이름과 위치는 앱 버전, 웹/모바일, 요금제에 따라 조금씩 다를 수 있습니다. 화면과 다르면 공식 도움말(문서 맨 아래 링크)을 함께 확인하세요.

1설정 화면 열기

  1. claude.ai 또는 Claude 앱에 로그인합니다.
  2. 화면 왼쪽 아래의 프로필 아이콘(계정 이름)을 누릅니다.
  3. 메뉴에서 Settings(설정)를 선택합니다.
설정 안에는 프로필·선호도, 기능(Capabilities), 개인정보, 외관, 언어 등의 항목이 있습니다. 아래 2~4장에서 자주 쓰는 항목을 다룹니다.

2개인 맞춤: 선호도, 스타일, 프로젝트

Claude를 내 방식에 맞추는 방법은 세 가지이며, 적용 범위가 다릅니다.

방법적용 범위용도
프로필 선호도내 모든 대화역할, 말투, 항상 지킬 규칙
스타일선택한 대화답변의 어조와 형식(간결함, 설명형 등)
프로젝트 지침해당 프로젝트 안의 대화특정 업무에 맞춘 지침과 자료

프로필 선호도 설정

  1. Settings → Profile(프로필)로 이동합니다.
  2. "Claude가 답변에서 고려해야 할 선호도" 입력란에 원하는 내용을 적습니다.
  3. 저장하면 이후 모든 대화에 적용됩니다.

입력 예시:

답변은 항상 한국어로 작성해 주세요.
설명은 핵심부터 짧게 쓰고, 필요할 때만 예제를 덧붙여 주세요.
코드는 설명 없이 바로 실행할 수 있는 형태로 먼저 보여 주세요.

스타일 사용

  1. 대화 입력창 아래의 스타일(Use style) 드롭다운을 엽니다.
  2. 미리 만들어진 스타일 중 하나를 고르거나, Create & edit styles에서 직접 만듭니다.
  3. 대화 중에도 언제든 다른 스타일로 바꿀 수 있습니다. Normal과 Concise는 목록에서 숨길 수 없습니다.
선호도는 "나는 누구이고 무엇을 원한다"를, 스타일은 "어떤 말투와 형식으로 답할지"를 정하는 용도로 나눠 쓰면 편합니다.

3기능 켜고 끄기

Settings → Capabilities(기능)에서 아래 기능을 조절할 수 있습니다.

기능하는 일
웹 검색최신 정보를 인터넷에서 찾아 답변에 반영합니다. 대화 중에도 켜고 끌 수 있습니다.
코드 실행 및 파일 생성코드를 실행하고 문서·스프레드시트 같은 파일을 만들어 내려받게 해 줍니다.
이전 대화 검색지난 대화를 참고해 연속성 있게 답합니다.
채팅 기록에서 메모리 생성대화에서 얻은 선호와 맥락을 저장해 이후 대화에 활용합니다.
개인정보가 걱정되는 작업을 할 때는 이전 대화 검색과 메모리 생성을 끄거나, 시크릿(Incognito) 대화를 사용하세요.

4메모리 관리

저장된 메모리 보기와 수정

  1. Settings → Capabilities로 이동합니다.
  2. 메모리 항목에서 View and edit memory를 누릅니다.
  3. 저장된 내용을 확인하고 필요 없는 항목을 지우거나 새 내용을 추가합니다.

일시 중지와 초기화

  • 일시 중지(Pause): 기존 메모리는 유지하되 새 메모리를 만들거나 사용하지 않습니다.
  • 삭제: 개별 항목을 지우거나 전체를 초기화해 처음부터 시작할 수 있습니다.

다른 AI에서 가져오기 / 내보내기

  1. 이전에 쓰던 AI에게 "저장된 내 선호와 정보를 모두 출력해 줘"라고 요청해 텍스트를 복사합니다.
  2. Settings → Capabilities → Memory → Start import를 누릅니다.
  3. 텍스트를 붙여넣고 Add to memory를 누르면 Claude가 핵심 정보만 골라 저장합니다.
  4. 내보내기는 같은 화면에서 메모리를 열어 텍스트를 복사하면 됩니다.

대화창에서 바로 요청하는 예시:

저장된 내 메모리를 있는 그대로 모두 보여 줘.
메모리는 약 하루 단위로 갱신되므로, 방금 한 말이 바로 반영되지 않을 수 있습니다. 프로젝트와 시크릿 대화는 메모리가 따로 취급되는 경우가 있습니다.

5그 밖의 설정

공식 도움말의 "개인 설정" 모음에는 아래 항목이 있습니다. 필요할 때 해당 문서를 찾아보세요.

  • 외관(테마) 설정 변경
  • 선호하는 언어로 Claude 사용하기
  • 모델, 노력(effort), 사고(thinking) 설정 변경
  • 휴식 알림과 방해 금지 시간 설정
