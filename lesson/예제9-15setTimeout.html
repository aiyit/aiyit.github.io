예제 9-15: setTimeout()으로 현재 시간 갱신 분석 보고서

본 문서는 JavaScript의 Date 객체와 setTimeout() 타이머 함수를 활용하여 웹 페이지에 현재 시각(시:분:초:밀리초)을 실시간으로 갱신하여 출력하는 예제 코드를 분석한 내용입니다.

1. HTML 전체 소스코드

<!DOCTYPE html>
<html>
<head>
    <meta charset="utf-8">
    <title>예제 9-15 현재 시간 표시</title>
</head>
<body>
    <h3>setTimeout()으로 현재 시간 갱신</h3>
    <p>현재 시간: <b id="ca"></b></p>

    <script>
        function setTime() {
            var time = new Date();

            var nowTime = 
                time.getHours().toString().padStart(2, '0') + ":" +
                time.getMinutes().toString().padStart(2, '0') + ":" +
                time.getSeconds().toString().padStart(2, '0') + ":" +
                time.getMilliseconds().toString().padStart(3, '0');

            document.getElementById("ca").innerText = nowTime;

            setTimeout(setTime, 10);
        }

        setTime();
    </script>
</body>
</html>

2. HTML 구조 및 DOM 요소 설명

  • <h3> 및 <p> 태그: 타이틀과 함께 "현재 시간:" 라벨을 표시합니다.
  • <b id="ca"> 태그: JavaScript 스크립트가 계산한 시·분·초·밀리초 문자열을 innerText를 통해 실시간으로 갱신하여 보여주는 핵심 출력 영역입니다.

3. JavaScript 핵심 로직 상세 분석

코드 요소 주요 역할 및 동작 원리
new Date() 컴퓨터의 현재 시스템 날짜 및 시간 정보를 담은 객체를 생성합니다.
padStart(2, '0')
padStart(3, '0')		 숫자 문자열의 자릿수가 부족할 경우 지정된 길이(시간/분/초는 2자리, 밀리초는 3자리)가 되도록 빈 자리를 '0'으로 채워주는 메서드입니다. (예: 5초 ➔ "05")
setTimeout(setTime, 10) 지정한 시간(10밀리초 = 0.01초) 후에 setTime 함수를 다시 호출합니다. 이를 통해 함수가 스스로를 반복 호출(재귀 호출)하면서 실시간 시계 기능을 구현합니다.
