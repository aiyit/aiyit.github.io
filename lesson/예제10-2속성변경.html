예제 10-2: DOM 요소 속성 변경(Attribute Change) 분석 문서

본 문서는 JavaScript를 활용하여 HTML 요소의 속성(Attribute)과 스타일(Style)을 동적으로 변경하는 원리와, src 프로퍼티 제어, style 객체 제어, 그리고 setAttribute() 메서드의 활용법을 상세히 설명합니다.

1. HTML 속성 변경 및 동적 제어 개념

웹 페이지가 로드된 이후, 사용자의 상호작용(버튼 클릭 등)에 따라 화면의 이미지를 바꾸거나 디자인(CSS 스타일)을 실시간으로 수정해야 할 때 DOM 요소의 속성 제어 기능이 사용됩니다.

💡 핵심 포인트: DOM 트리에 반영된 객체의 프로퍼티나 메서드를 호출하면 브라우저는 즉시 화면을 다시 그림(Rendering / Repaint), 사용자가 변경된 결과를 실시간으로 확인할 수 있게 됩니다.

1) 주요 제어 방식의 차이점

  • 프로퍼티 직접 접근 (예: element.src): 객체의 속성 값을 직접 읽거나 대입하여 변경합니다. 직관적이고 간편합니다.
  • 인라인 스타일 제어 (예: element.style.color): 요소의 CSS 스타일 속성을 직접 조작합니다. CSS 속성명이 카멜케이스(CamelCase, 예: backgroundColor)로 변환되어 적용됩니다.
  • setAttribute(name, value) 메서드: 속성 이름과 값을 직접 지정하여 새로운 속성을 부여하거나 기존 속성값을 강제로 교체합니다.

2. 제공된 HTML 원본 코드

<!DOCTYPE html>
<html>
<head>
<link rel="stylesheet" href="style.css"> 
<meta charset="utf-8">
<title>예제10-2속성변경(attribute change)</title>
<script>
  function changeImg(){
    document.getElementById("img").src = 'images/aisoftware.png';
  }

  function changeCss(){
    document.getElementById("cls").style.color = "red";
  }

  function changeSeta(){
    document.getElementById('set').setAttribute("style", "background-color:cyan");
  }
</script>
</head>
<body id="main">
  <h1 style="text-align:center;">속성 변경(Find Element)</h1>

  <p>이미지 변경: 
    <img id="img" src="images/ai.png" width="100px" height="100px">
  </p>

  <h2 id="cls" style="color:blue">CSS 속성(색상) 변경</h2>
  <h2 id="set" style="color:green">CSS setAttribute(attribute,value)</h2>

  <input type="button" id="bt1" value="change_img" onclick="changeImg();">
  <input type="button" id="bt2" value="change_style" onclick="changeCss();">
  <input type="button" class="bt3" value="change_setAttribute" onclick="changeSeta();">
</body>
</html>

3. 속성 제어 메서드 및 프로퍼티 상세 분석

구분 / 메서드 사용 예시 동작 설명 및 특징
src 프로퍼티 변경 document.getElementById("img").src = '...'; 이미지 태그(<img>)의 경로 속성을 직접 수정하여 웹 페이지에 로드되는 이미지소스를 동적으로 교체합니다.
style 객체 제어 document.getElementById("cls").style.color = "red"; 요소의 인라인 스타일(Inline Style) 속성에 접근하여 특정 스타일 값(글자 색상, 크기 등)을 실시간으로 변경합니다.
setAttribute() document.getElementById('set').setAttribute("style", "..."); HTML 태그의 특정 속성(Attribute) 이름과 바꿀 값을 매개변수로 받아 강제로 설정합니다. 기존 스타일 속성 전체를 덮어씌울 때 유용합니다.

핵심 정리

  • 이미지 경로 변경: element.src = '경로'를 이용해 화면에 표시될 리소스를 즉시 전환
  • 스타일 속성 조작: element.style.CSS속성명 = '값'을 통해 개별 스타일 동적 변경
  • 범용 속성 설정: element.setAttribute(속성명, 값)으로 HTML 표준/사용자 정의 속성 부여 및 수정

학습 포인트: DOM 요소를 가져오는 것에 그치지 않고, 가져온 요소의 속성과 스타일을 스크립트로 조작하여 인터랙티브한 웹 화면을 만드는 기법을 익힙니다.
