JavaScript 설명문 및 주요 개념 정리

1. 자바스크립트 키워드 및 연산자 종류

  • 주요 키워드(Reserved Words): var, let, const, function, if, else, for, while, return 등
  • 산술 연산자: + (더하기), - (빼기), * (곱하기), / (나누기), % (나머지), ** (거듭제곱)
  • 대입 연산자: =, +=, -=, *=, /=
  • 비교 연산자: ==, ===, !=, !==, >, <

2. 연산 실행 결과

자바스크립트 연산자 
        종류산술 연산자:
        사칙연산 및 수학적 계산 (+, -, *, /, %, **)
        할당(대입) 연산자: 변수에 값을 할당 (=, +=, -=, *=, /=, %=)
        증감 연산자: 값을 1 증가 또는 감소 (++, --)
        비교 연산자: 값의 크기나 동등성 비교 (==, ===, !=, !==, >, <, >=, <=)
        논리 연산자: 참/거짓 논리 연산 (&&, ||, !, ??)
        삼항(조건) 연산자: 조건에 따른 값 선택 (조건 ? 참일때 : 거짓일때)
        비트 연산자: 비트 단위 연산 (&, |, ^, ~, <<, >>)
        타입/객체 연산자: 데이터 타입 및 객체 확인 (typeof, instanceof, delete, in)
            
        연산자 우선순위 (높은 순 → 낮은 순)연산자 우선순위가 높을수록 먼저 계산됩니다.
