2. 변수와 자료형

변수(Variable)는 값을 저장하고 다시 사용하기 위한 이름입니다. 파이썬은 대입된 값을 보고 자료형을 자동으로 판단합니다.

자료형의미예시
int정수10, -3
float실수3.14, 0.5
str문자열"Python", "안녕"
bool참 또는 거짓True, False
list순서가 있고 변경 가능[10, 20, 30]
tuple순서가 있고 변경 불가(10, 20, 30)
dict키와 값의 쌍{"name": "민수"}
set중복을 허용하지 않는 모음{1, 2, 3}
name = "홍길동"
age = 20
height = 172.5
is_student = True

print(type(name))       # str
print(type(age))        # int
print(type(height))     # float
print(type(is_student)) # bool
type(값)은 자료형을 확인합니다. int("25")처럼 형 변환도 할 수 있습니다.

3. 연산자

종류연산자의미
산술+, -, *, /, //, %, **더하기, 빼기, 곱하기, 나누기, 몫, 나머지, 거듭제곱
비교==, !=, >, <, >=, <=비교 결과는 True 또는 False
논리and, or, not논리곱, 논리합, 부정
대입=, +=, -=, *=값 저장 또는 기존 값 갱신
포함in, not in자료 안에 값이 있는지 확인
a = 17
b = 5
print(a / b)    # 3.4 : 나눈 결과
print(a // b)   # 3   : 몫
print(a % b)    # 2   : 나머지
print(2 ** 3)   # 8   : 거듭제곱
시험 핵심: //는 몫, %는 나머지입니다. 17을 5로 나누면 몫은 3, 나머지는 2입니다.

4. 조건문과 반복문

4-1. 조건문 if

조건이 참인지 거짓인지 판단하여 실행할 내용을 선택합니다.

score = 75

if score >= 60:
    print("합격")
else:
    print("불합격")

4-2. 반복문 for와 while

for리스트나 정해진 범위의 값을 하나씩 꺼내 반복합니다.
while조건이 참인 동안 반복합니다. 종료 조건을 확인해야 합니다.
# 1부터 5까지 출력
for number in range(1, 6):
    print(number)

# while 반복
count = 1
while count <= 5:
    print(count)
    count += 1

range(1, 6)은 1부터 6 미만까지입니다. 따라서 1, 2, 3, 4, 5가 만들어집니다.

명령기능
break반복문을 즉시 종료
continue현재 반복을 건너뛰고 다음 반복으로 이동
pass아무 동작 없이 문법상 자리를 채움

5. 문자열·리스트·튜플

5-1. 문자열(String)

문자열은 문자가 순서대로 연결된 자료입니다. 인덱스는 0부터 시작합니다.

text = "PYTHON"
print(text[0])     # P
print(text[2])     # T
print(text[-1])    # N
print(text[1:4])   # YTH

5-2. 리스트(List)

리스트는 여러 값을 순서대로 저장하며 항목을 추가·수정·삭제할 수 있습니다.

scores = [80, 90, 75]
scores.append(100)   # 끝에 추가
scores[0] = 85       # 첫 번째 값 수정
scores.remove(90)    # 값 90 삭제
print(scores)
print(len(scores))   # 항목 개수
print(sum(scores))   # 합계
메서드기능
append(x)끝에 x 추가
insert(i, x)i 위치에 x 삽입
remove(x)값 x 삭제
pop()마지막 항목을 꺼내고 삭제
sort()오름차순 정렬
reverse()순서 뒤집기

5-3. 튜플(Tuple)

튜플은 순서가 있지만 생성 후 항목을 변경할 수 없습니다.

point = (10, 20)
print(point[0])
# point[0] = 30  # 오류: 튜플 항목은 변경 불가

6. 세트(Set)와 딕셔너리(Dictionary)

6-1. 세트(Set)

세트는 중복된 값을 하나만 남기는 자료형입니다. 항목의 순서를 기준으로 사용하지 않습니다.

numbers = {1, 2, 2, 3, 3, 3}
print(numbers)      # {1, 2, 3}와 같은 집합
print(2 in numbers) # True

6-2. 딕셔너리(Dictionary)

딕셔너리는 키(Key)와 값(Value)을 한 쌍으로 저장합니다.

student = {"name": "홍길동", "score": 95}
print(student["name"])
print(student["score"])
student["grade"] = "A"   # 새 항목 추가
print(student.keys())    # 키 목록
print(student.values())  # 값 목록

7. 함수(Function)

함수는 자주 사용하는 코드를 하나의 이름으로 묶은 것입니다. 입력값을 받을 수 있고 return으로 결과를 돌려줄 수 있습니다.

def add(a, b):
    result = a + b
    return result

total = add(3, 5)
print(total)  # 8
용어설명
매개변수(Parameter)함수를 정의할 때 입력받도록 만든 변수
인수(Argument)함수를 호출할 때 실제 전달하는 값
return실행 결과를 호출한 곳으로 돌려줌
지역 변수함수 내부에서 만들어져 주로 함수 안에서 사용
전역 변수함수 바깥에서 정의된 변수
lambda간단한 함수를 한 줄 식으로 표현
def greet(name, message="안녕하세요"):
    print(name, message)

greet("민수")
greet("영희", "반갑습니다")

square = lambda x: x * x
print(square(4))  # 16

8. 클래스와 객체지향 프로그래밍

클래스(Class)는 객체를 만들기 위한 설계도이고, 객체(Object)는 클래스를 바탕으로 실제 생성한 대상입니다. 객체는 데이터인 속성과 기능인 메서드를 가질 수 있습니다.

class Student:
    def __init__(self, name, score):
        self.name = name
        self.score = score

    def introduce(self):
        print(self.name, "학생의 점수는", self.score)

student1 = Student("민수", 90)
student2 = Student("영희", 95)

student1.introduce()
student2.introduce()
self는 현재 객체 자신을 가리킵니다. __init__()은 객체가 생성될 때 속성을 초기화하는 메서드입니다.
객체지향 특징설명
캡슐화(Encapsulation)데이터와 기능을 하나로 묶고 접근을 관리
상속(Inheritance)기존 클래스의 속성과 기능을 물려받음
다형성(Polymorphism)같은 기능 이름이 객체에 따라 다르게 동작
추상화(Abstraction)복잡한 내부 구현은 감추고 핵심 기능을 표현

9. 파일 입출력

파일 입출력(File Input/Output)은 프로그램의 데이터를 파일에 저장하거나 파일에서 읽어오는 기능입니다.

모드의미
r읽기. 파일이 없으면 오류
w쓰기. 기존 내용이 있으면 덮어씀
a추가. 기존 내용 뒤에 이어 씀
x새 파일 생성. 같은 이름이 있으면 오류
b바이너리 모드(예: rb, wb)
t텍스트 모드(기본값)

실습 9-1. 텍스트 파일 저장과 읽기

# 파일에 쓰기
with open("memo.txt", "w", encoding="utf-8") as file:
    file.write("파이썬 파일 입출력 실습입니다.\\n")
    file.write("데이터를 저장합니다.")

# 파일 읽기
with open("memo.txt", "r", encoding="utf-8") as file:
    content = file.read()

print(content)
with open()을 사용하면 작업이 끝난 뒤 파일이 자동으로 닫힙니다. 한글 파일은 encoding="utf-8"을 지정하면 인코딩 문제를 줄일 수 있습니다.

실습 9-2. CSV 파일

import csv

students = [
    ["이름", "점수"],
    ["민수", 90],
    ["영희", 95],
    ["철수", 82]
]

with open("scores.csv", "w", newline="", encoding="utf-8-sig") as file:
    writer = csv.writer(file)
    writer.writerows(students)

with open("scores.csv", "r", encoding="utf-8-sig") as file:
    reader = csv.reader(file)
    for row in reader:
        print(row)

10. 예외 처리

예외(Exception)는 프로그램 실행 중 발생하는 오류 상황입니다. try와 except를 이용하면 오류가 발생했을 때 대응할 수 있습니다.

try:
    number = int(input("숫자를 입력하세요: "))
    result = 100 / number
except ValueError:
    print("정수로 입력해야 합니다.")
except ZeroDivisionError:
    print("0으로 나눌 수 없습니다.")
else:
    print("계산 결과:", result)
finally:
    print("프로그램을 종료합니다.")
구문역할
try오류 가능성이 있는 코드 실행
except발생한 예외 처리
else예외가 발생하지 않았을 때 실행
finally예외 여부와 관계없이 실행
raise예외를 직접 발생

12. 자료구조와 알고리즘

자료구조(Data Structure)는 데이터를 효율적으로 저장하고 관리하는 방법입니다. 알고리즘은 그 데이터를 이용해 문제를 해결하는 절차입니다.

자료구조특징비유
배열(Array)인덱스로 데이터에 접근하는 구조번호가 붙은 사물함
스택(Stack)후입선출(LIFO): 나중에 넣은 것이 먼저 나옴접시 쌓기
큐(Queue)선입선출(FIFO): 먼저 넣은 것이 먼저 나옴줄 서기
리스트(List)순서에 따라 데이터를 관리할 일 목록
딕셔너리(Dictionary)키로 값을 찾음전화번호부

스택 구현

stack = []
stack.append("첫 번째")
stack.append("두 번째")
stack.append("세 번째")

print(stack.pop())  # 세 번째
print(stack.pop())  # 두 번째

큐 구현

from collections import deque

queue = deque()
queue.append("첫 번째")
queue.append("두 번째")
queue.append("세 번째")

print(queue.popleft())  # 첫 번째
print(queue.popleft())  # 두 번째

탐색과 정렬

  • 순차 탐색(Linear Search): 처음부터 차례대로 비교합니다.
  • 이진 탐색(Binary Search): 정렬된 데이터의 가운데 값과 비교해 범위를 절반씩 줄입니다.
  • 버블 정렬(Bubble Sort): 이웃한 두 값을 비교하고 필요하면 교환합니다.
numbers = [12, 7, 25, 9, 18]
target = 25

for index, value in enumerate(numbers):
    if value == target:
        print("찾은 위치:", index)
        break

13. 종합 실습: 학생 성적 관리

학생 이름과 점수를 저장하고 평균, 최고 점수, 합격 여부를 출력합니다. 리스트, 딕셔너리, 반복문, 조건문, 함수를 함께 사용합니다.

students = [
    {"name": "민수", "score": 90},
    {"name": "영희", "score": 85},
    {"name": "철수", "score": 72},
    {"name": "지민", "score": 98},
    {"name": "수현", "score": 55}
]

def get_average(data):
    total = sum(student["score"] for student in data)
    return total / len(data)

for student in students:
    result = "합격" if student["score"] >= 60 else "불합격"
    print(student["name"], student["score"], result)

average = get_average(students)
top_student = max(students, key=lambda x: x["score"])

print("평균:", round(average, 1))
print("최고 점수:", top_student["name"], top_student["score"])
코드 분석: students는 학생 데이터를 저장합니다. for문은 학생을 한 명씩 처리합니다. get_average()는 평균을 계산하고 max()는 최고 점수 학생을 찾습니다.

응용 과제: 학생을 2명 추가하고, 합격 기준을 70점으로 바꾸고, 평균보다 높은 학생만 출력한 뒤 결과를 CSV 파일로 저장해 보세요.
