정보 보안(Security) 핵심 정리

정보 보안의 기본 원리부터 암호화, 인증, 네트워크 공격, 보안 장비, 웹 취약점까지 초급 학습자 관점에서 정리했습니다.

1. 정보 보안의 기본 원칙

정보 보안(Information Security)은 정보와 정보 시스템을 무단 접근, 변경, 파괴, 유출 등으로부터 보호하는 활동입니다.

기밀성(Confidentiality)허가받은 사용자만 정보에 접근하도록 보호합니다. 예: 암호화, 접근 권한 설정.
무결성(Integrity)정보가 허가 없이 변경·삭제되지 않고 정확하게 유지되도록 합니다. 예: 해시값 검증, 전자서명.
가용성(Availability)필요한 때에 서비스와 정보를 이용할 수 있도록 합니다. 예: 백업, 이중화, 장애 대응.
사례침해 요소이유
개인정보 외부 유출기밀성허가되지 않은 열람
계좌 금액 무단 변경무결성데이터 변조
서버 장애로 서비스 중단가용성서비스 이용 불가
인증(Authentication)은 “누구인가?”를 확인하고, 인가(Authorization)는 “무엇을 할 수 있는가?”를 결정합니다.

2. 보안 위협과 공격 유형

공격핵심 개념
스니핑(Sniffing)네트워크를 오가는 데이터를 몰래 엿보는 행위
스푸핑(Spoofing)IP 주소나 신원 등을 속여 다른 대상으로 가장
서비스 거부(DoS)시스템 자원을 소모시켜 정상 서비스를 방해
분산 서비스 거부(DDoS)여러 시스템에서 동시에 트래픽을 보내 서비스 방해
중간자 공격(MITM)통신 당사자 사이에 끼어 데이터를 엿보거나 변조
세션 하이재킹(Session Hijacking)정상 사용자의 세션을 탈취해 사용자로 가장
재전송 공격(Replay Attack)이전에 전송된 정상 메시지를 다시 보내 부정 행위
사회공학(Social Engineering)사람을 속여 비밀번호 등 정보를 알아내는 기법
암기 기준: 스니핑은 엿보기, 스푸핑은 속이기, DoS/DDoS는 서비스 방해입니다.

3. 암호화와 전자서명

평문(Plaintext)은 암호화하기 전의 읽을 수 있는 데이터이고, 암호문(Ciphertext)은 암호화한 결과입니다.

방식설명대표 예
대칭키 암호암호화와 복호화에 같은 비밀키 사용. 빠르지만 키 전달·관리 중요.AES
공개키 암호공개키와 개인키 한 쌍 사용. 키 교환·전자서명 등에 활용.RSA, ECC
해시(Hash)입력 데이터를 고정 길이 값으로 변환. 일반적으로 원문 복원이 목적이 아님.SHA-256
  • 전자서명(Digital Signature): 서명자는 개인키로 서명하고, 검증자는 공개키로 검증합니다.
  • PKI(Public Key Infrastructure, 공개키 기반 구조): 인증서와 인증기관 등을 이용해 공개키의 신뢰성을 관리합니다.
  • 비밀번호 저장에는 일반 해시만 단독 적용하기보다 Argon2id, bcrypt, scrypt 같은 비밀번호 전용 해시와 salt를 사용합니다.
평문 비밀번호를 파일이나 데이터베이스에 저장하거나 암호화되지 않은 통신으로 전송하면 유출 위험이 큽니다.

4. 인증과 접근 통제

  • 지식 기반: 비밀번호, PIN처럼 알고 있는 정보
  • 소유 기반: 보안카드, 인증 앱, 보안 토큰처럼 가지고 있는 것
  • 생체 기반: 지문, 얼굴, 홍채처럼 신체 특징
  • 다중 요소 인증(MFA): 서로 다른 종류의 인증 요소를 둘 이상 조합
접근 통제설명
DAC(Discretionary Access Control)자원 소유자가 접근 권한을 지정
MAC(Mandatory Access Control)보안 등급과 중앙 정책에 따라 접근 결정
RBAC(Role-Based Access Control)사용자에게 역할을 부여하고 역할에 권한 연결
최소 권한 원칙: 사용자에게 업무 수행에 필요한 최소한의 권한만 부여합니다.

5. 네트워크 보안

장비·기술역할
방화벽(Firewall)보안 정책에 따라 네트워크 트래픽을 허용하거나 차단
IDS(Intrusion Detection System, 침입 탐지 시스템)침입 징후를 탐지하고 경고
IPS(Intrusion Prevention System, 침입 방지 시스템)침입을 탐지하고 차단
VPN(Virtual Private Network, 가상 사설망)공용 네트워크를 통해 보호된 사설 통신 경로 제공
WAF(Web Application Firewall, 웹 방화벽)웹 애플리케이션 요청을 분석해 웹 공격 차단

보안이 필요한 원격 접속에는 SSH(Secure Shell), 파일 전송에는 SFTP(SSH File Transfer Protocol), 웹 통신에는 HTTPS(HTTP over TLS)를 사용합니다.

6. 웹·데이터베이스 보안

취약점설명예방 방법
SQL 인젝션(SQL Injection)입력값으로 SQL 구문을 변조해 데이터베이스에 비정상 명령 실행매개변수화 쿼리(Prepared Statement), 입력 검증, 최소 권한
XSS(Cross-Site Scripting)악성 스크립트가 다른 사용자의 브라우저에서 실행되도록 삽입출력 인코딩, 입력 검증, 안전한 콘텐츠 처리
CSRF(Cross-Site Request Forgery)로그인된 사용자의 권한을 악용해 원치 않는 요청 전송CSRF 토큰, SameSite 쿠키, 요청 출처 검증
디렉터리 탐색경로 조작으로 허용 범위 밖 파일에 접근경로 정규화, 허용 목록 기반 접근
SQL 인젝션 예방의 핵심은 SQL 명령 구조와 사용자 입력값을 분리하는 매개변수화 쿼리입니다.

쿠키(Cookie)는 브라우저에 저장되는 데이터이고, 세션(Session)은 서버 측에서 사용자 상태를 관리하는 방식입니다. HttpOnly는 자바스크립트의 쿠키 접근을 제한하고, Secure는 HTTPS에서만 쿠키를 전송하도록 합니다.

7. 악성코드와 대응

종류특징
바이러스(Virus)정상 파일이나 프로그램에 기생하여 실행·복제
웜(Worm)다른 프로그램에 기생하지 않고 네트워크 등을 통해 스스로 전파
트로이 목마(Trojan Horse)정상 프로그램처럼 위장해 악성 행위 수행
랜섬웨어(Ransomware)파일을 암호화하거나 시스템을 잠그고 금전 요구
스파이웨어(Spyware)사용자 정보를 몰래 수집
키로거(Keylogger)키보드 입력을 기록해 정보 탈취
  1. 운영체제와 응용 프로그램을 최신 상태로 업데이트합니다.
  2. 백신·엔드포인트 보안 제품을 사용합니다.
  3. 출처가 불분명한 파일과 링크를 열지 않습니다.
  4. 중요 데이터는 분리된 환경에 정기적으로 백업하고 복구를 시험합니다.
  5. 감염이 의심되면 네트워크를 격리하고 증거 보존·분석·복구 절차를 수행합니다.

8. 보안 관리

  • 심층 방어(Defense in Depth): 방화벽, 인증, 암호화, 백업 등 여러 방어 계층을 구성합니다.
  • 보안 로그: 로그인, 권한 변경, 주요 데이터 접근 등을 기록하고 점검합니다.
  • 취약점 관리: 자산 파악 → 진단 → 조치 → 재점검 순서로 수행합니다.
백업 방식내용
전체 백업(Full Backup)선택한 데이터 전체를 백업
증분 백업(Incremental Backup)직전 백업 이후 변경된 데이터만 백업
차등 백업(Differential Backup)마지막 전체 백업 이후 변경된 데이터를 백업
위험(Risk)은 위협이 취약점을 이용해 손실을 일으킬 가능성과 영향으로 이해할 수 있습니다.

9. 확인 문제

문제 1. 개인정보 유출로 침해된 보안 요소는?
① 기밀성　② 무결성　③ 가용성　④ 이식성
정답: ① 기밀성 — 허가되지 않은 사람이 정보를 열람했기 때문입니다.
문제 2. 대표적인 대칭키 암호 알고리즘은?
① RSA　② AES　③ SHA-256　④ 전자서명
정답: ② AES — 같은 비밀키로 암호화와 복호화를 수행합니다.
문제 3. 침입 징후를 탐지하고 경고하는 시스템은?
① IDS　② IPS　③ VPN　④ NAT
정답: ① IDS — IPS는 탐지에 더해 차단 기능도 수행합니다.
문제 4. SQL 인젝션을 예방하는 대표적인 방법은?
① 문자열 직접 결합　② 매개변수화 쿼리　③ 관리자 권한 공유　④ 오류 상세 공개
정답: ② 매개변수화 쿼리 — SQL 구조와 입력값을 분리합니다.
문제 5. 정상 프로그램처럼 위장하는 악성코드는?
① 웜　② 트로이 목마　③ 바이러스　④ 방화벽
정답: ② 트로이 목마 — 정상 프로그램으로 위장해 악성 행위를 수행합니다.
