⚡ 접지·누전차단기 감전회로 배선 실습

전원, ELB, 부하, 접지극 단자를 클릭하여 올바른 배선을 완성하세요. 누전 발생 시 접지 경로와 ELB 동작을 확인합니다.

전원 OFF 누전 없음 접지 미연결 ELB 정상
1. 전원 L → ELB 전원측 L, N → ELB 전원측 N 연결
2. ELB 부하측 L → 부하 L, N → 부하 N 연결
3. 부하 PE → 접지극 연결로 접지계통 완성
4. 누전 발생 후 접지 유무에 따른 ELB 차단 여부 확인

배선 원칙
· 전원 L·N은 ELB 전원측에 연결합니다.
· ELB 부하측 L·N은 부하에 연결합니다.
· 보호접지(PE)는 부하 외함과 접지극에 연결합니다.
· 누전이 발생하면 접지 경로를 통해 누설전류가 흐르고, ELB는 전류 불균형을 감지해 차단합니다.

조작: 단자 클릭 2회로 배선 연결·해제 / 드래그로 시점 회전 / 휠로 확대·축소
