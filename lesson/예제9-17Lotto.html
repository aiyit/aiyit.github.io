예제 9-16: 로또(Lotto) 게임 웹 애플리케이션 분석 보고서

본 문서는 JavaScript 배열 제어 메서드와 반복문(`while`), 난수 생성(`Math.random`)을 활용하여 1부터 45 사이의 중복 없는 로또 번호 6개를 추출하고 오름차순으로 정렬하는 프로그램의 소스코드를 분석한 내용입니다.

1. HTML 전체 소스코드

<!DOCTYPE html>
<html>
<head>
    <title>예제9-16로또(Lotto) 게임</title>
    <script>
        function randomV() {
            const lottoNum = [];

            while (lottoNum.length < 6) {
                const num = Math.floor(Math.random() * 45) + 1; // 1~45
                if (!lottoNum.includes(num)) {
                    lottoNum.push(num);
                }
            }

            lottoNum.sort((a, b) => a - b); // 정렬

            document.getElementById("txt").value = lottoNum.join(", ");
        }
    </script>
</head>
<body>
    <h2 align="center">로또(Lotto) 게임(by Park GB)</h2>
    <p align="center">행운의 로또 1~45 숫자 발생기</p>
    <form>
        <input type="button" value="행운의 숫자" onclick="randomV()">
        <input type="text" size="30" id="txt" readonly>
    </form>
</body>
</html>

로또(Lotto) 게임(by Park GB)

행운의 로또 1~45 숫자 발생기

2. HTML 구조 및 DOM 요소 설명

  • <h2 align="center"> 및 <p align="center">: 페이지 중앙 정렬을 통해 게임 타이틀과 안내 문구를 깔끔하게 배치합니다.
  • <input type="text" readonly>: 생성된 6개의 로또 번호 결과가 문자열로 출력되는 입력 상자이며, 사용자가 임의로 수정할 수 없도록 읽기 전용으로 설정되어 있습니다.

3. JavaScript 핵심 로직 상세 분석

코드 요소 주요 역할 및 동작 원리
while (lottoNum.length < 6) 배열에 담긴 로또 번호의 개수가 6개가 될 때까지 반복 실행합니다.
Math.floor(Math.random() * 45) + 1 0 이상 1 미만의 난수에 45를 곱한 후 소수점을 버리고(0~44) 1을 더해 1부터 45 사이의 정수 난수를 생성합니다.
!lottoNum.includes(num) 이미 뽑힌 번호 중에 새로 생성된 번호가 포함되어 있는지 검사하여, 중복된 숫자가 들어오는 것을 방지합니다.
lottoNum.sort((a, b) => a - b) 추출된 6개의 숫자를 오름차순(작은 수에서 큰 수)으로 정렬합니다.
lottoNum.join(", ") 배열에 있는 숫자들을 쉼표와 공백(, )으로 연결하여 하나의 텍스트 문자열로 변환합니다.
