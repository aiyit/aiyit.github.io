5단계. 동영상 제작과 최종 통합

앞 단계의 자산을 편집하고, 이미지·사운드·웹툰을 하나의 완성 작품으로 연결합니다.

학습 목표

30~60초 티저 영상을 제작하고 모든 미디어가 같은 이야기와 분위기를 표현하는지 확인한 뒤 최종 작품을 제출합니다.

공통 작품: 「벚꽃 호수의 마지막 편지」 · 순서: 기획 → 이미지 → 사운드 → 웹툰 → 영상·통합

1. 30~60초 영상 구성 예시

0~8초 · 도입

호수와 벚꽃 풍경. 음악이 조용히 시작됩니다.

8~20초 · 발견

주인공이 편지를 발견합니다. 종이 효과음을 넣습니다.

20~40초 · 감정 변화

편지를 읽고 기억을 떠올립니다. 음악이 조금 풍성해집니다.

40~60초 · 마무리

꽃잎과 호수를 보여 주며 희망적인 여운으로 끝냅니다.

2. 영상 프롬프트와 편집의 역할

동영상 생성 AI: 움직임이 있는 장면을 생성합니다. 대상·행동·카메라·조명·시간 흐름을 구체적으로 지정합니다.

영상 편집기: 생성한 여러 장면을 순서대로 배열하고, 컷 길이·전환·자막·음악·효과음·음량을 조절합니다.

한 번의 생성으로 완성하려고 하기보다, 짧은 장면을 여러 개 만들고 편집기에서 연결하면 장면별로 수정하기 쉽습니다.

3. 영상 프롬프트 직접 작성

4. 편집과 통합 순서

  1. 장면 파일을 이야기 순서대로 정리합니다.
  2. 영상 편집기에 클립을 배치하고 컷 길이를 조절합니다.
  3. 이미지와 웹툰 컷을 삽입해 이야기의 핵심을 강조합니다.
  4. 배경음악을 낮은 음량으로 배치하고 장면에 맞는 효과음을 추가합니다.
  5. 필요한 경우 제목과 짧은 내레이션을 넣습니다.
  6. 시작과 끝의 음악을 자연스럽게 페이드 인·아웃합니다.
  7. 전체 길이와 화면 비율을 확인한 뒤 지원되는 형식으로 내보냅니다.

5. 최종 작품 제출 점검
