플리커·부저 경보 회로

타이머 2개로 램프 점멸과 부저 경보 회로를 구성합니다. (교육용 DC 24V 시뮬레이션)

개요

타이머 2개(T1, T2)가 서로 번갈아 동작하면서 램프를 점멸시키고, 램프가 켜질 때 부저를 울리는 경보 회로입니다.

타이머 단자

단자의미
A1, A2코일(전원) 단자
15접점 공통(COM)
16b접점 (평상시 15와 연결)
18a접점 (설정시간 후 15와 연결)

동작 원리

① +24V → T2의 b접점 → T1 코일 여자
② 3초 후 T1 a접점 ON → 램프·부저 ON, T2 코일 여자
③ 3초 후 T2 b접점이 열려 T1 소자 → 램프·부저 OFF, T2도 소자
④ ①로 돌아가 반복 = 플리커

학습 포인트

✔ 타이머 2개 ✔ a/b 접점 ✔ 경보 출력
체험 오류
● 타이머 접점 a/b 혼동
● 부저가 멈추지 않는 결선

※ 학습용 시뮬레이션입니다. 실제 전기 작업은 관련 규정과 전문가 검토가 필요합니다.

설정시간은 각 3초입니다. 접점 기호의 사선이 열린 모양이면 b접점(평상시 닫힘)으로 읽습니다.

배선 방법

1. 3D 화면에서 단자(구)를 클릭 → 연결할 다른 단자를 클릭하면 전선이 생깁니다.
2. 전선을 클릭하면 삭제됩니다. 마우스 드래그로 시점 회전, 휠로 확대합니다.
3. 배선 후 전원 ON을 누르고 약 10초간 관찰하면 결과가 판정됩니다.

필요한 연결(10개)

+24V→T2·15 / T2·16→T1·A1 / T1·A2→0V / +24V→T1·15 / T1·18→T2·A1 / T1·18→램프(+) / 램프(−)→0V / T2·A2→0V / T1·18→부저(+) / 부저(−)→0V

막히면 정답 배선으로 확인하고, 오류 체험 버튼으로 잘못된 결선의 결과를 비교하세요.

단자 클릭 → 단자 클릭 = 배선 · 전선 클릭 = 삭제
● +24V ● 0V ● 신호선(색별 구분)
회로도를 참고해 배선을 완성하고 전원 ON을 눌러 확인하세요.
