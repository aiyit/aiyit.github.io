Grok 설정 메뉴 & / 명령어 가이드

설정 메뉴 구조

프로필 → 설정 진입 시 좌측 메뉴:

  • 일반: 계정 / 외관 / 행동 유형 / 알림
  • Grok: 맞춤 설정
  • 데이터 및 정보: 데이터 컨트롤

1. 계정

로그인/로그아웃, 계정 전환, X 계정 연결.

  • 로그인 방법: X / Google / Apple / 이메일
  • X Premium+ 혜택 연동: X 계정 연결 버튼
  • 예시: 다른 계정으로 전환 → 계정 메뉴 → Switch account

2. 외관

  • 테마: 시스템 따라가기 / 라이트 / 다크
  • 언어: 시스템 / 한국어 / English 등

예시: 다크 모드 → 외관 → Dark 선택

3. 행동 유형

Grok 응답 스타일 설정.

  • 간결 / 정중 / 학구적 / 사용자 정의

예시: 사용자 정의 선택 후 역할·어조 직접 입력

4. 알림

  • 푸시 알림 on/off
  • Bot 완료·입력 필요 시 알림

예시: 모바일에서 알림 허용 후 설정에서 세부 필터

5. 맞춤 설정 (Grok)

  • 응답 스타일 세부 조정
  • 개인화 옵션

예시: Custom → “항상 한국어로, 짧고 직접적으로 답변”

6. 데이터 컨트롤

  • Improve the model: 모델 학습 사용 여부 (끄면 새 대화 학습 제외)
  • Personalize Grok using X: X 데이터로 개인화
  • 대화 기록으로 개인화: 이전 대화 기억
  • 전체 대화 삭제 / 계정 삭제 / 데이터 내보내기

예시: 학습 거부 → 데이터 컨트롤 → Improve the model 끄기

플랫폼마다 별도 설정 필요 (웹 / 앱 / X / CLI).

7. / 명령어 사용법 (Grok Build CLI)

프롬프트에 / 입력 → 메뉴 표시. 전체: /help
