예제 10-10 (개선): onFocus 및 onBlur 이벤트 활용 분석 문서

본 문서는 폼 입력창이 활성화될 때 발생하는 `onfocus`와 포커스가 벗어날 때 발생하는 `onblur`를 조합하여, 사용자에게 친절한 입력 가이드와 시각적 피드백을 제공하는 올바른 패턴을 설명합니다.

1. 개선된 onFocus / onBlur 활용 개념

앞서 살펴본 예제처럼 포커스가 들어올 때 입력값을 강제로 덮어씌우면 사용자 입력이 방해받습니다. 따라서 실무에서는 다음과 같이 활용하는 것이 적절합니다.

💡 올바른 UX 패턴:
  • onfocus: 입력창 배경색을 강조하고, 아래쪽에 입력 규칙(툴팁/안내 문구)을 띄워줍니다.
  • onblur: 입력창에서 포커스가 빠져나갈 때 안내 문구를 지우고 입력창 스타일을 원래대로 돌려놓습니다.

2. 개선된 HTML 원본 코드

<!DOCTYPE html>
<html>
<head>
<meta charset='utf-8'>
<title>예제 10-10 onFocus & onBlur</title>
<script>
    function showGuide(el) {
        document.getElementById("guide").innerHTML = "💡 영문, 숫자 조합 4~12자로 입력하세요.";
        el.style.backgroundColor = "#e8f4f8";
    }
    function hideGuide(el) {
        document.getElementById("guide").innerHTML = "";
        el.style.backgroundColor = "white";
    }
</script>
</head>
<body>
<h3>회원 가입 - 아이디 입력</h3>
<input id="txt" type="text" onFocus="showGuide(this)" onBlur="hideGuide(this)">
<p id="guide" style="color: #1769aa; font-size: 0.9rem;"></p>
</body>
</html>

3. 주요 이벤트 및 기법 상세 분석

이벤트 / 속성 사용 예시 동작 설명 및 특징
onfocus 이벤트 onFocus="showGuide(this)" 사용자가 입력 필드를 클릭하거나 탭하여 포커스를 얻을 때 발생합니다. this를 전달해 해당 요소를 직접 제어합니다.
onblur 이벤트 onBlur="hideGuide(this)" 사용자가 입력 필드 외부를 클릭하거나 다른 곳으로 포커스를 이동할 때(포커스 상실) 발생합니다.
스타일 동적 변경 el.style.backgroundColor = ... 포커스 상태에 따라 입력창의 배경색이나 테두리를 바꾸어 현재 사용자가 입력 중인 필드를 명확히 인지하게 돕습니다.

핵심 정리

    포커스 획득 (`onfocus`): 입력 가이드 제공 및 시각적 강조 효과 부여 포커스 상실 (`onblur`): 안내 메시지 정리 및 입력창 스타일 원복 사용자 경험(UX): 강제 입력 방식보다 사용자의 자유로운 타이핑을 보장하면서 피드백을 주는 형태가 올바름

학습 포인트: `onfocus`와 짝을 이루는 `onblur`의 역할을 이해하고, 폼 검증 및 가이드 제공에 알맞은 인터랙션 패턴을 익힙니다.
