함수 호출에서 시작하여 조건문과 반복문까지, 원본 수업 예제를 학생 눈높이에 맞게 다시 정리했습니다.

전체 흐름 10개 예제 통합 실습 비교표 확인문제

1. 먼저 전체 흐름을 잡아봅시다

이벤트→ 함수→ 입력·출력→ 조건 판단→ 반복

8-10~8-12에서는 사용자의 행동과 함수를 연결합니다. 8-13~8-15에서는 조건에 따라 다른 코드를 실행합니다. 8-16~8-19에서는 같은 작업을 여러 번 반복하는 방법을 배웁니다.

학생용 핵심 문장: JavaScript 프로그램은 결국 “사용자의 행동을 받아 → 값을 처리하고 → 조건에 따라 → 필요한 만큼 반복해서 → 화면에 결과를 보여주는 것”으로 이해하면 쉽습니다.

2. 예제별 이론과 실습

8-10이벤트 함수

핵심: 클릭 → 함수 실행

원본 예제는 버튼의 onclick으로 jsFunction()을 호출하고, 함수 안에서 alert()와 getElementById().innerHTML을 사용합니다.

function jsFunction() {
  alert("눌렀군요!");
  document.getElementById("first").innerHTML = "first";
}

<button onclick="jsFunction()">눌러주세요</button>

8-11함수로 계산하기

핵심: 입력값 → 읽기 → 숫자 변환 → 계산 → 출력

원본은 getElementById().value로 입력값을 읽고 parseInt()로 정수로 변환한 뒤 두 값을 더해 결과 입력창에 넣습니다.

function calc() {
  var x = document.getElementById("x").value;
  var y = document.getElementById("y").value;
  var tot = parseInt(x) + parseInt(y);
  document.getElementById("sum").value = tot;
}

함수역할결과

8-13if ~ else

핵심: 둘 중 하나를 선택

if (조건) {
  조건이 참일 때
} else {
  조건이 거짓일 때
}

원본에서는 현재 시각이 18시 이전인지 판단하는 예와, 연도를 입력받아 윤년인지 판단하는 예가 함께 사용됩니다.

8-14else if

핵심: 여러 조건 중 하나 선택

if (조건1) {
} else if (조건2) {
} else if (조건3) {
} else {
}

원본은 현재 시각에 따라 “꿈나라 / 좋은 아침 / 점심시간 / 좋은 오후 / 저녁시간 / 잘 쉬세요”처럼 여러 결과 중 하나를 표시합니다.

8-15switch ~ case

핵심: 하나의 값에 따라 선택

switch (값) {
  case "A":
    실행문;
    break;
  case "B":
    실행문;
    break;
  default:
    기본 실행문;
}

원본은 A~F 학점을 입력받아 해당 학점을 표시하고, 그 외에는 잘못된 입력으로 처리합니다.

8-16for 반복문

핵심: 횟수가 비교적 명확한 반복

for (초기식; 조건식; 증감식) {
  반복할 코드
}

원본은 x=0에서 시작하여 x<1000인 동안 x++하면서 0~999를 출력합니다.

실행 순서: 초기식 → 조건 검사 → 실행 → 증감 → 다시 조건 검사

8-17이중 for문

핵심: 반복 안에 또 반복

원본은 바깥쪽 for로 1~9단의 행을 만들고, 안쪽 for로 2~9를 곱하여 구구단 표를 만듭니다.

for (var x = 1; x <= 9; x++) {
  for (var y = 2; y <= 9; y++) {
    // x와 y를 이용한 작업
  }
}

8-18while 반복문

핵심: 조건을 먼저 검사

while (조건) {
  실행할 코드;
  조건에 영향을 주는 값 변경;
}

원본은 x=0에서 시작하여 x<100인 동안 실행하고 매 반복마다 x++합니다.

주의: 조건이 계속 참이고 변수의 값이 바뀌지 않으면 무한 반복이 발생할 수 있습니다.

8-19do ~ while 반복문

핵심: 일단 한 번 실행한 뒤 조건 검사

do {
  실행할 코드;
} while (조건);

원본은 x=20, y=45에서 시작하여 화면에 두 값을 출력하고 x++, y--를 수행한 뒤 x<y인지 검사합니다.

3. 통합 실습: 성적 처리 프로그램

목표: 입력 → 조건 판단 → 결과 출력의 흐름을 직접 만들어 봅니다.

점수를 입력하면 if / else if / else로 학점을 판정합니다.

결과가 여기에 표시됩니다.
function scorePractice() {
  const score = Number(document.getElementById("score").value);

  if (score >= 90) {
    result = "A";
  } else if (score >= 80) {
    result = "B";
  } else if (score >= 70) {
    result = "C";
  } else if (score >= 60) {
    result = "D";
  } else {
    result = "F";
  }
}

6. 학습 마무리

이 10개 예제에서 가장 중요한 것은 코드를 외우는 것이 아니라 프로그램의 흐름을 읽는 것입니다.

  1. 이벤트: 사용자가 클릭하면 함수가 실행됩니다.
  2. 입력: value, prompt() 등으로 값을 가져옵니다.
  3. 처리: 계산하거나 조건을 판단합니다.
  4. 출력: alert(), innerHTML, 입력창 등에 결과를 보여줍니다.
  5. 반복: 같은 작업을 여러 번 해야 하면 for, while, do while을 사용합니다.
