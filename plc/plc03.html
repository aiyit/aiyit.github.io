3주차 · Module 03

디지털·아날로그 I/O 및 센서 연결

전기 신호·모듈 설정·프로그램의 의미를 일치시킨다

오늘의 학습 목표

  • DI·DQ·AI·AQ의 신호 방향과 전기 특성을 구분한다.
  • PNP/NPN과 싱크·소스 입력의 관계를 개념적으로 설명한다.
  • 전송기·모듈의 신호 범위와 연결 적합성을 검토한다.
  • 원시값을 공학 단위로 환산하고 유효성을 함께 해석한다.
  • 실제 결선 없이 가상 신호로 정상·오류 결과를 확인한다.

선수학습: 1~2주차 / 준비물: 웹 브라우저·센서/모듈 공식 자료 / 내부 태그·숫자 기반 학습 / 실제 배선·활선 측정·출력 조작 제외

1

신호의 흐름 — 센서에서 프로그램, 출력까지

입력 모듈은 센서의 전기 신호를 프로그램이 읽을 수 있는 정보로 바꾸고, 출력 모듈은 프로그램의 결과를 외부 장치에 전달합니다. 센서와 모듈을 연결할 때는 이름보다 전압·전류·극성·공통 단자·범위를 먼저 확인합니다.

물리 상태→센서→입력 모듈→프로그램→출력 모듈→구동 인터페이스
연결 적합성의 기준: 신호 종류 + 전기 사양 + 기준 전위 + 모듈 설정 + 프로그램 해석
이 교안은 연결 관계를 이해하는 학습 자료이며 단자별 결선 지침이 아닙니다. 실제 배선·전원 조작·측정·출력 강제는 하지 않습니다. 실습은 내부 태그와 브라우저의 가상 숫자로 진행합니다.
2

디지털 신호 — 0과 1의 전기적 의미

디지털 신호는 두 논리 상태를 사용합니다. 그러나 실제 입력은 전압·전류의 판정 범위와 임계값을 가지며 “정확히 0V와 정확히 24V만 존재한다”는 뜻은 아닙니다.

논리·물리 구분의미
전기적 ON/OFF입력 모듈이 사양에 따라 판정한 상태
프로그램 TRUE/FALSE프로그램이 읽는 Bool 값
공정 의미제품 감지·정상·누름 등 설계자가 정의한 뜻

예를 들어 NC 접점을 쓰는 일반 신호에서는 정상 상태가 TRUE이고 조건 발생 시 FALSE일 수 있습니다. 하지만 NC 접점만으로 모든 단선·단락·위험을 검출하는 안전 기능이 되는 것은 아닙니다.

입력 전압과 임계값은 CPU·모듈별로 다릅니다. 24V DC 제품의 한 가지 예시를 AC 입력이나 다른 정격 제품에 일반화하지 않습니다.
3

센서 종류와 접점 방식

센서·조작기검출 대상·용도확인할 정보
푸시버튼작업자의 순간 조작NO/NC 접점·정격·논리 약속
리미트 스위치기계 위치 접촉 검출동작 위치·접점 방식·정격
근접 센서재질·원리에 따른 물체 접근검출 대상·거리·PNP/NPN·전원
광전 센서빛의 차단·반사 등을 이용한 물체 검출검출 방식·감도·출력 논리
온도·압력 전송기물리량을 전기 신호로 변환전류/전압·범위·전원·정확도

NO/NC 또는 Light-ON/Dark-ON은 검출 조건에 따른 출력 동작을 나타내며, PNP/NPN은 출력 회로의 전류 방향 특성과 관련된 구분입니다. 두 분류를 같은 뜻으로 사용하지 않습니다.

센서를 고를 때 “감지할 수 있는가?”와 “PLC가 전기적으로 받을 수 있는가?”를 따로 확인합니다.
4

PNP/NPN과 싱크·소스 입력의 관계

일반적인 DC 트랜지스터 센서의 ON 상태 전류 흐름을 기준으로 설명합니다. 실제 결선은 해당 센서와 입력 모듈 매뉴얼을 따릅니다.

센서 출력일반적인 전류 흐름짝을 이루는 입력
PNP, 소싱 출력센서가 입력 쪽으로 전류를 공급싱킹 입력
NPN, 싱킹 출력입력 쪽 전류를 센서가 0V 쪽으로 흘림소싱 입력
PNP: + 전원→센서 출력→DI→0V 기준
NPN: + 전원→소싱 DI→센서 출력→0V 기준

위 그림은 ON 시 전류의 개념도일 뿐 단자 번호나 전원 연결 순서를 제공하지 않습니다. 일부 모듈은 연결 방식에 따라 싱크/소스 입력을 지원하지만 모든 입력이 양쪽을 지원하지는 않습니다.

센서 선 색상이나 “M” 표시만 보고 결선하지 마세요. 단자 기능·극성·그룹 공통·절연 구조는 장치별로 확인합니다. 센서 색상 규칙은 실제 핀 배치 검증을 대신하지 못합니다.
5

디지털 출력 — 트랜지스터·릴레이와 부하

출력 방식기본 특징검토 사항
트랜지스터반도체로 스위칭, 제품별 DC 정격소스/싱크·전압·전류·부하·누설
릴레이접점으로 회로 개폐접점 정격·부하 종류·수명·동작 속도

출력의 채널별 정격뿐 아니라 그룹별 허용 전류와 외부 전원 조건도 확인합니다. 같은 전류라도 저항 부하와 코일·램프 등의 부하는 특성이 다를 수 있습니다.

접촉기·밸브 코일과 같은 유도성 부하는 스위칭 시 과도 전압을 만들 수 있으므로 부하·출력 방식에 맞는 보호와 인터페이스가 필요합니다. 임의의 소자를 추가하는 대신 제조사 지침을 확인합니다.

모터 전력을 PLC 출력에 직접 연결하지 않습니다. 출력 OFF도 장치의 전기적 격리를 보장하지 않습니다. 실제 장치 시험과 보호 설계는 자격 있는 담당자의 별도 작업입니다.
6

아날로그 신호 — 0~10V·0~20mA·4~20mA

신호주요 해석주의점
0~10V전압을 일정 물리량 범위에 대응기준 전위·입력 특성·배선·노이즈 검토
0~20mA전류를 측정 범위에 대응0mA 정상값과 일부 이상 상태 구분에 한계
4~20mA4mA를 물리량 하한, 20mA를 상한으로 사용 가능4mA 아래 상태의 해석·진단 기준은 장치별

4~20mA의 하한이 0mA가 아닌 특성은 신호 이상을 식별하는 데 활용할 수 있습니다. 그러나 0mA라는 숫자만으로 단선 원인을 확정할 수 없고, 단선 검출 지원·설정·전원·모듈 상태를 함께 봐야 합니다.

전압 입력 모듈이 전류 신호를 직접 받을 수 있다고 가정하지 않습니다. CPU의 내장 AI와 확장 AI는 지원 범위가 다를 수 있습니다.

아날로그 연결에서는 2선식/4선식 전송기의 전원 방식, 능동/수동 전류 루프의 조합, 허용 부하·전압 여유 등을 검토합니다. “전류 신호”라는 이유만으로 같은 단자에 호환되지 않습니다.

검토 항목확인 질문
센서 모델정확한 주문번호·데이터시트가 있는가?
전원정격·극성·소비 전류·공급 방식이 맞는가?
신호 종류DI/AI 및 PNP/NPN·전압/전류가 맞는가?
단자모듈의 실제 단자도·그룹 공통이 확인됐는가?
범위 설정전압/전류·측정 범위를 채널에서 올바르게 선택했는가?
배선 경로노이즈·차폐·접지·분리 기준을 따르는가?
보호회로 보호·출력 부하·서지 대책이 검토됐는가?
미사용 채널비활성화·단자 처리에 대한 제조사 규칙을 확인했는가?
미사용 AI를 모두 단락하라는 식의 단일 규칙을 적용하지 않습니다. 신호 종류·모듈에 따라 처리 방법이 다릅니다. 차폐의 접지 위치와 기준 전위 연결도 설비·매뉴얼 지침을 우선합니다.

여기서는 체크리스트 작성만 수행합니다. 실물 배선 전에는 승인된 작업 범위, 에너지 차단 및 무전압 확인 등 현장 절차가 필요합니다.

I/O 주소·원시값·공학 단위 구분

예시의미주의점
%I0.0입력 바이트 0 비트 0실제 채널 할당은 프로젝트에서 확인
%Q0.0출력 바이트 0 비트 0연결 부하 확인 없이 조작 금지
%IW64입력 바이트 64에서 시작하는 워드2바이트 점유·자료형·범위 확인
RawPressure변환 전 모듈 원시값범위·진단 코드의 의미 확인
PressureBarbar로 환산한 값계산식·단위·유효성 함께 제공

Siemens 일부 모듈의 구성된 단극성 정격 범위는 원시값 0~27648에 대응합니다. 예를 들어 지정된 4~20mA 모드에서 4mA=0, 20mA=27648일 수 있습니다. 이것은 모든 CPU·모듈·범위의 보편 규칙이 아닙니다.

0~20mA 모드로 읽는 4~20mA 센서는 하한 원시값이 0이 아닐 수 있습니다. 양극성 전압 범위나 다른 표현 형식도 있으므로 모듈의 analog value representation 표를 읽습니다.
9

스케일링 — 범위를 다른 범위로 변환

선형 환산의 기본식은 다음과 같습니다. 분모가 0이면 계산할 수 없으므로 입력 범위의 상·하한을 먼저 검사합니다.

Engineering = EngMin
            + (Raw - RawMin) / (RawMax - RawMin)
            * (EngMax - EngMin)

가상 압력 센서가 4~20mA로 0~10bar를 나타내고, 가상 모듈을 4~20mA=0~27648로 설정했다고 가정합니다.

전류원시값압력
4mA00bar
12mA138245bar
20mA2764810bar
// FC 본문 개념 예시
// Input: Raw : Int, ChannelOK : Bool
// Output: PressureBar : Real, Valid : Bool
#PressureBar := 0.0;
#Valid := FALSE;
IF #ChannelOK AND (#Raw >= 0) AND (#Raw <= 27648) THEN
    #PressureBar := INT_TO_REAL(#Raw) / 27648.0 * 10.0;
    #Valid := TRUE;
END_IF;

이 코드의 ChannelOK는 별도로 얻은 가상 품질 신호입니다. 실제 진단 비트나 라이브러리의 특정 출력 이름이 아닙니다. 범위 밖 값을 모두 무효 처리하는 보수적인 실습 정책이며, 모듈이 허용하는 초과 범위까지 정밀하게 표현하지 않습니다.

무효 시 0bar를 표시하더라도 Valid=FALSE를 함께 보아야 합니다. 숫자 0만 보고 실제 압력이 0이라고 판단하지 않습니다.
10

가상 아날로그 환산 계산기

가정: 4~20mA=원시값 0~27648=0~10bar. 아래 계산기는 일반 변환기를 흉내 내는 것이 아니라 이 범위의 교육용 수학 모델입니다. 실제 입력 모듈·PLC와 연결하지 않습니다.

입력 12.000mA → 원시값 13824.000 → 압력 5.000bar 품질: 유효 (가상 정상 범위)

전류 입력을 원시값으로 바꿀 때 실제 모듈의 양자화·정확도·필터 지연은 재현하지 않습니다. 정상 범위 밖 입력은 진단 원인을 추정하지 않고 무효로 표시합니다.

시험 입력품질예상 결과
4mA정상0bar, 유효
12mA정상5bar, 유효
20mA정상10bar, 유효
0mA정상범위 밖, 무효
원시값 13824무효값을 정상 측정으로 제시하지 않음
11

진단 — 단선·초과 범위와 프로그램 품질

일부 모듈은 단선·오버플로·언더플로 등에서 특수 원시값을 반환하거나 진단 메시지를 제공합니다. 지원·임계값·원시값은 모듈과 설정에 따라 다르므로 특정 숫자를 모든 장치의 단선 코드로 외우지 않습니다.

현상함께 확인할 정보
아날로그값이 고정됨센서 전원·배선·측정 범위·진단·값 갱신
원시값이 정격 밖실제 초과·단선·오버플로·잘못된 설정의 가능성
디지털값이 반전됨NO/NC·센서 동작 논리·PNP/NPN·프로그램 해석
센서가 짧게 켜졌는데 누락입력 필터·펄스 폭·스캔·통신 갱신
출력 명령은 ON인데 부하 반응 없음부하 전원·인터페이스·진단·피드백
스케일링 전에 입력 품질을 판정합니다. 오류 코드를 정상 측정값처럼 환산한 뒤 0~100%로 잘라 버리면 고장을 숨길 수 있습니다. 범위 제한과 진단 처리의 목적을 구분합니다.

고장 시험은 실제 배선을 끊거나 단락시키지 않고 내부 태그로 품질 이상을 모의합니다. 실제 측정·수리는 자격을 가진 담당자의 별도 절차입니다.

가상 실습 — 신호 목록부터 기대값 작성

  1. 가상 장치에 제품 센서 DI, 운전 표시등 DQ, 압력 측정 AI가 있다고 정합니다.
  2. 신호별 전기 사양을 “가정”으로 명시하고 실제 장치값과 혼동하지 않습니다.
  3. 제품 센서의 TRUE 의미, 표시등 ON 조건, 압력 범위를 씁니다.
  4. 물리 주소 대신 전역 DB에 ProductDetected : Bool, Enable : Bool, Lamp : Bool, RawPressure : Int, ChannelOK : Bool, PressureBar : Real, Valid : Bool을 만듭니다.
  5. Lamp는 ProductDetected AND Enable로 계산하고 압력은 위 예제 FC 논리로 환산합니다.
  6. 정상·범위 밖·품질 무효 입력을 나누어 시험합니다.
시험입력기대값
표시 조건 없음ProductDetected=FALSE, Enable=TRUELamp=FALSE
표시 조건 만족ProductDetected=TRUE, Enable=TRUELamp=TRUE
중간 압력RawPressure=13824, ChannelOK=TRUE5bar, Valid=TRUE
범위 초과RawPressure=30000, ChannelOK=TRUE0bar 기본값, Valid=FALSE
품질 이상RawPressure=13824, ChannelOK=FALSE0bar 기본값, Valid=FALSE

SCL을 아직 배우지 않았다면 코드 실행은 필수가 아닙니다. 진리표·환산표와 브라우저 계산기로 예상 결과를 확인하고, 7주차 이후 같은 요구사항을 프로그램으로 구현합니다.

확인 문제와 다음 학습

1. PNP와 NO는 같은 분류인가요?

아닙니다. PNP/NPN은 출력 회로의 특성과 관련되고, NO/NC는 동작 조건에 따른 출력·접점 상태에 관한 구분입니다.

2. PNP 센서는 일반적으로 어떤 입력과 짝을 이루나요?

센서가 전류를 공급하므로 일반적으로 싱킹 입력과 조합합니다. 실제 지원과 공통 단자는 모듈 매뉴얼로 확인합니다.

3. 전압 AI에 4~20mA 센서를 그대로 연결하면 되나요?

아닙니다. 입력 방식과 범위, 전송기 전원 등 전기적 적합성을 먼저 확인해야 합니다. 임의 결선을 하지 않습니다.

4. 원시값 0은 언제나 단선인가요?

아닙니다. 예를 들어 이 교안의 가상 4~20mA 모드에서는 0이 정상 하한 4mA를 뜻합니다. 오류값과 진단은 모듈별로 확인합니다.

5. 압력이 0bar로 표시되면 정상 0인가요?

Valid 같은 품질 정보를 함께 보아야 합니다. 이 예제는 무효 시 숫자 기본값도 0으로 설정하므로 숫자만으로 구분할 수 없습니다.

6. 센서의 짧은 펄스는 프로그램이 항상 읽나요?

아닙니다. 입력 필터·스캔·갱신 주기에 따라 놓칠 수 있어 실제 펄스 폭과 필요한 고속 기능을 검토합니다.
