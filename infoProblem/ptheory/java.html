JAVA PROGRAMMING

Java 프로그래밍 이론

객체지향 프로그래밍의 핵심 원리와 Java 문법을 예제 중심으로 학습한다.

1. Java와 실행 환경

Java는 객체지향 프로그래밍 언어다. 소스 코드를 바이트코드로 컴파일하고 JVM(Java Virtual Machine)에서 실행하므로 운영체제에 독립적인 실행 환경을 제공한다.

구성 요소역할
JDKJava 개발 도구 모음. 컴파일러와 실행 도구 등을 포함한다.
JREJava 프로그램 실행에 필요한 라이브러리와 실행 환경을 제공하는 개념
JVM바이트코드를 실행하는 가상 머신
javac.java 소스 파일을 .class 바이트코드로 컴파일
java클래스의 main 메서드 등을 실행
// Hello.java
public class Hello {
    public static void main(String[] args) {
        System.out.println("Hello, Java!");
    }
}

실행 흐름: Hello.java → javac 컴파일 → Hello.class → JVM 실행

2. 기본 문법과 자료형

Java는 변수의 자료형을 명시하는 정적 타입 언어다. 기본 자료형(primitive type)과 참조 자료형(reference type)을 구분한다.

분류자료형설명
정수byte, short, int, long정수 저장. long 리터럴은 보통 L을 붙인다.
실수float, double실수 저장. float 리터럴은 F를 붙인다.
문자char하나의 문자 저장
논리booleantrue 또는 false
참조String, 배열, 클래스 등객체를 참조하는 값
int age = 20;
double score = 95.5;
char grade = 'A';
boolean passed = true;
String name = "민수";

System.out.println(name + " : " + score);

형 변환

작은 범위의 자료형에서 큰 범위로 변환하는 확대 형 변환은 일반적으로 자동 처리된다. 큰 범위에서 작은 범위로 변환하는 축소 형 변환은 명시적 캐스팅이 필요하며 데이터 손실에 주의한다.

int n = 10;
double d = n;          // 자동 형 변환
double pi = 3.14;
int value = (int) pi;  // 명시적 형 변환: 3

4. 배열과 문자열

배열은 같은 자료형의 여러 값을 연속된 인덱스로 관리한다. 인덱스는 0부터 시작하며 생성 후 길이를 변경할 수 없다.

int[] scores = {90, 80, 95};
System.out.println(scores[0]); // 90
System.out.println(scores.length); // 3

int sum = 0;
for (int s : scores) sum += s;
System.out.println("평균: " + (sum / (double)scores.length));

2차원 배열은 행과 열 형태의 배열이다.

int[][] matrix = {
    {1, 2, 3},
    {4, 5, 6}
};
System.out.println(matrix[1][2]); // 6

5. 클래스와 객체

클래스는 객체를 만들기 위한 설계도이며, 객체는 클래스에 따라 생성된 실체다. 필드는 상태를, 메서드는 동작을 표현한다.

class Student {
    String name;
    int score;

    void introduce() {
        System.out.println(name + "의 점수: " + score);
    }
}

public class Main {
    public static void main(String[] args) {
        Student s = new Student();
        s.name = "지민";
        s.score = 92;
        s.introduce();
    }
}

생성자와 this

생성자는 객체 생성 시 초기화를 담당하며 클래스 이름과 같고 반환형을 쓰지 않는다. this는 현재 객체를 가리킨다.

class Book {
    String title;
    Book(String title) {
        this.title = title;
    }
}

접근 제한자

제한자접근 범위(개념)
private같은 클래스 내부
default같은 패키지
protected같은 패키지 및 다른 패키지의 하위 클래스 등
public어디서나 접근 가능(모듈 등 별도 제한 제외)

6. 객체지향의 4대 특징

특징핵심 개념예시
캡슐화데이터와 메서드를 묶고 내부 상태를 보호private 필드와 public getter/setter
상속기존 클래스의 특성을 하위 클래스가 확장class Dog extends Animal
다형성같은 타입의 참조가 실제 객체에 따라 다른 동작메서드 오버라이딩
추상화핵심 기능만 드러내고 세부 구현을 감춤abstract class, interface

상속과 오버라이딩

class Animal {
    void sound() { System.out.println("소리"); }
}
class Dog extends Animal {
    @Override
    void sound() { System.out.println("멍멍"); }
}
Animal a = new Dog();
a.sound(); // 멍멍

오버로딩은 같은 이름의 메서드를 매개변수 목록을 다르게 하여 여러 개 정의하는 것이고, 오버라이딩은 하위 클래스가 상위 클래스의 메서드 구현을 재정의하는 것이다.

7. 추상 클래스와 인터페이스

추상 클래스는 직접 객체화할 수 없으며 공통 상태와 구현을 공유할 수 있다. 인터페이스는 구현 클래스가 제공해야 할 동작의 계약을 정의한다. Java의 인터페이스에는 추상 메서드 외에도 default, static 메서드 등이 존재한다.

interface Flyable {
    void fly();
}
class Bird implements Flyable {
    public void fly() {
        System.out.println("날아간다");
    }
}

abstract class Shape {
    abstract double area();
}
class Circle extends Shape {
    double radius;
    Circle(double radius) { this.radius = radius; }
    double area() { return Math.PI * radius * radius; }
}

클래스는 하나의 클래스를 상속(extends)하지만 여러 인터페이스를 구현(implements)할 수 있다.

8. 예외 처리

예외(Exception)는 프로그램 실행 중 발생하는 비정상 상황이다. try-catch-finally로 예외를 처리하고 throw로 예외를 발생시키며 throws로 호출자에게 예외 처리를 위임한다고 선언한다.

try {
    int result = 10 / 0;
    System.out.println(result);
} catch (ArithmeticException e) {
    System.out.println("0으로 나눌 수 없다.");
} finally {
    System.out.println("항상 실행되는 정리 구문");
}
구분특징
Checked Exception컴파일 시점에 처리 또는 선언을 요구하는 예외 계열
Unchecked ExceptionRuntimeException 계열 등 컴파일러가 처리 선언을 강제하지 않는 예외
Error일반 애플리케이션이 보통 복구 대상으로 다루지 않는 심각한 문제

9. 컬렉션 프레임워크와 제네릭

컬렉션 프레임워크는 객체들을 저장하고 관리하기 위한 인터페이스와 클래스 모음이다.

종류특징대표 구현
List순서가 있고 중복 허용ArrayList, LinkedList
Set중복 원소를 허용하지 않음HashSet, TreeSet
Queue대기열 구조, 처리 순서는 구현에 따라 다름ArrayDeque, PriorityQueue
Map키와 값의 쌍으로 저장, 키 중복 불가HashMap, TreeMap
import java.util.*;

List names = new ArrayList<>();
names.add("민수");
names.add("지민");
names.add("민수");

for (String name : names) {
    System.out.println(name);
}

Map scores = new HashMap<>();
scores.put("민수", 90);
System.out.println(scores.get("민수"));

제네릭(Generic)은 자료형을 매개변수처럼 지정해 컴파일 시 타입 안정성을 높이는 기능이다. 예: List<String>.

10. static, final, 람다 기초

static 멤버는 객체가 아니라 클래스에 속한다. final 변수는 재할당할 수 없고, final 메서드는 오버라이딩할 수 없으며, final 클래스는 상속할 수 없다.

class Counter {
    static int count = 0;
    Counter() { count++; }
}
final double TAX_RATE = 0.1;

람다식은 함수형 인터페이스의 동작을 간결하게 표현한다.

List nums = Arrays.asList(1, 2, 3, 4);
nums.forEach(n -> System.out.println(n * 2));
