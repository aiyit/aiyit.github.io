1. NumPy란?

NumPy는 숫자를 한꺼번에 계산해 주는 파이썬 도구입니다. 엑셀에서 열 전체를 드래그해서 계산하는 것과 비슷합니다.

❌ 파이썬 리스트
a = [80, 90, 75]
a + 5   # 오류!
# 반복문으로 하나씩 더해야 함
✅ NumPy 배열
import numpy as np
a = np.array([80, 90, 75])
print(a + 5)  # 한 번에 계산
[85 95 80]
💡 import numpy as np 는 "NumPy를 불러와서 np라는 짧은 이름으로 쓰겠다"는 뜻입니다. 모든 예제 맨 위에 필요합니다.

2. 배열은 어떻게 생겼을까?

1차원 배열 = 숫자가 한 줄로 늘어선 상자

위의 작은 숫자가 인덱스(번호표). 반드시 0부터 시작! a[0]=80, a[-1]=95(맨 끝)

2차원 배열 = 행(가로)과 열(세로)로 된 표

2행 3열 → shape = (2, 3). 노란 칸은 m[1, 2] = 88 (1번 행, 2번 열)

배열 정보 보기

속성뜻(2,3) 배열일 때
m.shape모양(행, 열)(2, 3)
m.ndim차원 수2
m.size전체 원소 개수6
m.dtype원소 자료형int64 (환경에 따라 int32)

3. axis(계산 방향) 그림으로 이해하기

axis는 없애고 계산할 축입니다. 2차원 표에서 axis=0은 행 방향으로 더해 열별 결과를 만들고, axis=1은 열 방향으로 더해 행별 결과를 만듭니다. 화살표는 더하는 방향을 나타냅니다.

axis=0 ↓ (열끼리)
1+4=5, 2+5=7, 3+6=9 → [5 7 9]
axis=1 → (행끼리)
1+2+3=6, 4+5+6=15 → [6 15]
m = np.array([[1,2,3],[4,5,6]])
print(m.sum(axis=0))
print(m.sum(axis=1))
[5 7 9]
[ 6 15]
💡 학생(행)별 평균 → axis=1, 과목(열)별 평균 → axis=0. axis는 “남길 방향”이 아니라 “계산으로 줄이는 방향”입니다.

4. 슬라이싱: 표에서 원하는 부분 오려내기

a[시작:끝] 에서 끝 번호는 포함하지 않습니다. 2차원은 m[행범위, 열범위] 입니다.

m[1:, 1:] → 1행부터 끝, 1열부터 끝
m[:, 0] → 모든 행의 0번 열
a = np.array([80, 90, 75, 85, 95])
print(a[1:4])        # 1,2,3번
print(a[a >= 85])    # 조건에 맞는 값만 (불리언 마스크)
[90 75 85]
[90 85 95]

5. 브로드캐스팅: 작은 배열이 자동으로 늘어난다

두 배열의 모양을 오른쪽 끝부터 비교합니다. 각 차원의 크기가 같거나, 둘 중 하나가 1이면 계산할 수 있습니다. 크기가 맞지 않으면 오류가 납니다. 아래에서는 길이 3인 배열이 각 행에 적용됩니다(실제로 배열을 복제해 저장하는 것은 아닙니다).

+
→ 각 행에 똑같이 복사됨
= 
scores = np.array([[80,90,70],[85,95,88]])
bonus = np.array([0, 5, 10])   # 과목별 가산점
print(scores + bonus)
[[ 80  95  80]
 [ 85 100  98]]

6. 메소드 사전 (매개변수 + 예제)

분류별 표에서 메소드 → 매개변수 의미 → 예제 코드 → 결과 순서로 확인합니다. 값이 =로 적힌 매개변수는 생략 가능한 기본값입니다.

7. 종합 실습 프로그램

위 표의 예제를 하나의 프로그램으로 묶었습니다. 전체를 Jupyter / Colab에 붙여 넣어 실행하고, 표의 결과와 비교해 보세요. 숫자나 매개변수를 바꿔 가며 결과가 어떻게 달라지는지 확인하면 실력이 빠르게 늡니다.

import numpy as np

print("===== ① 배열 만들기 =====")
print(np.array([1, 2, 3], dtype=float))
print(np.arange(0, 10, 3))
print(np.linspace(0, 1, 5))
print(np.zeros((2, 3)))
print(np.full((2, 2), 7))
print(np.eye(3))

print("===== ② 모양 바꾸기·합치기 =====")
a = np.arange(6)
print(a.reshape(2, 3))
print(a.reshape(3, -1))
m = np.array([[1, 2, 3], [4, 5, 6]])
print(m.flatten())
print(m.T)
x = np.array([1, 2, 3])
y = np.array([4, 5, 6])
print(np.vstack((x, y)))
print(np.hstack((x, y)))
print(np.concatenate((x, y)))

print("===== ③ 통계 =====")
print(m.sum(), m.mean(axis=0), m.mean(axis=1))
print(m.max(), m.min(axis=1))
print(np.median([3, 1, 2, 10]), np.std([2, 4, 4, 4, 5, 5, 7, 9]))
print(np.array([3, 9, 2]).argmax())
print(np.cumsum([1, 2, 3, 4]))

print("===== ④ 수학 계산 =====")
print(np.sqrt([1, 4, 9]), np.abs([-3, 2]))
print(np.round([1.234, 5.678], 1))
print(np.clip([-5, 50, 120], 0, 100))

print("===== ⑤ 조건·정렬 =====")
s = np.array([55, 70, 90])
print(np.where(s >= 60, "합격", "불합격"))
print(np.sort([3, 1, 2]))
print(np.argsort([30, 10, 20]))
print(np.unique([1, 2, 2, 3, 3, 3], return_counts=True))
print((s > 90).any(), (s > 90).all())

print("===== ⑥ 난수 =====")
np.random.seed(42)
print(np.random.randint(1, 7, size=5))
print(np.random.rand(2, 2))
print(np.random.choice([10, 20, 30, 40], 2, replace=False))

print("===== ⑦ 변환·복사·계산·파일 =====")
print(np.array([1.7, 2.9]).astype(int))
b = x.copy()
b[0] = 99
print(x, b)
A = np.array([[1, 2], [3, 4]])
B = np.array([[5, 6], [7, 8]])
print(A @ B)
np.savetxt("a.csv", A, delimiter=",", fmt="%d")
print(np.loadtxt("a.csv", delimiter=",", dtype=int))
학생 질문: ① 숫자나 매개변수를 바꾸면 결과가 어떻게 달라질까요? ② ⑥의 seed(42)를 지우고 여러 번 실행하면 난수 결과는 어떻게 될까요?
💡 난수(⑥)는 seed(42)로 고정해 같은 코드면 같은 값이 나오지만, NumPy 버전에 따라 표의 예시 값과 다를 수 있습니다. 마지막의 a.csv는 실행한 폴더에 저장됩니다.

정리

배열의 구조
인덱스는 0부터, 2차원은 m[행, 열], 모양은 shape로 확인합니다.
계산 방향
axis=0은 열끼리(세로), axis=1은 행끼리(가로)입니다.
메소드 고르기
만들기 = array·arange·zeros, 바꾸기 = reshape·T, 통계 = sum·mean·max, 조건 = where·sort
