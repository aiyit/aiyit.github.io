1. NumPy와 시각화 도구의 관계

NumPy는 수치 계산과 배열 처리가 주된 역할이고, 그래프를 직접 그리는 기능은 약합니다. 그래서 계산한 데이터를 시각화 라이브러리에 넘겨주는 구조로 사용합니다.

1단계. 데이터 생성·수집
학생 점수, 센서 온도, 매출 데이터
2단계. NumPy 처리
평균, 합계, 최댓값, 조건 검색, 배열 연산
3단계. 시각화 도구
Matplotlib, Seaborn, Plotly
4단계. 결과 해석
추세, 분포, 차이, 이상값 확인
예) 학생 점수 100개가 있을 때 NumPy로 평균과 최고점을 계산하고, Matplotlib으로 점수 분포를 그래프로 표현합니다.

2. NumPy 연계 시각화 도구

도구특징활용

3. 대표적인 그래프 5가지

같은 숫자 배열도 어떤 그래프를 쓰느냐에 따라 전달하는 정보가 달라집니다.

그래프용도예시NumPy 기능그리기 함수
선 그래프 (Line)시간에 따른 변화시간별 온도 변화np.arange(), 배열 연산plt.plot()
막대그래프 (Bar)항목 간 크기 비교학생별 시험 점수np.array(), np.max()plt.bar()
히스토그램 (Histogram)값이 어느 구간에 얼마나 분포하는지한 학급의 성적 분포np.mean(), np.std()plt.hist()
산점도 (Scatter)두 변수 사이의 관계공부 시간과 시험 점수배열 간 연산, 조건 검색plt.scatter()
히트맵 (Heatmap)숫자 크기를 색으로 표현학생별·과목별 점수 비교2차원 배열, reshape()sns.heatmap()
질문: "학생 5명의 점수 비교"와 "한 학급 100명의 점수 분포"에는 각각 어떤 그래프가 맞을까요?

4. 실습 1 — 학생 점수 막대그래프와 평균선

목표: 배열 생성 → 평균 계산 → 막대그래프 → 평균선 표시까지 한 흐름으로 실행합니다.

import numpy as np
import matplotlib.pyplot as plt

# 1. 학생 점수 배열 생성
scores = np.array([70, 85, 90, 65, 95])

# 2. NumPy로 평균 계산
average = np.mean(scores)

# 3. 막대그래프 작성
students = np.arange(1, 6)
plt.bar(students, scores, label="Score")
plt.axhline(average, linestyle="--", label="Average")

# 4. 그래프 꾸미기
plt.xlabel("Student Number")
plt.ylabel("Score")
plt.title("Student Score Visualization")
plt.xticks(students)
plt.legend()
plt.grid(axis="y", alpha=0.3)

# 5. 그래프 출력
plt.show()
print("평균 점수:", average)
코드역할
np.array()점수 데이터를 배열로 생성
np.mean()평균 계산 (결과: 81.0)
plt.bar()학생별 점수를 막대로 표시
plt.axhline()평균을 나타내는 수평 점선
plt.show()그래프 화면 출력
학생 질문: ① 점수를 하나 추가하면 어떤 줄을 고쳐야 할까요? ② 평균 미만인 막대만 다른 색으로 칠하려면?(힌트: scores < average)

5. 실습 2 — 그래프 종류별 따라 하기

목표: 같은 방식으로 선 그래프, 히스토그램, 산점도, 히트맵을 직접 그려 봅니다. 한글 폰트 문제를 피하기 위해 라벨은 영어로 작성했습니다.

① 선 그래프 — 시간별 온도

import numpy as np
import matplotlib.pyplot as plt

hours = np.arange(0, 24)
temp = 15 + 8 * np.sin((hours - 9) * np.pi / 12)   # 배열 연산으로 온도 생성
plt.plot(hours, temp, marker="o")
plt.xlabel("Hour"); plt.ylabel("Temperature")
plt.title("Hourly Temperature")
plt.show()

② 히스토그램 — 점수 분포

np.random.seed(0)
scores = np.random.normal(70, 10, 100).clip(0, 100)   # 평균 70, 표준편차 10
plt.hist(scores, bins=10, edgecolor="black")
plt.axvline(scores.mean(), linestyle="--", label="Mean")
plt.xlabel("Score"); plt.ylabel("Students")
plt.legend(); plt.show()
print("평균:", scores.mean().round(1), "표준편차:", scores.std().round(1))

③ 산점도 — 공부 시간과 점수

np.random.seed(1)
hours = np.random.uniform(0, 10, 50)
score = 40 + 5 * hours + np.random.normal(0, 5, 50)
plt.scatter(hours, score)
plt.xlabel("Study Hours"); plt.ylabel("Score")
plt.title("Study Hours vs Score")
plt.show()
print("상관계수:", np.corrcoef(hours, score)[0, 1].round(2))

④ 히트맵 — 학생별·과목별 점수

import seaborn as sns

scores = np.array([[80, 90, 70, 85],
                   [85, 95, 88, 78],
                   [75, 80, 90, 92],
                   [60, 70, 65, 80],
                   [95, 85, 90, 88]])
sns.heatmap(scores, annot=True, cmap="Blues",
            xticklabels=["Kor", "Eng", "Math", "Sci"],
            yticklabels=["S1", "S2", "S3", "S4", "S5"])
plt.show()
학생 질문: ③에서 점들이 오른쪽 위로 향하는 이유는 무엇일까요? 상관계수가 1에 가까우면 어떤 의미일까요?

※ ②, ③은 난수를 사용하므로 seed를 고정해야 매번 같은 그래프가 나옵니다.
